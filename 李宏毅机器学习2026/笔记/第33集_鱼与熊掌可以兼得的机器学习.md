## 二、核心概念

### 2.1 "鱼与熊掌兼得"到底在要求什么（[00:00]–[02:37]）

先把两难重讲一遍（这段是复习 [[第23集_再探分类器与机器学习原理|P23]]）：

> [00:12]–[00:57]「如果我们把模型选择比较大……可以选择的 function 比较多，这个时候虽然我们可以让这个 loss ……压得很低，**但是它的坏处就是理想跟现实会有比较大的差距**。反过来，如果我们选择了一个比较小的模型，只有比较少的可以选择的 function，那我们的 loss 就会比较大，**我们的理想会比较糟，虽然我们的理想跟现实会比较接近**。」（[01:00]）「所以上次我们停在这边，说我们陷入了两难。」

⭐ **"兼得"的定义（老师这一集唯一的一次定义，[01:23]–[02:25]）**：

> 「如果你今天呢要从大 `𝓗` 里面找出某一个 function 小 h，把小 h 用在 D 做的 data 上，要让 loss 越小越好……如果你今天可以找到一个大 `𝓗`，这个大 `𝓗` 有神奇的能力：**第一个，大 `𝓗` 本身里面的成员没有很多**（你只有很少的可以选择的 function）；**同时虽然这边里面的成员很少，但他们的成员呢都是精英**（可以让你的 loss 又很低）。如果这两者同时可以成立的话，那我们就可以让鱼与熊掌兼得。」

⇒ ⭐⭐ **把这句话拆成两个硬条件**（这是本集所有内容的靶子）：

| 条件 | 对应 P23 的哪一半 | 为什么难 |
|---|---|---|
| **A. 成员很少**（`\|𝓗\|` 小） | **落差小** | P23 的"两难"说：`\|𝓗\|` 调小 ⇒ 理想崩坏 |
| **B. 成员都是精英**（里面有能让 loss 很低的 h） | **理想低** | 一个"随便挑的小 `𝓗`"里通常没有精英 |

⇒ **P33 的整个任务**：找到**一个** `𝓗`，它**同时**满足 A 和 B。老师的答案（[02:31]–[02:37]）：「接下来我们要讲深度学习**如何做到鱼与熊掌兼得**。」

⚠️ **一句话记住它**：**不是"把 `𝓗` 调小"，是"换一个又小又聪明的 `𝓗`"。**（对照：P23 的悲观点在于"你只会调大小"；P33 的多出来的那一维是**结构**。）

### 2.2 复习段：为什么需要 hidden layer（**本集主题外，只留指针**）

[02:37]–[08:45] 这一大段是老师口中的"**预习的影片里已经有的复习**"（[03:01]–[03:08] 原话：「这段讲的比较快一点……如果你等一下听得没有很清楚的话，你**再回去看预习的影片**」）。

- **内容**：任意曲线 → 切成一段一段 → 常数项 + 一堆阶梯形（**hard sigmoid**）→ 每个 neuron 造一个阶梯（调 weight / bias 造出不同的 sigmoid）→ 加起来就能产生**任何 piecewise linear function** → 而 piecewise linear 可以逼近任何 function；**两个 ReLU 叠起来 = 一个 hard sigmoid**，所以 activation 用 ReLU 也一样 ⇒ **一个 hidden layer 就能产生任何 function**。
- **正式笔记**：[[第04集_深度学习基本概念|第4集]]（piecewise linear / 蓝方 / ReLU 与激活函数）、[[第13集_深度学习简介|第13集]]。
- ⭐ **从这里只要带走一句话**：**一个 hidden layer 就"能表示"任何 function。** —— **本集整场都在跟这句话较劲**："能表示" ≠ "划不划算"（见 §2.3）。

### 2.3 反问：那 deep 有什么用？（[08:45]–[09:44]）

> [08:52]–[09:09]「我们一直强调有一个 hidden layer 的 network，它可以产生任何的 function……**那只要一个 hidden layer 就够了，弄一个 deep 的 network 有什么意义呢？**」
> [09:11]–[09:39]「所以有人就说 deep learning 它只是一个**行销的骗局**……"deep"听起来就非常的厉害，其实只要一个 hidden layer 就可以做所有的事情。**你只要有一个够胖的 network**……但是之所以不创造 `fat neural network`，只是因为 `fat neural network` 听起来实在是太废了。」

⭐ **这个反问为什么成立**：它把**"存在性"**（能不能表示）当成了**"效率"**（要花多少代价去表示）。老师 [09:42] 自己给了判决：「**真的是这样子吗？在实验上你其实可以发现，deep 的 network 确实比较强。**」

### 2.4 ⭐⭐ 公平的比较：Fat + Short v.s. Thin + Tall（[13:28]–[17:57]）

![[P33_01_矮胖vs高瘦_同参数量对照表.png]]
> 图注（[09:55]–[17:57]）：**本集的第一个实证页**，标题就写着 `Fat + Short v.s. Thin + Tall`。**左半张表**是"越深越好"：`1×2k 24.2` → `2×2k 20.4` → `3×2k 18.4` → `4×2k 17.8` → `5×2k 17.2` → `7×2k 17.1`（**红框圈住的是 `2×2k`**）。**右半张表**才是关键：两根橙色双箭头把**参数量相当**的两行对上 —— `5×2k (17.2)` ⇔ `1×3772 (22.5)`、`7×2k (17.1)` ⇔ `1×4634 (22.6)`；最底下**红框**圈着那个巨大的 `1×16k (22.1)`。⇒ **这张表要读的只有一件事：同一件事，往"高"长比往"胖"长更省。**（`X × Yk` = **X 层、每层 Yk 个 neuron**；表头是 **Word Error Rate (%)**，越低越好。）

老师先交代了数据来源与"越深越好"的第一印象：

- **论文是十年前（2011）的**：[09:57]–[10:11]「这个是取自一篇 **Interspeech 2011** 年的 paper……那个时代 deep learning 还是一个非常潮的东西，**可以叠个五六层的 network，所以大家觉得惊为天人**。」
- ⚠️ **这个实验跟作业 2 是同一件事**：[11:40]–[12:09]「它实际上把 deep learning 使用的方式**跟大家在作业 2 做的方式是一样的**……你是对一小段一小段的声音讯号（我们叫做 **frame**）去预测每一个 frame 属于哪一个 **phoneme**，那它**并不是真的语音辨识**」；[13:00]–[13:16]「其实那个时候跑出来的也不是 phoneme，它跑出来是比 phoneme 更小的单位，叫做 **senone**，一个 phoneme 由三个 senone 所组成」；后面再接一个 **WFST**（"你就想成是 rule-based 的东西"）把 phoneme 序列转成文字。
- **第一印象（左半表）**：[13:31]–[13:58]「一层 network 2000 的 neuron，错误率 24.2；两层 20.4；三层 18.4；四层 17.8；五层 17.2；七层 17.1……**这个 network 越深，错误率越低**，这个就是 deep learning 的力量。」
- **质疑（[14:00]–[15:11]）**：「当 network 越深的时候，它的**参数量就越多**……你可以让你的理想越来越美好。**如果今天你的资料量足够多**，你知道这个理想跟现实的差距**取决于两件事**吗？一件事情是**你的模型有多大**（如果太大，差距就会很大），但另外一件事情是**你有多少的训练资料**。……所以很多人对深度学习的印象就是：**深度学习就是大模型，大模型就要大资料，没有大资料就会 overfitting。**」
- 🔗⭐ **这张表的前半在 [[第13集_深度学习简介|第13集]] 就出现过**（P13 [43:48]–[44:16] 只讲了「1 hidden layer（2k neuron）WER **24.2**，越深越低」，并且当场判定**"不 surprise"**：参数多 ⇒ function set 大 ⇒ bias 小，有足够资料就更好）。⇒ **P33 补上的正是下面"公平比较"那一半**（同参数量下 **thin + tall 赢**）—— 换句话说：**P13 把这个问题挂起来的地方，就是 P33 开始回答的地方**。

⭐⭐ **于是才有"公平的比较"这一页**（[15:14]–[15:52] 原话）：

> 「**用个大模型有什么了不起的？**不需要深度学习，我们也可以制造出很大的模型 —— 举例来说我们也可以让模型**不要往天空发展、不要往直向的发展，而让它变胖、往横向的发展**，这样子也可以制造出很大的模型。所以光是把这个 layer 加深、说它 performance 会比较好、说它的 Word Error Rate 会比较低，是**不够的**。**如果你要真的体现深度学习的力量的话，你应该把一个矮胖的 network 跟一个高瘦的 network 来进行比较，当它们参数量一样的时候。**」

**这条比较的具体数字**（投影片字面 + [16:17]–[17:50] 口述）：

**第一组：参数量相当的两组对照**（投影片上的两根橙色双箭头）：

| 矮胖（fat + short） | 错误率 | ⇔ | 高瘦（thin + tall） | 错误率 |
|---|---|---|---|---|
| `1 × 3772` | 22.5 | ⇔ | **`5 × 2k`** | **17.2** |
| `1 × 4634` | 22.6 | ⇔ | **`7 × 2k`** | **17.1** |

**第二组：把矮胖加到极致也救不回来**（投影片两个红框）：

| 矮胖 | 错误率 | 高瘦 | 错误率 |
|---|---|---|---|
| **`1 × 16k`**（参数量**远大于**全表任何一个） | **22.1** | **`2 × 2k`**（只有两层，参数量远小于它） | **20.4** |

（补充：`1 × 16k` 的 22.1 **确实**比同样一层的 `1 × 2k` 的 24.2 好 —— **但"加宽"救不回它，加深可以**。）

- **`3772` 这个数字是怎么来的**（[16:27]–[16:35]）：「就是当你一层 network 有 3772 个 neuron 的时候，**它的参数量会跟五层 network、2000 个 neuron 的参数量是接近的**。」（`4634` 同理，对上七层。）
- ⭐ **最后一击**（[17:14]–[17:50]）：「甚至当你把参数量不断地增加，**一层 network 有 16k neuron** 的时候……它的参数量是**远大于**投影片上的其他 network 了。就算是你开了一个很大的一层矮胖 network，它的 performance 虽然比同样 2000 个 neuron 的还要好（22.1 < 24.2），**但是你只要叠两层 network，虽然它的参数量远少于这个巨大模型，但是深的模型的错误率还是比较低的**（20.4 < 22.1）。」

### 2.5 ⭐⭐ 本集的结论：deep 的优势是"省参数"（[18:08]–[19:57]）

> [18:19]–[18:34]「直接跟大家讲结论：**虽然一个 hidden layer 的 network 可以表示任何 function，但是当你要表示某一个 function 的时候，往往用一个 deep 的架构会是比较有效率的。**」
> [18:57]–[19:11]「矮胖的 network 反而会需要比较多的参数……你要做到同一件事、你要产生某一个 function，用高瘦的 network 反而是**比较有效率**的。」
> [19:12]–[19:41]「所以用 deep learning **并不是比较容易 overfitting**……很多人对 deep learning 有一个误解，所谓的 deep 就是大的模型……如果你没有足够的 data 那就会有 overfitting。**但这不是 deep learning 的核心，并不是 deep learning 真正的优势所在。** deep learning 真正的优势所在是：当你要产生某一个 function 的时候，**你需要比较少的参数**。比较少的参数意味着什么？**意味着你比较不会 overfitting，或者是你只需要比较少的训练资料。**」
> [19:46]–[19:58]「是不是跟你直觉想到的、或者是跟坊间报章杂志上随便看到的**正好相反**？一般的印象就是 deep learning 就是大资料、容易 overfitting，但事实上 **deep learning 它真正的强项反而是不容易 overfitting**。」

⭐ **把这段话翻译成 P23 的语言**（这是本集跟 P23 的接口，务必自己会翻）：

| 老师的话 | P23 的语言 |
|---|---|
| "需要比较少的参数" | **模型（假设空间）比较小 ⇒ `\|𝓗\|` 小** |
| "比较不会 overfitting" | **`P(抽到坏资料) ≤ \|𝓗\|·2e^(−2Nε²)` 里乘号左边小 ⇒ 落差小** |
| "或者只需要比较少的训练资料" | 同一条式子的**反解式**：`N ≥ log(2\|𝓗\|/δ)/(2ε²)` —— `\|𝓗\|` 小 ⇒ 要的 `N` 小 |
| "可以让 loss 又很低"（§2.1 的条件 B） | **理想本身低**（deep 装得下那个复杂函数） |

⇒ ⭐⭐ **一句话**：**深度让"装下这个目标函数"所必需的 `|𝓗|` 变小了。** 成员少（A）＋ 里面有精英（B）＝ §2.1 说的"鱼与熊掌兼得"。
⚠️ 但注意老师用的词是「**往往**」（[18:32]）—— 这不是"所有函数都这样"的定理（见 §5 易错点 1、）。

### 2.6 三个类比：为什么"深"会带来好处（[20:21]–[25:43]）

老师在正式推导前先给了三个"深层次结构"的类比（[20:10]–[20:17]：「在我们直接探讨 deep learning 的好处之前，我们先来举几个例子」）。

**类比一：逻辑电路 —— parity check（[20:21]–[23:41]）**

![[P33_02_逻辑电路类比_parity_check与XNOR.png]]
> 图注（[20:21]–[23:41]）：**投影片左上**先定义了 **XNOR gate**（右上角附真值表：**两个输入相同 → 1，不同 → 0**）。**上半**是任务：给一串 0101，电路要数 1 出现的次数 —— **偶数输出 1、奇数输出 0**（`1010 → 1 (even)`、`0001 → 0 (odd)`）；投影片右侧写着结论「**For input sequence with d bits, Two-layer circuit need O(2^d) gates.**」。**下半**是 deep 版做法：把 **4 个 bit（A B C D = 1 0 1 0）** 用 **3 个 XNOR 串起来**（前一个的输出接下一个的输入），中间算出 **0、0**，最后输出 **1**（＝有两个 1，偶数 ✓）—— **3 个 gate = d−1 个**。

- [21:24]–[21:31]「因为只要**两层电路**就可以制造出任何的 function」⇒ 但 [21:37]–[21:55]「如果你只用两层逻辑闸的话，那你需要 **2 的 d 次方**个 gate（d 是输入 sequence 的长度）」。
- [22:04]–[22:16]「**但是没有人用两层的逻辑电路来做一台电脑**，因为你知道把逻辑电路用其他的方式来建构，可能会是更有效率的解法。」
- ⭐ [23:14]–[23:33]「当你把这些 XNOR 的 gate **不是排成两层，而是排成一个 deep 的结构**的时候 —— 第一个 XNOR 的输出会是下一个 XNOR 的输入、下一个的输出又会是再下一个的输入 —— 当你把它们串成一排的时候，**你会用比较少的 gate 就做到比较复杂的事情。**」

**类比二：写程式（[23:41]–[24:47]）**

![[P33_03_程式类比_别把东西都塞进main.png]]
> 图注（[23:41]–[24:47]）：投影片左边一句话 **`Don't put everything in your main function.`**，右边是一棵呼叫树：`main` → `sub1 / sub2 / sub3` → `subsub1 / subsub2 / subsub3` → `subsubsub1 / subsubsub2 / subsubsub3`。⭐ **要看的是那些"交叉"的长箭头**：`subsub2` 同时被 `sub1`、`sub2`、`sub3` 呼叫（`subsub1`、`subsub3` 各有自己的呼叫者）—— **同一个 sub function 被多处复用**。（页脚 `http://rinuboney.github.io/2015/10/18/theoretical-motivations-deep-learning.html` 是投影片自带的延伸阅读，本课不要求。）

- [23:59]–[24:15]「你除了 `main` function 以外，你会写很多的 module，你会在适当的时机去呼唤这些 module，然后每一个 module 或者每一个 function 里面，都还有它可以去呼叫的 sub function，**然后不同的 function 也可以呼叫同样的 sub function**。」
- [24:23]–[24:39]「有这种结构的好处是：它会避免你的程式太过冗长……如果同一个功能在一个程式里面需要反复使用的话，**你可以去 call 同样的 function**。」

**类比三：剪窗花（[24:47]–[25:43]）**（⚠️ 这一段**没有截图**，记文字）

> [24:58]–[25:05]「你一个色纸，然后把这个色纸把它**折起来**，然后在折起来的色纸上**剪几刀**，展开你就有一个复杂的图案。」
> [25:07]–[25:27]「那算这个复杂的图案你**也可以直接去剪它**，但你要直接剪出这个复杂图案……那是很麻烦的，**你要剪很多刀**。但如果我们把纸折起来，**我们只需要剪几刀就可以剪出复杂的图案**，我们会比较有效率。」
> ⭐ [25:33]–[25:41]「所以今天这个**折纸的过程、把纸对折再对折，这个对折的过程其实就是 deep learning 里面的 layer 在做的事情。**」

⭐ **三个类比的共同骨架**（归纳）：

| 类比 | "深"换来了什么 | 关键动作 |
|---|---|---|
| parity check | `O(2^d)` 个 gate → `d−1` 个 | **前一个的输出当下一个的输入**（串起来） |
| 写程式 | 不必处处重写 → 呼叫 module | **同一个 sub function 被多处共用** |
| 剪窗花 | 剪很多刀 → 剪几刀 | **对折 = 让一次操作作用在很多地方** |

⇒ ⭐⭐ **共同点 = "重复使用"**：**深度 = 把"同一个（组）运算"重复套用** ⇒ **一次设计，多处生效** ⇒ 这就是"省参数"的来源。（§2.7 的推导会把这个直觉变成一张图。）

### 2.7 ⭐⭐⭐ 正面回答：一次"折"就是一个 layer（[25:51]–[36:12]）

![[P33_04_三层网络的折叠推导_2的3次方段.png]]
> 图注（[25:51]–[36:12]）：**本集的核心推导页**。**上半**是一个三层网络：`x` 分两条路 —— 上路（weight `1`、bias `−0.5` → 输入 `x − 0.5`）、下路（weight `−1`、bias `+0.5` → 输入 `−x + 0.5`），各自过 **ReLU**（蓝），两条输出都乘 `1` 相加 = **`a₁`**；第二层（绿）**用同一组参数**（`a₁ − 0.5` 与 `−a₁ + 0.5`）再折一次得到 **`a₂`**；第三层（橙）同理得到 **`a₃`**。**下半三张图**就是这条链的"数段数"：**左 = `x` 与 `a₂`**（折了两次后的形状：图上贴着轴出现**两个 V** ⇒ **4 段**）、**中 = `a₂` 与 `a₃`**（**一层**做的事：把 `a₂` 再**折一次** ⇒ **2 段**）、**右 = `x` 与 `a₃`**（4 个 V ⇒ **8 段**，红字标着 **`2³ pieces`**）。⚠️ **图是转 90° 画的**（老师 [27:09]「这个图是你要把头转 90 度来看的」：**`x` 画在纵轴、值画在横轴**），所以"山谷"看起来像 `>`。

**怎么读这个网络**（[26:13]–[28:39] 口述）：

1. **第一层只有 2 个 neuron，参数固定**：`w=1, b=−0.5` 与 `w=−1, b=+0.5`，ReLU。
2. 上路 neuron：**输入大于 0.5 时输出 = 输入本身，小于 0.5 时输出 0**（[27:29]–[27:45]）；下路 neuron 恰好相反（[27:59]–[28:22]）。⇒ **两个 neuron 各负责 V 形的一半**（[28:33]「那两个 neuron 分别贡献一半」）。
3. 两条路都乘 1 相加 ⇒ **`x` 与 `a₁` 的关系是一个 V（山谷）形**。
4. ⭐ **第二层不是新东西，是"把 `x` 换成 `a₁` 再做一次同样的事"**：[30:07]–[30:39]「`a₁` 跟 `a₂` 的关系**其实跟 `x` 还有 `a₁` 的关系是一样的**……第一个绿色的 neuron 它的输入是 `a₁ − 0.5`，第二个的输入是 `−a₁ + 0.5`」⇒ **`a₁–a₂` 也是一个 V**。
5. ⭐⭐ **于是 `x–a₂` 变成 W 形**：[31:37]–[32:42]「`x` 从 0 挪到 0.5 的时候，`a₁` 从 1 变到 0 ⇒ `a₂` 就**经历了一次轮回**（从 1 变到 0 又变回 1）；`x` 从 0.5 到 1 的时候，**再一次**……所以 `x` 跟 `a₂` 的关系是**一个 W 的形状**。本来只是一个 V 的形状，两个加起来就变成一个 W。」
6. **第三层再来一次** ⇒ [35:52]–[36:12]「`a₃` 它有 **2 的三次方个 pieces**」。

⇒ ⭐⭐⭐ **这一段真正要记的机制**（一句话）：**每一层都在做同一件事 —— 「把输入折一下」（`|输入 − 0.5|` 类操作）；折一次，段数翻倍。K 层 ⇒ 2^K 段，而你只用掉 2K 个 neuron。**

- ⚠️ **数值口径提醒**：老师口述里的坐标（例："`a₁` 从 **1** 变到 **0**"）跟投影片上半写的 weight / bias（`±1`、`∓0.5`）**不在同一个标尺上**（下半那三张图做了归一化：横轴从 `0` 画到 `1`）。⇒ **本页要带走的是"折一次、段数翻倍"这个结构，不是图上某个具体数值。**
- 🔗 **和 §2.6 的关系**：**"折纸"就是 layer 干的事** [25:38]；**"同一个模组被反复套用"就是 sub function 被反复呼叫** [24:15]；**"前一个的输出接下一个的输入"就是 XNOR 串联** [23:20]。三个类比在数学上就是这张图。

### 2.8 ⭐⭐ 指数级的差距：2K 个 neuron v.s. 2^K 个 neuron（[36:16]–[38:43]）

![[P33_05_Deep与Shallow对比_2K段锯齿.png]]
> 图注（[36:16]–[38:43]）：**本集的"总账页"**。右边那条红橙色锯齿 = **同一个目标函数**（`2^K pieces`，横轴是输出 `y`、纵轴是输入 `x`，`0→1`）。左边上下两栏就是两种做法：**上半 `Deep`** = `x → [2 neurons] → [2] → [3] → ⋯ → y`，括号标注 **`K layers (2K neurons)`**，红字 **`smaller |𝓗|`**；**下半 `Shallow`** = `x → [一个大方块] → y`，标注 **`2^K neurons`**，红字 **`larger |𝓗|`**。⇒ **同一件事，一个要 2K 个 neuron，一个要 2^K 个 —— 这就是本集要证的"指数级"。**

- [36:16]–[36:59]「假设在 0 到 1 之间……你想让一个 network 的 output `y` 它有 **2 的 K 次方个线段**，那你其实不需要一个太复杂的 network，**你只要有 K 层、每层两个 neuron，总共 2K 个 neuron**，就可以达成这样子的 input 跟 output 的关系。」
- [37:04]–[37:55]「但同样的锯齿状……如果你想要用一个 shallow 的 network，你要怎么做到呢？……那也不是做不到（只有一个 hidden layer 也可以制造出任何 function），**但是你需要大量的 neuron** —— 因为当只有一个 hidden layer 的时候，假设你用的 neuron 是 ReLU，**那每一个 neuron 只能制造一个线段出来** ⇒ **2 的 K 次方个线段就需要 2 的 K 次方个 neuron。**」
- [37:57]–[38:13]「所以我们比较一个 shallow 跟 deep 的 network：**要产生同样的 function，deep 的 network 是 2K 个 neuron，shallow 的 network 是 2 的 K 次方个 neuron**……**他们是 exponential 的差别。**」
- [38:15]–[38:43]「所以今天要产生同样的 function 的时候，deep 的 network 参数量比较小、它有**比较简单的模型**；而 shallow 的 network 它的参数量比较大，你需要一个**比较复杂的模型** —— 而复杂的模型比较容易 overfit，或者是**因为比较容易 overfit，所以你必须要比较大量的资料**。」

⭐⭐ **投影片那两个红字 `smaller |𝓗|` / `larger |𝓗|` 就是 P23 的记号** ⇒ **本集最后一步：`|𝓗|` 小 ⇒（P23 的不等式）落差小；而 deep 又能把 loss 压低 ⇒（§2.1 的条件 A + B）鱼与熊掌兼得。**（写完整见 §3.2。）

### 2.9 什么情况下 deep 才赢：complex and regular（[39:00]–[41:28]）

![[P33_06_结论_complex_and_regular与补充影片.png]]
> 图注（[39:00]–[41:28]）：**本集的落点页**。两条 bullet：**① `Deep networks outperforms shallow ones when the required functions are complex and regular.`**（底下小字 `Image, speech, etc. have this characteristics.`）；**② `Deep is exponentially better than shallow even when y = x².`**。页面下方是**两段补充影片的 QR code**（`https://youtu.be/FN8jcICrqY0`、`https://youtu.be/qpuLxXrHQB4`）—— ⚠️ **这段影片本笔记没有看**，只记老师口述的结论。

- [39:00]–[39:22]「如果你今天你的目标的 function，也就是可以让你的 loss 很低的那个 function，**它是复杂而且有规律的**，那 **deep 的 network 会优于 shallow 的 network**。」
- [39:22]–[39:52]「那什么样的问题会让 loss 低的那些 function 会是复杂且有规律的呢？**很有可能语音、影像等等这些问题**……那这可以解释为什么今天深度学习在影像上、在语音上，尤其是效果非常的好。」
- ⭐ **老师自己把"诚实的边界"也说了**（[39:55]–[40:22]）：「那有人会问说，**那到底要多复杂的 function，deep 相较于 shallow 才能够占到优势呢？** 那如果说 function 要真的很复杂的时候 deep 才会有优势，那也许多数的状况 deep 仍然是不会有优势的。」⇒ 于是他在**以下这两段影片**里回答。
- [40:26]–[40:58]「那在以下这两段影片中，会直接告诉你说：假设今天有一个 function 叫 **`y = x²`**，那显然是一个非常简单的 function —— 我们用 shallow 的 network 去产生这个 function，跟用 deep 的 network 去产生这样子的 function，**比较起来，deep 是比 shallow 还要 exponential 的好。**」[40:50]–[41:02]「什么叫 exponential 的好？就是 **shallow 的 network 相较于 deep 的 network，要产生 `y = x²` 这个 function，它需要 exponential 多的参数量。**」
- ⭐ **本集的最后一句话**（[41:03]–[41:28]）：「最后就是今天这堂课的结论：**深度学习是一个可以让鱼与熊掌可以兼得的方法** —— 透过深度学习，我们有机会**在比较少的参数量的情况下得到比较低的 loss**，这就是为什么深度学习是一个有潜力的方法，因为它是一个可以让鱼与熊掌兼得的方法。」

⚠️ **"complex and regular" 里的 `regular` 老师没有定义**。**这里的一种读法**（本集没说，但三个类比都指向它）：**`regular` = 有规律 = 可以拆成"重复使用的小模组"** ⇒ 正好是 deep 结构擅长的事（§2.6 的三个类比、§2.7 的"同一个模组套 K 次"）。⇒ **两个词缺一不可**：只有复杂、没有规律（纯随机函数）时，"套用同一个模组"这招使不上；只有规律、不复杂时，shallow 本来就够用。

### 2.10 追问：「那有没有 **shallow 优于 deep** 的情形？」（2026-09-26 用户提问）

> **用户原话**：「关于这一点你有什么看法，我毕竟是个小白，你能举个具体的例子吗（shallow 优于 deep）？我感觉 deep 的结构优势能把指数的计算复杂度压缩到线性，**shallow 在哪方面优于 deep 呢？结构简单吗？**」

**先给结论：在"本集这把尺子"（表示同一个函数所需的参数量）上，几乎不存在"shallow 优于 deep"** —— 最好也只是**打平**。理由是一个**常数代价的降级构造**：

- ⭐ **恒等层只要 2 个 ReLU（每个坐标）**：`ReLU(x) − ReLU(−x) = x` ⇒ 把前 `L−2` 层各做成"什么都不改地传 `x`"，最后一层就是那个 shallow 网络 ⇒ deep 能**模拟**任何 shallow 网络，**代价 ≈ `2d(L−2)` 个 neuron**（`d` = 输入维度、`L` = 层数）。⚠️ **严格说不是"常数"，而是与 `d·L` 成正比**（每层要把 `d` 维输入原样传下去，每个坐标一对 ReLU）—— **但它不含指数**，所以"两边不对称（poly vs exponential）"这个结论不变。
- 而 deep 换来的便宜是**指数级**（`2K` vs `2^K`）。
- ⇒ **两边不对称**：deep 最多"白干一场（不赚）"，shallow 也没法拿"我结构简单"反过来省下指数级的参数。⇒ 所以老师那句「**那也许多数的状况 deep 仍然是不会有优势的**」（[39:55]–[40:11]）应读成「**deep 的便宜用不上**」（打平），**不是"shallow 更省"**。

**那"deep 的便宜用不上"具体长什么样？**（这就是 `regular` 的实感）

| 目标函数 | 有"可重复使用的子结构"吗 | 结果 |
|---|---|---|
| 影像 / 语音里那些函数 | ✅ 有 —— "猫耳朵"这种小 pattern 在**不同位置、不同图片**里反复出现 | **deep 赚翻**（复用 = 省参数） |
| **随机查表函数**（每个 x 给一个互不相干的随机值） | ❌ 没有 | **打平** —— 折纸、"呼叫同一 sub function"都无从下手，只能硬记 ⇒ `2K` vs `2^K` 的分岔**消失** |

⇒ ⭐ **`regular` 的实感 = "目标函数里存在可重复使用的子结构"**；它与 [[第31集_卷积神经网络|第31集]] 是同一条线（**CNN 的参数共享**同样要求"同一个 pattern 会在不同位置出现"）。

**那 shallow 到底赢在哪？—— 换一把尺子就赢**（⚠️ **以下都不在本集**，属补充，供理解用）：

| 尺子 | 谁赢 | 说明 |
|---|---|---|
| **参数量**（**本集的尺子**） | deep（或打平） | 见上 |
| **好不好训** | ⭐ **shallow** | 深网络更难优化（梯度消失/爆炸）—— 这正是 [[第13集_深度学习简介\|第13集]] 里 **ResNet 那个"特殊结构"存在的原因**；优化那条线是 P19–P21 |
| **延迟 / 并行度** | ⭐ **shallow（宽而浅）** | 深网络必须**逐层串行**，宽网络一层内可**并行** ⇒ 延迟敏感的端侧设备上，"宽而浅"有时更划算 |
| **可调试 / 可解释** | shallow | 层数少、看得清（工程上的"结构简单"就是这个意思） |

⇒ ⭐ **一句话**：**"deep 更好"是"给定这把参数量的尺子、且目标函数带复用结构"时的结论**；**换任务、换尺子，结论就会变**。

### 2.11 ⭐ `regular` 到底是"凭感觉"吗？（2026-09-26 用户追问）

> **用户原话**：「这个所谓 regular 是凭感觉吗」「因为这个东西没有具体的定义」

**① 先确认：课上确实没有定义。** 老师全程只用了这个词组，两处原话：

> [39:05]–[39:18]「目标的 function……**它是复杂而且有规律的**，那 deep 的 network 会优于 shallow 的 network」
> [39:22]–[39:36]「那什么样的问题会让 loss 低的那些 function 会是复杂且有规律的呢？**很有可能**语音、影像等等这些问题」

投影片上也只写 `complex and regular` 两个词 —— **没有判据、没有例子、没有"多复杂才算复杂"**（老师自己在 [39:55]–[40:22] 就把这个问题抛给了那两段补充影片）。⇒ **觉得"凭感觉"不是没听懂，是它真的只到"路标"的程度。**

**② 但"没定义" ≠ "没内容"：它有严格的对应物 —— `depth separation`（深度分离）。**

经典出处：**Matus Telgarsky, _Benefits of depth in neural networks_（COLT 2016；[arXiv:1602.04485](http://xxx.itp.ac.cn/abs/1602.04485)）** —— 定理的形状：

> **存在**一类函数，**深网络用多项式量级的参数就能表示，而固定深度的浅网络需要指数级参数**。

⭐ **关键在这里**：Telgarsky 构造的那类函数，就是**"把一个简单模块反复自复合"出来的锯齿（折叠）函数** —— **正是 §2.7 老师在黑板上画的那张图**。⇒ 课堂那个玩具推导**不是凭空的**，它是这类定理的**最小可视版**。

## 三、公式与推导要点

### 3.1 把 §2.7 数一数：段数 2^K，neuron 数 2K v.s. 2^K

| `K`（层数） | deep 需要 | 段数（= 目标 function 的锯齿数） | shallow 需要（ReLU 一层） |
|---|---|---|---|
| 1 | 2 个 neuron | 2 | 2 个 neuron |
| 2 | 4 | 4 | 4 |
| 3 | 6 | **8**（`P33_04` 的 `2³ pieces`） | 8 |
| 5 | 10 | 32 | 32 |
| 10 | **20** | **1,024** | 1,024 |
| 20 | **40** | **1 048 576** | 1 048 576 |

⇒ ⭐ **`K` 一大，两条曲线就分岔**：deep 是**线性**（`2K`），shallow 是**指数**（`2^K`）。老师 [38:13] 原话：「**他们是 exponential 的差别。**」

⚠️ **两处口径要说清楚**（别被"差 1"绊住）：

1. 老师口述「**每一个 neuron 只能制造一个线段出来**」是**量级说法**：严格说单层 ReLU 网络能造出的**折点数 ≤ neuron 个数**（`M` 个折点 ⇒ `M+1` 段）—— **差 1 不影响"指数级"这个结论**，所以投影片就写 `2^K`。
2. **"2 个 neuron 折一次"里的"2"不是巧合**：一个 ReLU 只管折点的**一侧**，所以要用**两个** ReLU（`+` 与 `−`，各带自己的 bias）把折点两侧拼起来（§2.7 步骤 2 的"各贡献一半"）。

### 3.2 接回 P23：为什么"省参数"就等于"鱼与熊掌兼得"

P23 的两条式子（[[第23集_再探分类器与机器学习原理|第23集]] §3.5）：

```
P(抽到坏的训练资料) ≤ |𝓗| · 2e^(−2Nε²)              ← 落差
N ≥ log(2|𝓗|/δ) / (2ε²)                            ← 反过来问"要多少资料"
```

本集要做的事，就是把**同一个目标函数**放进两种 `𝓗` 里比较：

| | 用 deep 装这个函数 | 用 shallow 装这个函数 |
|---|---|---|
| 需要的参数量 | **2K**（小） | **2^K**（大） |
| 对应的 `\|𝓗\|` | **smaller**（投影片红字 `P33_05`） | **larger** |
| 落差 `P(坏资料)` 的上界 | 小 ⇒ **"鱼"** | 大 ⇒ 容易 overfit |
| 能不能压低 loss | ✅ 装得下 ⇒ **"熊掌"** | ✅ 也装得下（但要很多参数） |

⇒ ⭐⭐ **本集一句话的完整版**：**深度没有消掉两难，它换掉了"`|𝓗|` 小就必然装不下好函数"这个前提** —— 在**带结构的** `𝓗` 里，`|𝓗|` 可以很小，但**精英仍然住在里面**。

### 3.3 补充：`smaller |𝓗|` 该怎样读（⚠️ 口径提醒）

投影片把 `smaller |𝓗|` 写在 deep 那栏，**容易读成"固定参数量时，deep 网络的函数更少" —— 那是不对的**。两种比法要分开：

| 比法 | deep | shallow |
|---|---|---|
| **A. 同一个目标函数，"装下它"所需要的最小模型**（= 本集 `P33_05` 的比法） | **小**（`2K` ⇒ `smaller \|𝓗\|`） | **大**（`2^K` ⇒ `larger \|𝓗\|`） |
| **B. 固定参数量，比"能表示多少种 function"** | **反而更多**（⚠️ 这是本集**没说**的另一件事） | 较少 |

- ⭐ **正确的读法**：`smaller |𝓗|` 说的是 **"为了装下这个目标函数，你需要多大的假设空间"** —— 它是一个**"够用就好"的最小型号**，不是"deep 的表达能力弱"。
- **为什么 B 那一栏是"反而更多"**：现代理论里有一支结果叫**深度带来的指数级表达优势**（固定参数量时，ReLU 网络能切出的**线性区域个数**随**深度**指数增长）—— 本课不讲，这里只作为"别把 A、B 混起来"的提醒。
- ⚠️⭐ **这跟 P32 是同一类坑**：**同一个记号 `|𝓗|`，可以有不止一种"数法"**。P32 的坑是"`|𝓗|`（模型多大）vs `|𝓗_val|`（你比了几个）"；本集的坑是"**装下这个函数需要多大** vs **同样参数量下能装多少**"。⇒ **见到 `|𝓗|` 先问一句：这次数的是什么？**

## 五、易错点与纠正

1. ⚠️ **"一个 hidden layer 可以表示任何 function" ≠ "一个 hidden layer 就够了"** —— 前者问的是**能不能**，后者问的是**要多少代价**。老师用的是「**往往**用一个 deep 的架构会是比较有效率的」（[18:32]）—— **"往往"两个字不能丢**。
2. ⚠️ **本集没有说"deep 网络参数量少"**，它说的是「**做同一件事，deep 需要的参数少**」。真实的大型 deep 网络参数量当然很大 —— 关键是**拿它跟"能完成同一件事的 shallow 网络"比**。
3. ⚠️ **别把 `smaller |𝓗|` 读成"deep 的表达能力弱"**（见 §3.3 的 A / B 两种比法）。
4. ⚠️ **P23 的两难没有消失，是换了位置**：P23 说「`|𝓗|` 调小 ⇒ 理想崩坏」——那是对**随便一个小 `𝓗`** 说的；P33 说「有一个**带结构的小 `𝓗`**，里面装着精英」。⇒ **关键不是"小"，是"小而且选得聪明"。**
5. ⚠️ **"越深错误率越低"那张表不能单独引用** —— 它混淆了参数量（老师自己 [14:00] 就点破了）。要引用就引用**公平对照的两行**。
6. ⚠️ **`y = x²` 那个结论来自两段补充影片**（`P33_06` 的两个 QR code），**本笔记没有核对过影片内容**；老师口述的只有结论（deep 指数级更好、shallow 需要指数级多的参数）。
7. ⚠️ **论文出处不要编**：投影片上的数字来自老师口中的「**Interspeech 2011** 的 paper」，**投影片与字幕都没有给标题/作者** ⇒ 引用时只说"2011 年一篇语音辨识论文"。
8. ⚠️ **`3772` / `4634` 不是随手取的数**：它们分别被选成"参数量≈五层 / 七层"的**一层**网络（[16:27]–[16:41]）—— 这才是这两行能当对照的原因。
9. ⚠️ **类比不是证明**：三个类比（电路 / 程式 / 剪窗花）只给直觉，**真正的论证是 §2.7 的折纸构造**。
10. ⚠️ **谈"训练 loss 小"时，前提"`𝓗` 很小"必须同时在场**：小 `𝓗` ⇒ 弹性不够 ⇒ **训练 loss 都压不下去**（P18 的 model bias；P23 的理论版 = "h^all 在 D_all 上 loss 压不下去"）⇒ 所以「**在更小的 `𝓗` 上训练 loss 仍压得很低**」正是"理想没崩坏"的**可观测判据**，也是本集最反直觉的一点。⚠️ 反过来，**大 `𝓗` 上训练 loss 小什么都说明不了**（那种情况总能靠"背下来"做到）。📌 **本条来历**：2026-09-26 曾把用户这句复述判成"靶子歪了"，**被用户拿 P23 的笔记反驳后撤回** —— 保留在此，作为"也会误判"的记录。

## 六、疑问清单

### ✅ 已关闭（本集解决的旧账）

- ⭐⭐ **"为什么 deep 比 fat / shallow 好？"**（[[第04集_深度学习基本概念|第4集]]、[[第13集_深度学习简介|第13集]]、[[第17集_逻辑回归|第17集]] 都留着的悬念）⇒ 本集给的答案：**在做同一件事的前提下，deep 需要的参数是"指数级"地少** ⇒ `|𝓗|` 小 ⇒ 落差小，同时理想仍然低。**注意是"部分关闭"**：本集给的是**构造性论证**（存在这样的函数），不是"所有函数都这样"。
- ⭐ **"鱼与熊掌兼得"到底是什么**（P23 [73:47] 留的话）⇒ = **找到一个 `𝓗`：成员少 + 成员都是精英**（§2.1）。
- ⭐ **"神经网路不是万能的吗？一个 hidden layer 就够了？"** ⇒ 能表示 ≠ 划算（§2.3、易错点 1）。

### ⬜ 留给后续（本集不解决）

- ⭐ **`y = x²` 的两段补充影片**（`P33_06` 的 QR code）—— 老师把它们当作"要多复杂才有优势"的答案；**建议找时间看**（各约十几分钟量级，⚠️ 未核实）。
- ⭐ **`regular` 到底怎么定义**：老师只说"复杂而且有规律"，**没给判据**（这里的一种读法 = 可拆成重复使用的小模组，见 §2.9）。
- ⭐ **这和"层级特征"那条线是什么关系**：本集只讲**参数量效率**；"deep 学到由简到繁的 feature"（[[第13集_深度学习简介|第13集]] 的 feature extractor 视角）是**另一条**理由，本集**没有**用它 —— 两条别混讲。
- ⭐ **CNN（[[第31集_卷积神经网络|第31集]]）其实是同一招的另一半**：CNN 用 **receptive field + 参数共享** 把"影像的先验"写进结构里，也是在"**用更少的参数做同一件事**"。⇒ **P31 与 P33 是"降低 `|𝓗|`"的两条路**（一个是**结构先验**、一个是**深度复用**）。
