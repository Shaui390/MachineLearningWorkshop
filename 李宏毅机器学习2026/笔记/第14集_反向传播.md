# 第14集：反向传播（Backpropagation）

> 一句话：backprop **不是新训练方法，它就是梯度下降**——NN 参数上百万，它只是把"求梯度"算得**更高效**的算法。思路就一句话：把 ∂C/∂w 用 chain rule 拆成两项，分别用 **forward pass**（秒算）和 **backward pass**（从输出层反着递推）得到。

## 本集讲了什么

1. 为什么需要 backprop：NN 参数百万级（语音：8 层 × 1000 neuron），梯度是百万维向量 → 必须高效
2. 复习 chain rule（一条路径相乘、多条路径相加）
3. 单笔 data 的 ∂C/∂w = ∂z/∂w × ∂C/∂z（两项 = 两个 pass）
4. forward pass：∂z/∂w 就是 w 前面的 input（秒算，前向跑一遍网络即可）
5. backward pass：chain rule 递推 ∂C/∂z，**从 output layer 反着算**
6. 组合 → 每笔梯度 → 对所有 data 求和 → 更新参数

---

## 先定符号（一整节都在算它）

- 一笔 data 的 cost：`Cⁿ`（输出 y 与目标 ŷ 的距离）；Total Loss `L = Σₙ Cⁿ`
- 所以 `∂L/∂w = Σₙ ∂Cⁿ/∂w` —— **只用研究一笔 data 的 ∂C/∂w 怎么算**，最后求和即可
- 单个 neuron：`z = x₁w₁ + x₂w₂ + b` → 过激活函数 σ → 输出 `a = σ(z)` → a 再乘权重传给下一层的 z′……

**总目标**：`∂C/∂w = ∂C/∂z · ∂z/∂w`（chain rule，z 消掉）

---

## 一、Forward pass：算 ∂z/∂w —— 秒算

`z = x₁w₁ + x₂w₂ + b` 直接求导：

- `∂z/∂w₁ = x₁`，`∂z/∂w₂ = x₂`，`∂z/∂b = 1`
- **规律：w 前面接的 input 是什么，偏微分就是什么**（看 w 接在谁后面）

对隐藏层同样成立，只是"input"变成了上一层 neuron 的 output。课程手算例（网络 2-2-2，输入 [1,−1]）：

| 层 | 上游 output | 该层 w 的 ∂z/∂w |
|---|---|---|
| 第1层 | x = [1, −1] | 1、−1 …（就是输入本身） |
| 第2层 | 0.98、0.12 | 0.98、0.12（接谁就是谁） |
| 第3层 | 0.86、0.11 | 0.86、0.11 |

> 做法：**把 data 前向喂一遍，记下每个 neuron 的 output**，所有 w 的 ∂z/∂w 同时到手 → 这就是"forward pass"。

---

## 二、Backward pass：算 ∂C/∂z —— chain rule 递推

`z → σ → a → (×w₃, ×w₄) → z′、z″ → … → C`

### 拆两步

`∂C/∂z = ∂C/∂a · ∂a/∂z = ∂C/∂a · σ′(z)`（σ′(z) 已知：sigmoid 的导数，之前见过）

`∂C/∂a`：a 通过**所有下游路径**影响 C（本例子两条，下一个 neuron 个数就是几项）：

`∂C/∂a = w₃·∂C/∂z′ + w₄·∂C/∂z″`

### 递推公式（本集核心式子）

> **`∂C/∂z = σ′(z) · [ w₃·∂C/∂z′ + w₄·∂C/∂z″ ]`**
> （下游有 K 个 neuron 就对 K 项求和）

各项：σ′(z) 可算、w 是已知参数，**唯一未知的是下游的 ∂C/∂z′、∂C/∂z″** → 递归到 output layer 就有答案。

**为什么每个下游项都要乘 w_j？（责任分配）**

- `z_j = w_j·a + 其它项` → 对 a 求偏导：`∂z_j/∂a = w_j`——**a 对 z_j 的"影响斜率"就是这条连接的权重**（对线性函数 y=kx 求导得 k 的翻版）；
- 链式法则"多条路径相加"：`∂C/∂a = Σ_j (∂C/∂z_j)·(∂z_j/∂a) = Σ_j w_j·∂C/∂z_j`；
- 所以反向传播 = 误差信号**原路返回**：穿过哪条连接就乘谁的 w_j（影响力），在 a 处求和，再乘 σ′(z)（a→z 的局部转换率）折算回 z 层面；
- 记忆点：**正向图和反向图共用同一组 w_j；w_j = 0 则误差传不过来（权重越大责任越大）。**

### 边界（Case 1）：下游是 output layer

`∂C/∂z′ = ∂C/∂y₁ · ∂y₁/∂z′`

- `∂y₁/∂z′`：activation 的导数（秒算）
- `∂C/∂y₁`：取决于 cost function 怎么定义（cross-entropy / MSE），总之是可算的简单项（"depend on 你的 cost function"）

### Case 2：下游还不是 output layer

→ 继续往下一层推，推到 output layer 为止。这条路径听起来"很崩溃"：每算一个微分都要一路走到输出。**但实际不是这么算的**（见下面第三节）。

---

## 三、关键：从 output 层反着算（为什么叫"反向"）

- 若从第 1 层开始展开：10 层网络的第 1 层 ∂C/∂z 会变成一棵爆炸的树
- 实际：**先算 output layer 的 ∂C/∂z（秒算）→ 再算上一层 → 逐层往前**，每个 ∂C/∂z 只用到下游已算好的值 + 本层 w + σ′(z)
- 结果：backward pass 的**运算量和 forward pass 一样**（都是每个 neuron 算一次）

### 会指数爆炸吗？不会 —— 靠"记录"（记忆化）

- **会爆炸的是"展开成式子"**：每层 N 个分支 → 路径数 ≈ N^L，符号微分（先推出表达式再代数字）的表达式大小指数膨胀
- **backprop 算的是数值、不是式子**：`∂C/∂z = σ′(z)·Σ_j w_j·∂C/∂z_j` 算完**存下来**；下游的 ∂C/∂z_j 被所有上游共享，算一次读多次 → 多路径的求和把指数条路径**压成一次求和**（记忆化 / 动态规划）
- **计数**（L 层 × 每层 N 个 neuron 全连接）：参数 ≈ L·N²；forward ≈ L·N² 次乘加；backward ≈ L·N² 次乘加（每连接 ×w_j、每 neuron 一次求和 + 一次 ×σ′(z)）；组装梯度每参数 1 次乘法 → 总量 **O(参数个数)，线性于层数**（不是 N^L）
- **代价 = 空间换时间**：必须先 forward 再 backward，把 z、a、σ′(z) 留在内存 → 训练比推理吃显存的原因
- 术语：这就是 **reverse-mode automatic differentiation**（反向模式自动微分）在计算图上的一次反向遍历，代价 O(节点数 + 边数)

---

## 四、反向网络视角（三角形 / OPAMP）

递推式可以看成一个"反向 neuron"：

```
input: ∂C/∂z′  ──×w₃──┐
                       ├─→ Σ ──×σ′(z)──→ output: ∂C/∂z
input: ∂C/∂z″  ──×w₄──┘
```

- 画成**三角形**（老师叫它 opamp/放大器）：它把 input **直接乘一个常数** σ′(z)，**没有非线性转换**
- σ′(z) 为什么是常数？→ z 在 forward pass 时已经算出固定值，σ′(z) 随之定死
- 所以 **backward pass ≈ 把原网络方向倒过来，新建一个"反向网络"再跑一遍**（三角形 = 反向网络的 neuron，放大倍率 σ′(z)）

---

## 五、Backprop 完整流程（总结）

1. **forward pass**：喂一笔 data，记下每个 neuron 的 output（= 所连 w 的 ∂z/∂w）
2. **backward pass**：从 output layer 的 ∂C/∂z 开始（边界公式），用递推式逐层往前，得到所有 ∂C/∂z
3. **相乘**：`∂C/∂w = ∂z/∂w × ∂C/∂z`（一笔 data 的梯度）
4. **求和**：`∂L/∂w = Σₙ ∂Cⁿ/∂w` → 完整梯度向量 → `θ ← θ − η·∇L` → 重复

---

## 公式速查

| 要算什么 | 公式 | 来源 |
|---|---|---|
| 单笔梯度 | `∂C/∂w = ∂z/∂w · ∂C/∂z` | chain rule |
| forward | `∂z/∂w` = w 前面的 input | 直接求导 |
| backward 递推 | `∂C/∂z = σ′(z) · Σ_j w_j · ∂C/∂z_j` | chain rule + sigmoid 导数 |
| output 层起点 | `∂C/∂z′ = ∂C/∂y · ∂y/∂z′` | 手动可算 |
| 汇总 | `∂L/∂w = Σₙ ∂Cⁿ/∂w` | 对全部 data 求和 |

---

## 易混点

1. **backprop ≠ 新优化方法**：它就是 gradient descent 里"算梯度"那一步的高效实现
2. **两个 pass 不是独立的**：backward 需要的 σ′(z) 等数值来自 forward pass（同一个网络、同一笔 data）
3. **∂C/∂w 是单笔**：真正更新参数前必须对所有 data 求和，才是 ∂L/∂w
4. **三角形 neuron 乘的是常数**：与正向 σ(z) 不同，它没有非线性变换（不然也就不叫"线性放大器"了）
5. **b 同理**：∂z/∂b = 1，代入公式即可，没有任何特殊
6. **"优化"一词的四种含义别混**：① 最优化问题本身（min L，数学）② **计算方式的高效化**（backprop 属于这层：同一份梯度，运算量从 N^L 压成 L·N²，靠缓存 ∂C/∂z）③ 优化算法（SGD/Momentum/Adam，改变"怎么走向最小值"）④ 系统/工程效率（kernel、混合精度、并行、FlashAttention）。判据 = 看它改变的是**目标 / 运算量 / 走向最小值的方式 / 执行方式**；backprop 只属于 ②，它不改 loss、也不改更新规则
