#### 1. 面对一个分类任务，第一反应是先当作一个回归任务来做

**具体思路：假设有两类不同的宝可梦，a对应1，b对应-1。看预测的结果，如果预测的数字更接近1（正值），model就判断是a类；更接近-1（负值），model就判断是b类**

 这样做会带来两个问题：
 1. 模型的参数是根据梯度下降来优化的，会让定义的Loss在训练过程中逼近0，这一点导致了一个问题：*模型会因为**过于“正确“的值**（比如说非常大的一个正数）影响整条线的划分，导致最终结果不合理*，如图：
    ![[Pasted image 20260910174142.png]]*可以看到，在右边的表中，由于出现了一些过于极端的点，导致原来看起来比较合理的分割线（绿色）转向为有一些错误的分割线（紫色）*

    > **（我的疑问：为什么“太正确”反而是错的？）**
    > 因为回归用的 Loss 是均方误差，它惩罚的是**距离 target 有多远**。右下角那堆点其实是 class 1（target = 1），但 model 给出的值**远大于 1**，于是 (100−1)² 变成一个巨大的 error；梯度下降为了把它压小，只好把整条线往右转。**对回归来说紫色线更好，对分类来说绿色线才对——同一个 function，两种任务的好坏标准不一样。**
 2. 在分类多个类别中，如果定义：预测数字接近1就是类别1，接近2就是类别2，接近3就是类别3...这样的分类方式暗含了**相邻以及离得近的数字代表的类别之间存在更近的关系，但实际上并没有**，导致训练过程中出现问题

 其他可选的思路（老师叫 Ideal Alternatives）：**找一个 function，里面藏一个 g(x)，g(x)>0 就 output class 1，否则 class 2**；它的 Loss 定义成"**在 training data 上分错的次数**"：
 ![[Pasted image 20260910180019.png]]
 *这条路这节课不走。原因很关键：**"数错误次数"这个东西不能微分**，梯度下降直接没得用（老师原话 [15:28]"叫你解这个 function 你八成不会……这个没办法微分"）。Perceptron、SVM 属于这类方法，投影片上标 Not Today。*
 *→ 所以老师绕道去用**几率模型**：可微、能套三步骤、还能解释 sigmoid 从哪来。*

#### 2. 今天要讲的重点内容 —— 全概率公式（贝叶斯）+ 高斯分布

 要做分类，需要知道四个值：**P(C1)、P(C2)、P(x|C1)、P(x|C2)**。
 - 前两个很好算（叫做 **prior**，先验）：training data 里水系 **79** 只、一般系 **61** 只，共 **140** 只 → **P(C1)=79/140=0.56，P(C2)=61/140=0.44**
 - 后两个才是难点。老师举的例子：给一只**没出现在那 79 只里**的水系宝可梦，它被 sample 出来的几率**不可能是 0** → 所以要**估测出一个分布**。

 假设目前有两个class：
![[Pasted image 20260910191824.png]]*这里抽取pokemon的部分水系精灵和一般系精灵作为两组不同的数据*

 做法：假设这 79 个点是从**一个高斯分布**里 sample 出来的（老师叫它 generative model），那我们只要找出那个高斯：
 - 高斯由两个东西决定：**μ（mean，是个 vector）** 和 **Σ（covariance matrix，是个 matrix）**。μ 决定中心在哪，Σ 决定这个椭圆多胖、往哪边歪。
 - 找出它们的办法叫 **Maximum Likelihood（最大似然）**：任何一组 μ、Σ 都可能 sample 出这 79 个点，但可能性（likelihood）大小不同 → 找**让 likelihood 最大**的那一组：
 ![[Pasted image 20260910192432.png]]
 - 解法很直观（[35:16] 老师原话"这个结果是很直觉的"）：**μ\* 就是平均值**，**Σ\* 就是 (x−μ\*)(x−μ\*)ᵀ 的平均**。
 - ⚠️ 一个容易踩的细节：**79 个点是 independent 地被 sample 出来的，所以机率是相乘**（L = f(x¹)·f(x²)···f(x⁷⁹)），不是相加。（相乘取 log 之后才变相加）

 > **（我的疑问：x是怎么计算的？矩阵吗？之后的7个特征的情况也是用矩阵运算的吗？）**
 > **是，但不用我手算。** 一只宝可梦 = 一个点，x = [Defense, SP Defense] 就是个 **2 维向量**；7 个特征时就是 7 维向量。
 > - **μ\* = 79 个向量的平均**（2 维时是 2 个数，7 维时是 7 个数）
 > - **Σ\* = (x−μ\*)(x−μ\*)ᵀ 的平均**（2 维时是 2×2 矩阵，7 维时是 **7×7**）
 > 投影片 [19:34] 上有真实数字：μ¹=[75.0, 71.3]，Σ¹=[[874, 327], [327, 929]]。
 > **怎么看这个 Σ：对角线（874、929）= 两个特征各自的方差；非对角线（327）= 两个特征之间的协方差**（正数代表"Defense 高的，SP Defense 也偏高"）。
 > 算几率用到的核心是 **(x−μ)ᵀΣ⁻¹(x−μ)**，可以理解成"**用 Σ 当尺子量出来的距离**"（马氏距离）。一维时它就是 (x−μ)²/σ²——减均值、除标准差、平方，多维只是把这件事对每个特征都做一遍，再扣掉特征之间的相关性。

 > ⚠️ **老师自己承认的一个符号坑**：likelihood（似然）**也用 L 表示**，跟 loss 撞名了。原话 [32:45]："这个可能性，这边我们也用了 L，因为我想不到更好的 **notation（记法/符号）**，它可能会跟 loss 有点混淆。"
 > **怎么区分：loss 要最小化（越小越好），likelihood 要最大化（越大越好），方向正好相反。**

 这样就能得到某个精灵（知道其物防和特防）在两个class中出现的概率，进而由**贝叶斯公式**得到其**在其中任意一个类别（水系或者一般系）中的概率**：
![[Pasted image 20260910193449.png]]
*（小订正：整个式子叫**贝叶斯公式**，其中**分母**那一坨才是用**全概率公式**展开的。判定规则是 **P(C1|x) > 0.5 → class 1（水系）**）*

#### 3. 对这种模型的改进方法

 老师的观察 [43:42]：**"每个 Gaussian 都有自己的 mean 和自己的 variance，是比较少见的做法"**；**比较常见的做法是让不同的 class share 同一个 covariance matrix**。

 提出把两组数据合到一起，其中u_1,u_2不变，但新的sigma共用：
![[Pasted image 20260910194546.png]]

 > **（我的疑问：我不知道为什么要这样，这样做有什么依据吗？）**
 > 有依据，而且是老师亲口给的：
 > 1. **参数太多会过拟合**。原话 [44:22]："covariance matrix 它其实是跟你 input 的 feature size 的**平方**成正比的。" 7 个特征时 Σ 是 7×7=49 个数，两个 class 就是两倍 → **参数多 → variance 大 → 容易 overfitting**。共用之后参数直接砍半。
 > 2. **Σ 具体怎么算**（很直观）：**Σ = (79/140)·Σ¹ + (61/140)·Σ²**，也就是"两个协方差矩阵按样本数**加权平均**"。μ¹、μ² 的算法**完全不变**（还是各自求平均）。
 > 3. **数学后果**：共用 Σ 之后，两个高斯相除时**指数上的二次项会互相消掉**（下面第 6 节会看到），于是分界线变成直线。

 在修改model后，分界线从弧线变成了一条直线，这种**分界线为直线的model也叫做linear model**：
![[Pasted image 20260910194651.png]]
 *注意老师的措辞 [50:57]：**"Gaussian 不是 linear 的，但是它分两个 class 的 boundary 是 linear 的。"** —— 这才是 linear model 这个称号的来源。*

 在考虑所有feature（7个）的时候，准确率从原来的54%提升到73%，说明修改的效果不错。
 *（补一句老师对 73% 的态度 [51:32]：**"这个就很难分析了，因为这是在七维空间中发生的事情……但这个就是 machine learning fancy 的地方。"**）*

#### 4. **总结一下刚才讲的2、3两点：这套几率模型其实也是机器学习三步骤**
![[Pasted image 20260910204238.png]]
 - **Step 1（function set）**：就是 posterior probability 那个式子（参数 = 两个 prior + 两个 class 的 probability distribution）；判定规则是 P(C1|x)>0.5 → class 1。
 - **Step 2（好坏的标准）**：⚠️ **这一集的 Step 2 不是"定义 loss 然后最小化"，而是"让 likelihood 最大的那组 μ、Σ"**——和前几集的形式不一样。
 - **Step 3（怎么找）**：很 trivial（平均值 + 协方差），所以老师一句话带过。

#### 5. 补充：不一定要选择高斯分布这种几率模型

 有人问"为什么要用 Gaussian"，老师的回答很实在 [54:46]：**"如果我选了别的几率模型，你也会问我同样的问题。其实你永远可以选一个你自己喜欢的 probability distribution。"**
 而且 [55:03]：**"这个就不是人工智慧，是你凭人的智慧去决定。"** 选简单一点的几率模型 → **bias 大、variance 小**；选复杂的 → bias 小、variance 大。

 常见的另一种假设是：**假设每个 dimension 产生的几率是 independent**，于是 P(x|C) = P(x₁|C)·P(x₂|C)···P(x_K|C)，每一项都是**一维高斯**。
 > **这句"独立"的后果很值得记**：假设各维度独立，等于**强迫原来那个高维高斯的 covariance matrix 变成 diagonal（对角线以外通通是 0）**——因为非对角线装的正是"两个特征之间的相关性"。参数更少、模型更简单。
 > **老师试了这个 → 坏掉了** [57:04]："看来这个模型太简单了……不同的 feature 间的 covariance，看来是必要的。"

 后面的一部分（这里我开始听不懂了）：
![[Pasted image 20260910204705.png]]
 *这页在讲：**binary feature（比如"是不是神兽"，output 只有 0/1）不该用高斯**——[57:54] 老师原话"你说它是用 Gaussian distribution 产生的，就太自欺欺人了"——这时应该用 **Bernoulli distribution**。*
 *而"假设所有 feature 都独立"这种做法，就叫 **naive Bayes classifier**——**naive** 是因为"它真的很 naive、真的很简单" [58:34]；[58:41] 老师补了一句金句：**"它强不强，就代表你的假设是否精准。"***

#### 6. sigmoid 的由来（这一段其实只有三行）

![[Pasted image 20260910204851.png]]
 *把 posterior probability 的分子分母**同除** P(x|C1)P(C1) → 分子变成 1，分母变成 `1 + P(x|C2)P(C2)/(P(x|C1)P(C1))`；把分母里那一坨**取 natural log** 叫做 **z**；于是整个式子就变成 `1/(1+exp(−z))` = **σ(z)**（sigmoid function）。*

 形状（[60:28]）：**z→∞ 时 output→1，z→−∞ 时 output→0**。

![[Pasted image 20260910204947.png]]
 *这页开始把 z 拆开：z = ln[P(x|C1)/P(x|C2)] + ln[P(C1)/P(C2)]；后一项 [61:31] 老师叫"**小学生的数学**"：P(C1)/P(C2) = N1/N2 = 79/61。*

 > **（我的疑问：分类不是用softmax做吗？为什么这节课讲这么多最后发展到sigmoid上了呢？）**
 > **softmax 和 sigmoid 是同一个东西的两个规格**：sigmoid = **2 类**版；softmax = **K 类**版（2 类时 softmax 会退化成 sigmoid）。
 > 两集在做的事不一样：**P13 的 softmax 是"直接放在输出层的现成零件"**（我当时写的"一般将 output layer 加上 softmax"）；**P16 是倒推"这个概率从哪来"**，从哪里算出来竟然刚好是 sigmoid 的形状。
 > 意义在于：**P4 里写的 y = c·sigmoid(b+wx₁)，那个 sigmoid 当时是硬塞进去的逼近工具；这一集告诉你，如果假设数据来自高斯分布且共用 Σ，你不得不得到 sigmoid。**

#### 7. z 到底长什么样（老师亲口说"可以睡一下"的数学段）

 [61:04] 老师原话：*"接下来这边呢，是数学比较多的。如果你觉得这个无聊的话呢，你就睡一下，等一下听一下结论就好。"* —— **所以这一段只记"每一步在干什么"就行：**

| 步骤  | 在干什么                                                              |
| --- | ----------------------------------------------------------------- |
| 1   | z 里的**乘法取 log 变加法**，拆成"似然比"+"先验比(N1/N2)"两半                        |
| 2   | 似然比那半：两个 Gaussian 相除再取 log → **上下相同的常数 `1/(2π)^{D/2}` 直接约掉**      |
| 3   | 把 `(x−μ)ᵀΣ⁻¹(x−μ)` **展开**成 `xᵀΣ⁻¹x − 2μᵀΣ⁻¹x + μᵀΣ⁻¹μ`，中间两项一样所以合并 |

![[Pasted image 20260910205023.png]]
![[Pasted image 20260910205040.png]]
 *上面两张就是把"两高斯相除取 log"和"把二次型展开"写全的样子。*

| 步骤 | 在干什么 |
|---|---|
| 4 | ⭐ **令 Σ1 = Σ2 = Σ** → ① determinant 那一项消掉 ② **`−½xᵀΣ1⁻¹x` 和 `+½xᵀΣ2⁻¹x` 直接相消** |
| 5 | 只剩下 5 项 → 其中**只有两项跟 x 有关**，三项跟 x 无关 → 把 x 提出来 |
| 6 | 提出来的那坨是个 vector → **叫它 wᵀ**：`wᵀ = (μ1−μ2)ᵀΣ⁻¹` |
| 7 | 剩下三项都只是**数字** → 加起来 → **叫它 b**：`b = −½(μ1)ᵀΣ⁻¹μ1 + ½(μ2)ᵀΣ⁻¹μ2 + ln(N1/N2)` |
| 8 | 所以 **P(C1\|x) = σ(wᵀx + b)** |

![[Pasted image 20260910205208.png]]
*就是这张：Σ1=Σ2=Σ 之后，两个 `±½xᵀΣ⁻¹x` 被红笔划掉，剩下的前半截圈起来写 **wᵀ**、后半截圈起来写 **b**。*

 老师对第 7 步的安抚 [66:43]：*"后面这一项你可能觉得看起来很可怕，但它其实很简单……这是一个 vector、这是一个 matrix、这是一个 vector，三个乘起来得到的其实就是一个 **scalar**，它就是个数字……所以你只是把这三个数字加起来而已。"*

 > **⭐ 这一节最重要的一句话：共用 Σ 之所以能让分界线变成直线，就是因为 x 的二次项被消掉了，z 只剩下 x 的一次项。**
 >（反过来：**不共用 Σ 的话，z 里就有二次项，分界线就是曲线** —— 这就是第 2 节那张 47% 的图里弧线的来源。）
