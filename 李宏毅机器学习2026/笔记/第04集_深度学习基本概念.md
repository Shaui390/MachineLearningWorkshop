# 第04集：深度学习基本概念（第2讲 P4）

> 本集主题：从 linear model 的局限走向 Deep Learning。讲稿：[[raw/第04集_字幕|字幕存档]]；我的自写笔记：[[第04集_深度学习基本概念（自己写的）]]（已逐条检查，结果见下）。
> 一句话总结：线性模型永远是一条直线 → 用"常数 + 一堆蓝色函数（hard sigmoid）"拼出任意曲线 → 蓝方用 sigmoid 逼近 → 写成 y = b + Σcᵢσ(bᵢ+wx₁) 并把参数拉成一个大向量 θ → 同样的梯度下降，只是实作上按 batch 分块更新（update≠epoch）→ 用 ReLU 更省 → 堆层数变身 **Deep Learning**，但堆过头会 **overfitting**。

---

## 本集讲了什么

1. **Linear model 的模型偏差（Model Bias）**：X₁ 与 Y 的关系可能很复杂（先升后降），而线性模型永远是一条直线——这是**模型结构本身**的限制，和参数 b（bias）没关系！
2. **万能构造法**：任意连续曲线 → 取点 → 连成 piecewise linear 曲线 → 每条折线 = **常数 + 一堆"蓝色函数"**（hard sigmoid 的形状：水平→斜坡→水平）
3. **用 sigmoid 逼近蓝方**：`y = c·σ(b+wx₁)`；改 **w** 变坡度、改 **b** 左右平移、改 **c** 变高度 → 各类形状的 sigmoid
4. **新模型（多 feature）**：`y = b + Σᵢ cᵢ·σ(bᵢ + Σⱼ wᵢⱼ xⱼ)`，矩阵化：`y = b + cᵀ σ(xW + b)`（向量化、写得更简洁）
5. **参数统称 θ**：w、b、c、b 全部拉直拼成一个大向量 θ → L(θ) → θ\* → 梯度下降 `θ¹ = θ⁰ − η∇L(θ⁰)`
6. **实作细节：batch/update/epoch**：数据随机分组，每批算一次梯度更新一次（update）；全部批次看完一遍 = 一个 epoch（**update ≠ epoch！**）
7. **ReLU**：`c·max(0, b+wx₁)`，两个 ReLU 合成一个 hard sigmoid → 换 ReLU 要**两倍数量**；sigmoid/ReLU 统称**激活函数**
8. **实验**：100 ReLU 明显进步；1000 个测试停滞；**堆层数**：1 层 0.28k→2 层 0.18k→3 层 0.14k（训练），测试 0.43k→0.38k；**4 层 0.10k/0.44k = overfitting**
9. **命名故事**：**"加权求和 + bias → 激活函数 φ"的计算单元** = neuron；成排 = hidden layer；很多层 = deep → **Deep Learning**（老技术换新名）
10. **未解之谜（埋坑）**：一排够多 ReLU 就能逼近任何函数 → 为什么一定要"深"而不是"胖（fat network）"？——日后讲；backprop = 只是更高效算 gradient 的方式

## 核心概念

### 1. Model Bias（模型偏差）≠ 参数 b
- 线性模型 y = b + wx₁ 无论怎么调 w、b **永远是一条直线**（单调），但真实数据可能"先升后降"（过峰值后物极必反）
- 这种"模型结构本身造不出来的限制"叫 **Model Bias**
- ⚠️ 术语歧义：同一个词 "bias"，B 是**参数**（bias，截距），Model Bias 是**模型的能力限制**——老师特意交代："这个东西叫做 Model 的 Bias，它跟 B 的 Bias 不太一样" [01:49–02:07]

### 2. hard sigmoid与 piecewise linear
- hard sigmoid形状：**先水平 → 斜坡 → 再水平**（像一个被压扁的 S）
- **hard sigmoid 的数学式**（课上只说"不好写"，等价形式如下）：
  - 分段式：σ_hard(u) = 0（u<0）；u（0≤u≤1）；1（u≥1），其中 u = b+wx₁ → 完整蓝方：`y = c·σ_hard(b + wx₁)`
  - 闭式（ReLU 写法）：**σ_hard(u) = max(0, u) − max(0, u−1)**（等价于 clip(u, 0, 1)）——就是"两个 ReLU 相加"的由来
  - 参数手感与 soft sigmoid 相同：w 定坡度、b 定位置、c 定高度
- 红曲线 = **常数（constant）** + 一堆蓝线；每个蓝线的斜坡斜率与红色对应线段一致，起点/终点对准红色转折点 [03:52–05:53]
- 任意连续曲线：取点 → 点连成 piecewise linear → 逼近（点够多/位置合适就非常接近）[07:12–07:44]
- 结论：**足够多的蓝线加起来 ≈ 任意连续函数**——这就是"复杂模型"的全部秘密

### 3. sigmoid：蓝线的"软"版
- 式子：`y = c / (1 + e^(−(b+wx₁))) = c·σ(b + wx₁)`；σ = sigmoid = "S 型"函数
- x₁→∞ 收敛到 c（封顶高度）；x₁→−∞ 趋近 0
- 三个参数的"手感"（考试点）：

| 参数 | 作用 | 直觉 |
|---|---|---|
| w | 改**坡度/斜率**（更陡=调大 \|w\|） | sigmoid 中段有多斜 |
| b | **左右平移**（σ 中点 x = −b/w，w>0 时右移=减 b） | 斜坡起点在哪 |
| c | 改**高度**（饱和值） | 曲线多高 |

- 蓝方真正的名字叫 **hard sigmoid**；用光滑 sigmoid 逼近它是因为"直接写出 hard sigmoid 的式子不容易"（其实也不难：两个 ReLU 相加）

### 4. 多 feature 模型 + 矩阵化
- `y = b + Σᵢ cᵢ·σ(bᵢ + Σⱼ wᵢⱼ xⱼ)`：i = 第几个 sigmoid（蓝方），j = 第几个 feature；wᵢⱼ = 第 i 个 sigmoid 乘给第 j 个 feature 的权重。3 个蓝方 × 3 个 feature = 9 个 w
- 矩阵化全链路（本集最重要的表示法）：
  **x → xW + b = r → σ(r) = a → cᵀa + b = y**
- 注意两个 b：`xW + b` 里的 b 是**向量**（b₁b₂b₃，每个 sigmoid 一个），`+ b` 的 b 是**标量**（输出偏置）——它们是不同的东西（课上用绿/灰底色区分）

### 5. θ：参数大合集
- 所有未知参数（矩阵 W、向量 b、向量 c、标量 b）拉直拼成一个**长向量 θ**（纵向量），统称所有未知参数
- L(θ)：定义方式、计算方式与之前 L(w,b) **完全一样**（给定 θ → 算估测 y → 与 label 求 e → 求和）
- θ\* = 让 L 最小的那组参数；θ⁰ 随机初始化（之后还会讲更好的初始化）
- 梯度：`∇L(θ)` 简写 = 对**每一个** θᵢ 求 ∂L/∂θᵢ 集合成的向量（倒三角 = 高数里的 grad）
- 更新：`θ¹ = θ⁰ − η·∇L(θ⁰)`；停止 = 不想做了 / 梯度为 **零向量**（实作上几乎不可能，通常是不想做了）
- 参数多到不能暴力枚举（e.g. 16 个参数的组合数量巨大）→ 必须用梯度下降 [27:57–28:46]

### 6. batch / update / epoch（实作重点！）
- N 笔资料**随机**分成一组组 **batch**（每组 B 笔）
- 每用一个 batch：算该批的 loss l₁ → 由 l₁ 的梯度**更新一次参数** → 换下一个 batch（l₂ → 更新 → …）
- **update = 每更新一次参数；epoch = 把 N 笔全部看过一遍**（两者不是一回事！）
- 例子：N=10000, B=10 → 1000 个 batch → **一个 epoch = 1000 次 update**；N=1000, B=100 → **一个 epoch = 10 次 update**。所以光听"训了一个 epoch"不知道更新了几次——取决于 batch size
- batch size 是**超参数**（本集三个超参数：learning rate、sigmoid/ReLU 个数、batch size；层数也算）
- 为什么要分 batch？**下周讲**（伏笔）

### 7. ReLU 与激活函数
- 式子：`y = c·max(0, b + wx₁)`（0 和 b+wx₁ 谁大取谁；b+wx₁<0 输出 0）
- **两个 ReLU 相加 = 一个 hard sigmoid**：一个 ReLU 提供"水平→斜坡"的起步，另一个（取负系数）提供"斜坡→水平"的封顶
- 因此把 sigmoid 换成 ReLU 需要**两倍数量**：i 个 sigmoid → 2i 个 ReLU
- sigmoid 与 ReLU 统称 **activation function（激活函数）**；哪个更好？**下次讲**——老师实验都用了 ReLU，"显然 ReLU 比较好"

### 8. neuron / network / deep（命名史）
- 每个 **"加权求和 + bias → 激活函数 φ"的计算单元**叫 **neuron（神经元）**（输出 = `φ(Σwᵢxᵢ+b)`；φ = identity 时叫"线性神经元"）；很多 neuron 串起来 = **neural network（神经网络）**
  - ⚠️ **neuron ≠ 激活函数**（2026-09-11 订正）：neuron 是整体（参数 + 运算），sigmoid/ReLU 只是其中的 **φ**；**"没写激活" = φ 取 identity**，不是"没有 φ"
  - 💡 **"线性神经元 = φ 取 identity 的 neuron"这个看法有三个用处**：① 所有 neuron 统一成 `a = φ(Σwᵢxᵢ+b)`，不用为"无激活"造特例；② **参数量公式统一**（φ 不带来参数 → "数 neuron 看权重"成立）；③ **反向传播统一**——identity 的导数 `φ′(z)=1`，于是 [[第14集_反向传播|第14集]] 的递推式 `∂C/∂z = φ′(z)·Σwⱼ∂C/∂zⱼ` 退化成 `∂C/∂z = Σwⱼ∂C/∂zⱼ`，**线性层的梯度"原样穿过"、没有任何缩放**（P14 那个"三角形"的放大倍率 = 1）
  - ⚠️ 边界：identity **不是非线性**，不能给网络增加表达能力 → **hidden layer 不能用它，output layer 恰恰要用它**
- 每一排 neuron = 一层（**hidden layer**）；很多 hidden layer = **deep** → 整套技术 = **Deep Learning**
- 彩蛋：80/90 年代 neural network 被过度吹捧 → 名声臭掉（写 paper 会被拒）→ 改名重振雄风（"穿西装就不一样了"😄）
- 历史曲线：AlexNet 8 层 16.4% → VGG19 7.3% → GoogleNet 22 层 6.7% → ResNet 152 层（都是影像辨识基准集错误率）

### 9. overfitting（过拟合）——本集结尾的爆点
- 4 层模型：训练 **0.10k**（比 3 层 0.14k 更好！）但没看过资料 **0.44k**（比 3 层 0.38k 更差！）
- 定义：**训练资料上变好，没看过的资料上没变好** → overfitting
- 选择标准：看**没看过**的资料（测试误差），不是训练误差 → 选 3 层留作预测 2/26
- 预测彩蛋：2/25 = 5250 人（假设正确）→ 2/26 = 3964（约 3.96k，因为模型知道周五观众少）；下周揭晓误差比 0.38k 大还是小（老师预计不准 😄）

## 公式与推导要点

**单 feature**：`y = b + Σᵢ cᵢ·σ(bᵢ + wᵢx₁)`（i = sigmoid编号）
**多 feature**：`y = b + Σᵢ cᵢ·σ(bᵢ + Σⱼ wᵢⱼxⱼ)`（i = sigmoid编号，j = feature）
**矩阵形式**：`y = b + cᵀ·σ(xW + b)`
- 其中 x：1×3 特征向量；W：3×3（wᵢⱼ，9 个权重）；b：3 维向量（b₁b₂b₃）；c：3 维向量；b：标量
- 全参数：θ = flatten(W, b, c, b)，本例 **16 个**（9w+3bᵢ+3cᵢ+1b）

**梯度下降**：`θ⁰ 随机 → ∇L(θ⁰) = g → θ¹ = θ⁰ − η·g → … 直到不想做或 g = 0 向量`

**实验数据（56 天 feature，K = 千人）**：

| 模型 | 训练 loss | 测试 loss |
|---|---|---|
| linear | 0.32k | 0.46k |
| 10 ReLU | ≈ linear（没进步） | ≈ linear |
| 100 ReLU | 0.28k | 好了一些 |
| 1000 ReLU | 更低 | **没有太大进步**（停滞） |
| 1 层(100 ReLU) | 0.28k | 0.43k |
| 2 层 | 0.18k | 好了一些 |
| 3 层 | 0.14k | 0.38k |
| 4 层 | **0.10k** | **0.44k** ← overfitting |

## 易错点与纠正（本次互问互答产出）

1. **Model Bias ≠ bias 参数**：model bias 是模型结构的能力上限（线性永远直线）；b 是参数（截距）。同一英文词、两个概念 [01:49–02:07]
2. **蓝方不是直线**：hard sigmoid 是"水平→斜坡→水平"的台阶坡，也因此需要 sigmoid/ReLU 来逼近它——题目里"三段直线"的说法要改
3. **update ≠ epoch（本集最易踩）**：update = 用一个 batch 更新一次；epoch = 全部数据看完一遍。N=10000/B=10 → 1 epoch = 1000 updates。报进度时只报 epoch 不报 batch 大小 = 信息不全
4. **sigmoid 换 ReLU 要 2 倍数量**：两个 ReLU 才抵一个 hard sigmoid [43:05–43:20]
5. **训练误差小 ≠ 选它**：4 层训练 0.10k 优秀但测试 0.44k 翻车 → overfitting；选模型看**没看过**的资料
6. **更多激活单元 ≠ 无限更好**：1000 ReLU 时训练降但测试停滞——"一定限度"以内才成立
7. **数字细节**：10000/100 = 100（不是 1000）；3 层测试 0.38k 优于 4 层 0.44k，别把方向记反
