## §2 矩阵形式：一整层 self-attention 就是一连串矩阵乘法

> ⚠️ 本节的"矩阵"**不是新东西**：老师做的事只是把上一集"一个一个向量地算"改成"**把它们并排摆好，一次算完**"。所以读的时候可以一直问自己：**这句话用上一集的逐个数写法怎么写？**

### 2.1 开场复习 + ⭐ 一个容易被忽略的重点（[00:00]–[03:26]）

老师先把上一集的活重做一遍，只是主角换成 `a²`：[00:37]–[00:48]「其实从这一排 vector 得到 b1 跟得到 b2，它的操作是**一模一样**的，所以我们再讲一次怎么从 input 的 vector 得到 b2，等于是帮大家复习上上周说过的东西。」

复习链（跟 P38 完全一致，只是下标换成 2）：

```
a² --×Wq--> q² --与 k¹~k⁴ 各做一次 dot product--> α₂₁ α₂₂ α₂₃ α₂₄
   --softmax--> α′₂₁ α′₂₂ α′₂₃ α′₂₄ --对 v¹~v⁴ 加权求和--> b²
```

⭐ **本集真正的新信息藏在开场这 10 秒**（[00:50]–[01:02]）：

> 「这边的 b1 到 b4，它们**并不需要依序产生**，你并不需要算完 b1 再算 b2 再算 b3 再算 b4。**B1 跟到 B4，它们是一次同时被计算出来的。**」

⇒ 这句话当时听起来像废话，但它是 §7 里 self-attention **打赢 RNN 的那个"平行化"**的伏笔。**矩阵写法存在的意义就是让"同时算"变成事实**（见 §2.7）。

⚠️ **字幕坑**：这一段 ppt 说的是 `b²`，但 whisper 大量写成 `V2`（[02:29]「然后全部加起来就是 V2」）—— 靠上下文区分"大 V 矩阵"和"b²"。

### 2.2 第一步：一排 a 并排摆起来，乘三张表得到 Q、K、V（[03:28]–[06:46]）

每一层的输入是一排向量 `a¹ a² a³ a⁴`，而**每一个 a 都要产生 q、k、v** [03:41]–[03:57]。矩阵写法把这四件事合成一件：

1. **把 a¹–a⁴ 并排摆成一个矩阵**，老师给它取名 **`I`**（[04:34]–[04:49]）：「这个矩阵有四个 column，它的 **column 就是 a1 到 a4**」。
   ⇒ ⚠️ **约定：一个向量 = 直着写的一列（column）**。这是理解本集所有公式的前提。
2. `I` 乘上 `Wq` 得到 **`Q`**，「这个大 Q 就是 Q1 到 Q4，你把 Q1 到 Q4 这四个 vector 拼起来，就是大 Q 的四个 column」[04:52]–[05:08]。
3. `K`、`V` 一模一样：「它的操作跟 Q 是一模一样的，我们就不要再细讲，免得你觉得很无聊」[05:40]–[05:44]。
4. 小结 [06:28]–[06:42]：「**其实就是把输入的这个 vector sequence 乘上三个不同的矩阵**，你就得到了 Q、得到了 K、跟得到了 V。」

⚠️ **两个精度提醒**（写下来免得以后被绕）：

- **乘法的左右顺序**：投影片 p25 写的是 **`Q = Wq · I`**（W 在左、I 在右）。老师的口述听起来是反的 —— [05:26]「把 **I** 这个矩阵**乘上**另外一个矩阵 WQ」。[05:23]–[05:30] 还说「Wq 其实是**内容的参数**（听写存疑，语义应是"里面的参数"），它是等一下**被认出来的**（= 被**认**出来？更可能是"被**学**出来"的听写错）」⇒ **以投影片的 `Q = Wq·I` 为准**。
- `Wq/Wk/Wv` 是**三张不同的表**，不是同一张。

### 2.3 第二步：算 α —— 得到 `A = KᵀQ`（[06:46]–[10:08]）

上一集说 `α_ij = q^i · k^j`（**dot product，一个数**）。矩阵写法分三层垫上来：

1. **`k` 要"倒下来"** [07:19]–[07:34]：老师把 `k¹` 画成横的、说"代表说它是 **transpose**，希望你可以了解我的意思" ⇒ `q¹` 乘 `k¹` 的 transpose 就是 `q¹` 跟 `k¹` 做 inner product，得到 `α₁₁`。
2. **把 K 的四列当横排，乘一个 q** [07:58]–[08:32]：`q¹` 跟 k¹、k²、k³、k⁴ 四个 dot product 的动作，「你可以看作是我们把 K1 到 K4 **拼起来当作一个矩阵的四个 row**，把这个矩阵乘上 Q1，得到另外一个向量」，这个向量里面就是 `α₁₁ α₁₂ α₁₃ α₁₄`。
3. **四个 q 一起做** [08:39]–[09:41]：`q²` 也对 k¹–k⁴ 算（得到 α₂₁–α₂₄），`q³`、`q⁴` 同理 ⇒ 「你可以看作是两个矩阵的相乘，一个矩阵它的 row 就是 K1 到 K4，另外一个矩阵它的 **column 就是 Q1 到 Q4**」。

于是 [09:44]–[10:01]：

```
A = Kᵀ · Q          （A 里存的就是 q 跟 k 之间的 attention 分数）
```

⚠️ **顺序要记牢：`Kᵀ` 在前、`Q` 在后**（投影片 p23 右下角写的就是 `K^T` 在左、`Q` 在右）。这跟我们常见的"`QKᵀ`"写法左右相反，原因是老师的约定是"**向量直着摆**"。

![[P39_01_矩阵形式_alpha与KtQ与softmax.png]]
> 图注（投影片 **p23**）：上半是**单个 q¹ 的写法** —— `α₁,₁ = k¹ q¹`、`α₁,₂ = k² q¹`、`α₁,₃ = k³ q¹`、`α₁,₄ = k⁴ q¹`（每个 q 方块都画在 k 方块的右边 = 乘），右边用一张灰底直排图说明"**四个 k 叠起来 × 一个 q¹ = 一整个直排的 α**"；中段是上一集那种画法（`q¹`–`q⁴`、`k¹`–`k⁴`、`v¹`–`v⁴` 一排，**`q²` 被红框框住**、四条黑线连到 `α₂,₁`–`α₂,₄` 四个点）—— 说明"换成 b² 也是同一套操作"；下半才是矩阵形式：**`K^T`（四个 k 直排）`×` `Q`（q¹q²q³q⁴ 横排）`= A`（4×4，元素是 α）`--softmax-->` `A′`（4×4，元素是 α′）**。
> ⚠️ 这一页同时给了 `A` **和** `A′`；本节讲 `A`（这张图的左下 + 右下），`softmax` 那一步在 **§2.4**。

### 2.4 第三步：`A′ = softmax(A)` —— 对每一个 column 做（[10:08]–[10:42]）

[10:08]–[10:18]：「我们会**对 attention 的分数做一下 normalization**，比如说你会做 softmax，你会对这边的**每一个 column** 做 softmax，让**每一个 column 里面的值相加是 1**。」

⚠️ 注意是 **column（不是 row）** —— 因为一个 column 里的 α′ 就是"某个位置对所有位置"的那一排权重，它们加起来要等于 1（与 P38 .3 的 α′ 是同一件事）。

[10:21]–[10:29] **再提一次那个"反教条"的点**：「其实这边做 softmax **不是唯一的选项**，你完全可以选择其他的操作，比如说 ReLU 之类的，那其实得到的结果也不会比较差。」（P38 [26:24]「这边就没有什么道理……你高兴就好」，同一件事。）

[10:36]–[10:42] 记号：softmax 之后的值"有点不一样了，所以我们用 **A′** 来表示通过 softmax 以后的结果"（字幕的 `apply` / `ply` = **A′ / A prime**）。

⭐⭐ [10:49]–[11:04] **老师当场抓自己投影片的 bug**：

> 「我发现我这个投影片上有一个小小的 bug …… 这个 bug 就是这边应该是 **A′** 而不是 **head**（听写错，见下）。本来最早是写成 head 的，那我现在把它改成 A′，**这样这个地方没有改过来**。」

✅ **"head" 是 whisper 听错，老师说的其实是 `hat`（帽子）** —— 证据就在下一张投影片上：`P39_02`（p24）里那四个注意力分数写的是 **`α̂₁,₁` `α̂₁,₂` `α̂₁,₃` `α̂₁,₄`（带帽子）**，而同一页右下角的矩阵里已经是 **`α′`（撇号）**。
⇒ **结论：`Â`／`α̂` 是这个记号的旧版，`A′`／`α′` 是新版**，老师改到一半、p24 上还留着旧的。以后看到两种写法混用，知道是同一件事就好。

### 2.5 第四步：`O = V A′`（[10:42]–[12:51]）

[11:04]–[11:25]：把 v¹–v⁴ 拼起来、**当成大 `V` 这个矩阵的四个 column**；「接下来呢，你把 `V` 乘上 **A′ 的第一个 column** 以后，你得到的结果就是 **b¹**」。

[11:34]–[12:05] 老师顺便给学过线代的人一句话：「如果你熟悉线性代数的话，你知道说把这个 A′ 乘上 V …… 而把 **A′ 的第一个 column** 乘上 V 这个矩阵做的事情，其实就是**把 V 这个矩阵里面的每一个 column，根据 A′ 这个矩阵里面的每一个 column 里面每一个 element 做 weighted sum**，那就得到 b1。」

[12:29]–[12:41]：A′ 的第二个 column 乘 V 得到 b²，第三个得 b³，最后一个得 b⁴。

[12:41]–[12:51] 于是 `A′ × V = O`，而 **O 的每一个 column 就是 self-attention 的输出 b¹–b⁴**。

![[P39_02_矩阵形式_O等于V乘Aprime.png]]
> 图注（投影片 **p24**）：上排还是上一集那种"逐个数"的画法 —— `q¹k¹v¹` … `q⁴k⁴v⁴` 一排，四个 ⊗ 乘完沿红线汇总成左上角的绿色 **`b¹`**；⭐ 四个点标的是 **`α̂₁,₁`–`α̂₁,₄`（带帽子 = 旧记号，见 §2.4）**。下排是矩阵形式：**`b¹b²b³b⁴`（绿，标 `O`）`=` `v¹v²v³v⁴`（蓝，标 `V`）× `A′`（灰 4×4，元素全是 `α′`）**。
> ⚠️ **左右顺序以投影片为准**：投影片写的是 **`V A′`**（V 在左）；老师口述 [12:41] 说成"把 A′ 这个矩阵乘上 V"是口语顺序，**别照抄**。（同一件事在 §2.2 的 `Wq·I` 上也发生过一次。）

### 2.6 整条链子 + ⭐⭐ 唯一要学的参数（[12:51]–[14:56]）

[13:17]–[14:08] 老师把整层重排一次：

```
I  ──×Wq/Wk/Wv──▶  Q, K, V
I ──▶ Q ──×Kᵀ──▶  A  ──(softmax 之类)──▶  A′      ← A′ 有时候叫 attention matrix
A′ ──×V──▶  O        （O 就是 self-attention 这一层的输出）
```

[13:58]–[14:03]：「有时候我们会把这个 **A′** 叫做 **attention 的 matrix**。」
[14:11]–[14:15]：「所以 self-attention **输入是 I，输出是 O**。」

然后是本集前半段最重要的一段 [14:15]–[14:56]：

> 「虽然 self-attention 这边做了一个很复杂的操作，但是其实 self-attention layer 里面**唯一需要学的参数，就只有 Wq、Wk、跟 Wv 而已**。**只有 Wq、Wk、Wv 是未知的，是需要透过我们的训练资料把它找出来的。** 但是其他的操作都没有未知的参数，**都是我们人为设定好的**，都不需要透过 training data 找出来。」

⇒ 投影片 p25 上把这个结论标了两处：红圈框住 `Wq/Wk/Wv` 三块并拉箭头写 **`Parameters to be learned`**；底部黑条写 **「所以 Wq Wk Wv 是未知的」**。

![[P39_03_矩阵形式_QKV等于W乘I与待学参数.png]]
> 图注（投影片 **p25**，§2.2–§2.6 的**总结页**）：上半 `Q = Wq·I`（橙）、`K = Wk·I`（黄）、`V = Wv·I`（蓝），右边绿方块写着 **`I`**（= 输入那一排向量）；**红框框住 `Wq/Wk/Wv` 三块，红线拉出来写 `Parameters to be learned`**。下半是 §2.3–§2.5 的两步：`A′ ← A = Kᵀ Q`（灰块标 `A′`，左下注明 **`Attention Matrix`**），以及绿块 **`O = V A′`**；最底部黑条是老师那段的结论 **「所以 Wq Wk Wv 是未知的」**。
> ⭐ 这一页就是"**整层只有三张表要学**"这句话的全部证据 —— **§2.2 看它的上半**（从 a 得到 Q/K/V），**§2.6 看它的下半**（整条链子 + 参数）。

**补充（字幕没说，但很值得记一笔）**：**`Wq/Wk/Wv` 的大小与 sequence 长度 L 无关** —— 不管一句话是 5 个词还是 500 个词，要学的还是这三张表。这就是 self-attention 能被塞进任何 network、且不像 §7 的 CNN 那样被"输入大小"绑住的原因之一。

### 2.7 ⭐ 回答你的问题：`v¹`–`v⁴` 是向量吗？`V` 是矩阵吗？这样乘起来是不是有点奇怪？

**问题原文**：
> 「用线性代数的思路的话，v1-v4是向量吗？如果是的话那么V应该是一个矩阵，乘起来感觉会有点奇怪？」

**逐层回答**：

**① 是，`v¹`–`v⁴` 每一个都是一个向量。** 一个向量在这里就是"**一串数、直着写**"（老师：[11:20]「你把 v1 到 v4 当成大 V 这个矩阵的四个 **column** 把它拼起来」）。

**② `V` 不是新东西 —— 它就是这四列"并排放在一起"之后取的名字。** 所以 `V` 和 `v¹…v⁴` 装的是**同一批数**，只是排版方式不同。`I`、`Q`、`K`、`A`、`A′`、`O` 全都是这个意思（[04:40]–[04:52] 老师说 `I` 的时候就明说"你可以把 A1 到 A4 **拼起来**看作是一个矩阵"）。

**③ "乘起来奇怪"的感觉来自：`O = V A′` 里左右两边都是"一堆向量"，看不出谁配谁。** 解开它的唯一办法是 —— **别把它当矩阵乘法，当成"把上一集的加权求和换个写法"**：

| 上一集的逐个数写法（P38 .4） | 矩阵写法里对应哪一块 |
|---|---|
| `b¹ = α′₁₁·v¹ + α′₁₂·v² + α′₁₃·v³ + α′₁₄·v⁴`（四个向量各乘一个数再相加） | **`A′` 的第一个 column**（`α′₁₁ α′₁₂ α′₁₃ α′₁₄` 直着写）就是这四个权重；它乘 `V` 得 `O` 的第一个 column = `b¹` |
| `b² = α′₂₁·v¹ + α′₂₂·v² + α′₂₃·v³ + α′₂₄·v⁴` | **`A′` 的第二个 column** 乘 `V` ⇒ `O` 的第二个 column = `b²` |
| … | … |

⇒ **`O = V A′` 只是"一次把四条加权求和并行做完"的批量写法**，不是新的数学。老师在 [11:50]–[12:05] 说的就是这句话。

**④ 有一个前提值得记住**：`A′` 的 column 数必须等于 `V` 的 column 数，**两边都 = sequence 长度 L** —— 因为"每一个位置都要配一个输出"。这也是为什么 attention matrix **永远是 L×L**（这个 L 在 §5 讲语音时会变成大麻烦）。

**⑤ 顺带回答"为什么非要写成矩阵"**（补充，字幕没有直说）：因为 `b¹`–`b⁴` 是**同时**算出来的（§2.1 [00:50]–[01:02] 老师已经点过），而"同时算"在实作上就是"**一次矩阵乘法**"。这个优势会在 §7 变成 self-attention 对 RNN 的胜负手。

## §3 多头注意力 Multi-head Self-attention（[15:03]–[19:08]）

### 3.1 为什么需要多个 head（[15:03]–[16:19]）

[15:03]–[15:15]：self-attention 有一个进阶版本叫 **multi-head self-attention**，「其实今天的**使用是非常的广泛的**」。

[15:15]–[15:46] ⭐ **作业 4 的提示**（考试/作业重点）：

- 作业 4 里助教原来的 code 就有 multi-head self-attention，**head 的数目设成 2**；
- 「刚才助教给你提示说**把 head 的数目改少一点改成 1，其实就可以过 medium 的 baseline**」；
- ⚠️ 但 [15:28]–[15:39]：**并不代表所有的任务都适合用比较少的 head** ——「有一些任务，比如说**翻译**、比如说**语音辨识**，其实用**比较多**的 head，你反而可以得到比较好的结果」；
- [15:41]–[15:46]：「至于需要用多少的 head，这个又是另外一个 **hyperparameter**，也是你需要调的。」

[15:48]–[16:19] ⭐ **为什么要多个 head**：

> 「你可以想成说 **"相关"这件事情有很多种不同的形式、有很多种不同的定义**。所以也许我们不能只有一个 q，我们应该要有**多个 q，不同的 q 负责不同种类的相关性**。」

投影片右上角红字就是这个意思：**`Different types of relevance`**。

### 3.2 怎么做：q、k、v 各再乘几张小表，分裂成多个 head（[16:19]–[18:53]）

[16:25]–[16:46]：

```
a^i ──×Wq──▶ q^i ──×W^{q,1}──▶ q^{i,1}
                 └─×W^{q,2}──▶ q^{i,2}
```

⚠️ **上标有两个**：`i` 是**位置**（第几个向量），`1`/`2` 是**这个位置的第几个 head** [16:38]–[16:46]。「所以这边有 q1 跟 q2，代表说我们有两个 head，我们认为这个问题里面**有两种不同的相关性**，所以我们需要产生两种不同的 head 来找两种不同的相关性。」

[16:59]–[17:20]：**既然 q 有两个，那 k 也就要有两个，那 v 也就要有两个** —— 就是把 q、k、v **分别**乘上两个矩阵，得到不同的 head。

![[P39_04_MultiHead_两个head的qkv.png]]
> 图注（投影片 **p26**，Multi-head 的第一版）：左上两条公式 **`q^{i,1} = W^{q,1} q^i`**、**`q^{i,2} = W^{q,2} q^i`**；底部 **`q^i = W^q a^i`**（绿色 `a^i`），绿箭头表示 `q^i/k^i/v^i` **各自再分裂**成两份（`q^{i,1} q^{i,2}`、`k^{i,1} k^{i,2}`、`v^{i,1} v^{i,2}`），右边是另一个位置 `a^j` 的同一套（`q^{j,1} …`）；中段的 ⊗ 与黑线画的是**第一个 head 的 attention**（上面只出现绿色 **`b^{i,1}`** 一格）；底部中间写着 **`(2 heads as example)`**。

[17:35]–[18:22] **接下来怎么做 self-attention？跟之前一模一样，只是"1 那一类的一起做，2 那一类的一起做"**：

- 「这个 `q^{i,1}` 在算 attention 的分数的时候，他就**不要管那个 k² 了**，他就只管 `k¹` 就好」[17:46]–[17:57] ⇒ `q^{i,1}` 跟 `k^{i,1}`、`k^{j,1}` 算 dot product（[18:02] 字幕 `dapada` = dot product）；
- 「今天在做 weighted sum 的时候，**也不要管 v² 了**，看 `v^{i,1}` 跟 `v^{j,1}` 就好」[18:08]–[18:14]（字幕 `waiting sound` = weighted sum）；
- ⇒ 得到 **`b^{i,1}`**。
- 第二个 head 照做一遍：`q^{i,2}` 只对 `k^{i,2}` 做 attention、只对 `v^{i,2}` 做 weighted sum ⇒ 得到 **`b^{i,2}`** [18:27]–[18:41]。

[18:42]–[18:46]：「如果你有多个 head、有 8 个 head、有 16 个 head，那也是一样的操作，**这边是用两个 head 来当做例子**。」

![[P39_05_MultiHead_bi1与bi2.png]]
> 图注（投影片 **p27**，与上一张**版式几乎相同的相邻一页**）：差别只在**绿色方块变成两个 —— `b^{i,1}` 与 `b^{i,2}`**（= 两个 head 各自算完了），并且 **`q^{i,2}` 被画上红框**（老师此刻正在讲第二个 head）。⭐ 这两页连起来看就是"投影片一格格补上去"的过程：p26 = 只讲了第一个 head，p27 = 第二个 head 也算完。

### 3.3 把两个 head 接起来，再乘一张表 `W^O`（[18:53]–[19:08]）

[18:57]–[19:08]：

> 「接下来你可能会把 `b^{i,1}` 跟 `b^{i,2}` **把它接起来**（concatenate），然后再通过一个 transform，也就是**再乘一个矩阵**，然后得到 `b^i`，然后再送到下一层去。」

![[P39_06_MultiHead_接起来乘WO得到bi.png]]
> 图注（这张是从投影片上**裁下来的一段**，看不到页码）：左 = 绿色 `b^i`；中间 = 蓝色大块 **`W^O`**；右边 = 一个竖着的长框，里面上下叠着绿色 `b^{i,1}`、`b^{i,2}`（= 接起来之后的向量）⇒ 整条读作 **`b^i = W^O · [ b^{i,1} ; b^{i,2} ]`**。⚠️ 这张图和 §3.2 的两张是同一件事的**后半**（§3.2 停在 `b^{i,1}`/`b^{i,2}`，这张图才是"送进下一层"）。

⚠️ **字幕坑**：[19:03] 说"再乘**三个**矩阵"是听写错 —— 这里只有**一张** `W^O`。（同一段的 [17:14]–[17:20]"乘两个矩阵、两个矩阵、两个矩阵"指的是 `q`、`k`、`v` **各自**乘两张表，不是乘三张。）

## §4 位置资讯 Positional Encoding（[19:15]–[25:00]）

### 4.1 问题：self-attention 眼里"天涯若比邻"（[19:15]–[21:03]）

[19:15]–[19:25]：「讲到目前为止，你会发现 **self-attention 的 layer 少了一个也许很重要的资讯** …… 这个资讯是**位置的资讯**。」

[19:28]–[19:41]：「每一个 input，它是出现在 sequence 的**最前面还是最后面**，它是**完全没有这个资讯**的。」

[19:42]–[20:02] ⭐ 老师自己拆掉一个常见误解：

> 「你可能说，刚才不是说 input 就是有位置 1234 吗？**但是那个 1234 是我们画在投影片上的时候，为了帮助大家理解所标上的一个编号。** 你想想看，对 self-attention 而言，那个位置 1 跟位置 2 跟位置 3 跟位置 4 有任何差别吗？**完全没有任何差别** —— 这四个位置的操作其实是一模一样的。」

[20:06]–[20:29] ⭐ 本集名句（字幕写成"天涯落臂林／天涯落臂零"）：

> 「对它来说，1 跟 4 的距离并没有特别远，2 跟 3 的距离也没有特别近，对它来说就是 **天涯若比邻** —— **所有的位置之间的距离都是一样的**。也没有任何一个位置距离比较远，也没有任何位置距离比较近，也没有谁在整个 sequence 的最前面，也没有谁在整个 sequence 的最后面。」

[20:31]–[21:03] **但这样设计可能会有问题**：位置的资讯有时候也许很重要。例子是 **POS tagging（词性标记）**——

> 「也许你知道说，**动词比较不容易出现在句首**。所以如果我们知道说某一个词汇它是放在**句首**的，那它是动词的可能性可能就比较低。」（字幕 `聚首` = 句首）

⇒ 「可是在我们到目前为止讲的 self-attention 的操作里面，它根本就没有位置的资讯。」

### 4.2 解法：给每个位置一个专属向量 `e^i`，把它加到 `a^i` 上（[21:03]–[22:52]）

[21:03]–[21:20]：「如果你觉得位置的资讯是一个重要的事情，那你可以**把位置的资讯把它塞进去** …… 这边就要用到一个叫做 **positional encoding** 的技术。」

做法只有三步 [21:22]–[21:49]：

1. **为每一个位置设定一个 vector**，叫做 **positional vector `e^i`**（上标 i 代表位置）；
2. **每一个不同的位置都有它专属的 `e`**（`e¹` 是一个向量、`e²` 是一个向量、`e²⁸` 是一个向量……）；
3. **把这个 `e` 加到 `a^i` 上面 —— 就结束了**。

[21:52]–[22:02]：为什么这样就行了？「你等于就是告诉你的 self-attention 位置的资讯，**如果它看到说 `a^i` 好像有被加上 `e^i`，它就知道说现在出现的位置应该是在 i 这个位置**。」

⚠️ **加的位置很关键**：是加在**输入 `a^i`** 上（在算 q、k、v **之前**），**不是**加在 q、k、v 上 —— 投影片左下角画的就是 `e^i + a^i → q^i k^i v^i`。

![[P39_07_PositionalEncoding_ei加到ai上.png]]
> 图注（投影片 **p29**）：标题 **`Positional Encoding`**；左边四条 bullet —— **`No position information in self-attention.`**（= §4.1 那一整段）、**`Each position has a unique positional vector e^i`**、**`hand-crafted`**、**`learned from data`**（后两条 = §4.3 要讲的两种来源）；左下角是流程图 **`e^i`（灰）+ `a^i`（绿）`→` `q^i k^i v^i`**（★ 就是"加在 a 上、不是加在 q/k/v 上"的证据）；右边是一张彩色热力图，右上写 **`Each column represents a positional vector e^i`**，并用一个**黑色长框圈出其中一整个 column**（= 某个位置的 `e^i`），底部色条从 **-1 到 1**。

### 4.3 `e^i` 从哪里来：人设（sin/cos）还是学出来？—— 老师说这题还没有定论（[22:52]–[25:00]）

[22:05]–[22:13]：最早的那个 transformer（也就是 `Attention is all you need` 那篇 paper）用的 `e^i`，"长的是这个样子"（就是上一张图的热力图）。

[22:52]–[23:00]：这种 positional vector 是 **hand-crafted** 的，也就是**人设的**。

[23:00]–[23:08] ⚠️ **人设的第一个问题**：「假设我现在在定这个 vector 的时候，**只定到 128**，那我现在 sequence 的长度如果是 **129** 怎么办呢？」

[23:08]–[23:18]：不过在最早的 paper 里"比较没有这个问题"，因为那个 vector **是透过某一个规则所产生的** ——「透过一个很神奇的 **sin、cos** function 所产生的」。

[23:23]–[23:31] ⚠️ **第二个问题**：「那当然你又会有新的问题 —— **为什么是 sin 跟 cos 呢？为什么不是别的东西呢？** 为什么一定要这样产生 hand-crafted 的 positional vector 呢？」

[23:31]–[23:46] ⭐ 老师的立场：

> 「其实**你不一定要这么产生**。这个 positional encoding **仍然是一个尚待研究的问题**，你可以创造自己新的方法，**或甚至 positional encoding 是可以根据资料学出来的**。」（⚠️ 字幕 `上代研究` = **尚待研究**）

[23:46]–[25:00] 参考资料与投影片 p30 的内容：

- 引用了一篇"**去年**放在 arXiv 上的论文"（= 2020 年，`https://arxiv.org/abs/2003.09229`），里面**比较了**各种 positional encoding 并**提出**了新的做法；
- 投影片右上角的 **Table 1. Comparing position representation methods**（三个维度：`Inductive` / `Data-Driven` / `Parameter Efficient`）：

## §5 用在语音上：向量太多 ⇒ Truncated Self-attention（[25:00]–[27:57]）

### 5.1 问题：语音的向量序列非常长（[25:19]–[26:15]）

[25:19]–[25:36]：self-attention「**不是只能用在 NLP 相关的应用上**」，做语音的时候也可以用 —— 但「你可能会希望对 self-attention **做一些小小的改动**」。

[25:39]–[26:15] **为什么要改**：一段声音讯号要表示成一排向量，而这排向量**可能会非常的长** —— 因为**每一个向量其实只代表了 10ms 的长度** [25:50]–[25:56]，所以

> 「如果今天是一秒钟的声音讯号，它就有 **100 个向量**；5 秒钟的声音讯号就 **500 个向量**；**你随便讲一句话都是上千个向量了**。」

（⇒ 与 P38 §2.3 的"window 25ms、右移 10ms ⇒ 1 秒 100 个 frame"是同一件事。）

### 5.2 代价：attention matrix 的大小是"长度的平方"（[26:17]–[26:58]）

[26:17]–[26:37]：

> 「你想想看，我们今天在计算这个 **attention matrix** 的时候，它的 **complexity 是长度的平方** —— 你要计算这个 attention matrix，你需要做 **L 乘以 L 次的 inner product**。」

[26:37]–[26:58]：**L 大的两个后果** ——①「它的**计算量**就很可观」；②「如果 L 很大的话，你也需要**很大的 memory** 才能够把这个矩阵存下来」。⇒「你讲一句话，那句话所产生的这个 attention matrix **可能会太大，大到你根本就不容易处理、不容易训练**。」

![[P39_09_SelfAttentionForSpeech_向量太多与L平方.png]]
> 图注（投影片 **p32**，第一版）：标题 **`Self-attention for Speech`**，右上 `https://arxiv.org/abs/1910.12977`；左上就是 §5.1 那句话 **`Speech is a very long vector sequence.`**（配一段波形，标 **`10ms`**）；左下是 §5.2 的代价 —— **`If input sequence is length L`** ⇒ 一个 **L×L** 的大灰块，横轴标 `L`、纵轴标 `L`，块里写 **`A′`**，底下注明 **`Attention Matrix`**；右边是这一层的输入输出（蓝 `a¹`–`a⁴` → 浅蓝自注意力层 → 绿 `b¹`–`b⁴`）。

### 5.3 一招：Truncated Self-attention（[27:00]–[27:57]）

[27:00]–[27:11]：

> 「所以在做语音的时候，有一招叫做 **truncated self-attention**。truncated self-attention 做的事情就是 —— 我们今天在做 self-attention 的时候，**不要看一整句话，我们就只看一个小的范围就好**。」

[27:15]–[27:17]：**范围应该有多大，那个是人设定的。**

[27:20]–[27:41] ⭐ **为什么可以只看小范围？**「那就取决于**你对这个问题的理解**」——

> 「也许我们要辨识这个位置有什么样的 **phoneme**（字幕 `phoning`）、这个位置有什么样的内容，我们**并不需要看整句话**，只要看这句话**跟它前后一定范围之内**的资讯，其实就可以判断。」

[27:41]–[27:54]：所以也许没有必要让 self-attention 考虑一整个句子，「也许只需要考虑一个小范围就好，**这样就可以加快运算的速度**」。

> 图注（投影片 **p32** 的**第二版** —— 与上一张是同一页，截图**顶部被裁掉**（标题那行只剩一点），右下页码同样是 **32**）：上面一排绿 `b¹`–`b⁴`，蓝括号写着 **`Attention in a range`**（只括住 `b²`–`b⁴` 一段）；中间是自注意力层，里面画着蓝箭头 —— **`a³`（被红框框住 = 现在要处理的位置）只往 `a²` 拉一条、往 `a⁴` 拉一条**，而往 `a¹` 的那一条上**打了一个大红 ✗**；`a¹`／`b¹` 被灰色涂掉 = 落在范围外；底部大字 **`Truncated Self-attention`**。

### 5.4 ⭐ 回答你的问题：这跟 P38 的"整段一个 label"是一回事吗？要到 P51 讲吗？

**问题原文**：
> 「由于语音的切片过多，导致算出来的 α′ 矩阵的 L 太大不好计算，**可以将多个输入向量放在一起考虑**（不知道这样是不是对应了上节课讲的整个 sequence 对应一个 label 的 self-attention，还是说这个内容要到 P51 讲）」

**(a) 前半段 ✅ 完全正确**：切片多（10ms 一个）⇒ α′ 矩阵的 L 太大不好算 —— 就是 [25:56]–[26:39] 那两段（1 秒 100 个向量 + complexity 是长度的平方）。

**(b) 「可以将多个输入向量放在一起考虑」⚠️ 描述方向要换一换**：

- 老师给的做法**不是"合起来考虑"，而是"把范围切小"** —— 名字是 **truncated self-attention** [27:00]；
- 重点有两个：**① 只看一个小范围**（省算力）；**② 范围多大是人设定的** [27:15]–[27:17]。
- ⚠️ 第 ② 点特别值得留意：self-attention 本来标榜的是"**关联性由机器自己学出来**"，而 truncated 这一步是**人先替它划了一个界**。这个味道更接近 CNN 的 receptive field —— 所以 里老师拿 CNN 来类比，不是巧合。
- ⚠️ **别和"合并 frame"混了**（2026-09-29 课后追问补写）：如果你说的"放在一起"指的是"**把相邻的几个 frame 合成一个向量**"，那是**另一个**做法（**下采样**，会**改变序列长度**）—— ⚠️ **本集完全没讲**；truncated **不改长度**，只是限制**每个位置能看多远**。

**(c) 它和 P38 的"整个 sequence 对应一个 label"❌ 不是一回事**（🧩 两件事被并到一起了）：

| | P38 的三种输出类型 | truncated self-attention |
|---|---|---|
| 分的是什么 | **self-attention 的输出要拿给谁用**（每个向量一个 label／整句一个 label／seq2seq） | **self-attention 内部，一个向量允许看多远** |
| 层面 | **任务**的分类 | **layer 本身**的改动 |
| 关系 | 两者**互相独立、可以任意组合** | |

⭐ 而且**语音辨识在 P38 就已经被归到第三类了**（不是第二类）—— P38 [11:42]–[11:46] 原话：

> 「或者是**语音辨识** …… 真正的语音辨识**也是一个 sequence to sequence 的任务**，输入一句话然后输出一段文字。」

⚠️ **顺带钉死一个最容易连错的地方（2026-09-29 课后追问补写）**：「**把多个输入向量放在一起考虑**」**不是某一类输出的特征** —— 它是 **self-attention 层本身的性质**（P38：「进几个 vector 出几个 vector」，而且**每个输出都看过整个 input sequence**）⇒ **三种输出类型都有它**，所以它**区分不出 seq2seq**。

⚠️ 而且**类型二和类型三不是一条链子上的两步**：不要读成"**先把多个向量合成一个值、再长出序列**"—— 这两件事是**从同一个输入出发的平行选项**，没有先后关系。

| 输入 | 输出 | P38 的类型 | 实例 |
|---|---|---|---|
| n 个向量 | **n 个** label（一一对应） | 类型一 = sequence labeling | POS tagging／音素分类（**作业二**） |
| n 个向量 | **1 个** label | 类型二 | sentiment analysis／语者辨认（**作业四**） |
| n 个向量 | **m 个**（**m 由机器决定**） | **类型三 = seq2seq** | 翻译／真正的语音辨识（**作业五**） |

⇒ seq2seq 真正特别的地方只有一句：**输出长度是机器自己决定的**（P38 [11:05]–[11:19]），所以它需要一整套 Encoder-Decoder（**P49–P50**），而不是一层 self-attention 就完事。

**前瞻（本课还没讲，等 P49–P50 验证）**：seq2seq 的 decoder 确实是"**一次吐一个**、再把吐出来的接回去"这样长出一整条序列 —— 如果当时脑子里想的是这个，那这个直觉**会在 seq2seq 的 decoder 那里找到落点**；但 **P38/P39 一个字都没讲**，现在先别当成已学的东西记。

**(d) 也不是 P51**（这一条顺手查了播放列表，值得记）：

- **P51 = 「2022 - 各式各样神奇的自注意力机制 (Self-attention) 变型」（1:11:16）** —— 它讲的正是**本集结尾** [43:30]–[45:03] 那一小段提到的东西（有哪些 xx-former、怎么把运算量降下来），**不是**语音辨识。
- 真正把 **seq2seq / Encoder-Decoder** 讲清楚的是**第 5 讲的 P49–P50 `Transformer (上)/(下)`**（P48 是批次标准化）。

## 用在影像上，以及与 CNN 的关系（[27:57]–[35:13]）

### 6.1 换个角度看一张图片：它也是一堆向量（[27:57]–[29:18]）

[28:06]–[28:18]：到目前为止 self-attention 的适用条件是"**输入是一排向量 / 一个 vector set**"。

[28:18]–[28:32]：「那我们之前在讲 CNN 的时候，我们是跟大家说**影像一张图片，我们把它看作是一个很长的向量**。那其实一张图片，我们也可以**换一个观点**，把它看作是一个 **vector 的 set**。」

[28:36]–[29:06]：怎么换？—— 一张解析度 **5×10** 的图片可以看作一个 **tensor，大小是 5×10×3**（3 代表 RGB 三个 channel）；**每一个位置的 pixel 就是一个三维的向量**；所以整张图片「其实就是 **5×10 个向量**」。⇒「影像这个东西其实也是一个 vector set，它既然也是一个 vector set 的话，**你完全可以用 self-attention 来处理一张图片**。」

### 6.2 已经有人这么做了：Self-Attention GAN 与 DETR（[29:15]–[29:25]）

[29:15]–[29:25]：「有没有人用 self-attention 来处理一张图片呢？**是有的** —— 这边就举了两个例子」，而且「现在把 self-attention 用在影像处理上，也不算是**一个非常石破天惊的事情**」（字幕 `死破天惊`）。

![[P39_11_影像上的应用_SelfAttentionGAN与DETR.png]]
> 图注（投影片 **p34**，上下两个应用各占一半）：
> **上 = `Self-Attention GAN`**（右边写 `https://arxiv.org/abs/1805.08318`）：左边是 `convolution feature maps (x)`（一叠蓝格）→ 分成三路 **1×1 conv**，分别得到 `f(x)`（黄）、`g(x)`（绿）、`h(x)`（紫）；`f(x)` 与 `g(x)` 的 `transpose` 相乘（⊗）→ `softmax` → **`attention map`**（一张黑白格）；`attention map` 再与 `h(x)` 相乘（⊗）→ 右边橙色的 **`self-attention feature maps (o)`**。

### 6.3 CNN = 简化版的 self-attention（[29:25]–[31:32]）

[29:38]–[30:05]：如果用 self-attention 处理一张图片 —— 「假设这个是你**要考虑的 pixel**，那它**产生 query**，**其它 pixel 产生 key** …… 你今天在做 inner product 的时候，你考虑的不是一个小的（范围），而是**整张影像的资讯**」。

[30:05]–[30:19]：而 CNN 里「每一个 filter、每一个 neuron **只考虑 receptive field 范围里面**的资讯」。

⭐ [30:22]–[30:24]：

> 「所以如果我们比较 CNN 跟 self-attention 的话，我们可以说 **CNN 是什么？CNN 可以看作是一种简化版的 self-attention**。」

[30:42]–[30:47]：或者反过来说，「**self-attention 是一个复杂化的 CNN**」。

[30:47]–[31:30] ⭐ **第二个差别（更关键）**：

- 在 CNN 里，**receptive field 的范围跟大小是人决定的**；
- 而对 self-attention 而言，「我们用 attention 去找出相关的 pixel，**就好像 receptive field 是自动被学出来的** —— neuron 自己决定说 receptive field 的**形状**长什么样子，neuron 自己决定说以这个 pixel 为中心，**哪些 pixel 是我们真正需要考虑的、哪些 pixel 是相关的**。」
- ⇒「所以 **receptive field 的范围不再是人工划定，而是让机器自己学出来**。」

![[P39_12_SelfAttentionVsCNN_01矩阵与感受野.png]]

### 6.4 论文：CNN 就是 self-attention 的特例（[31:32]–[32:19]）

[31:36]–[31:45]：

[31:50]–[31:53]：**self-attention 只要设定合适的参数，它可以做到跟 CNN 一模一样的事情。**

[31:57]–[32:15]：所以 —— CNN 的 **function set** 长这个样子、self-attention 的 function set 长那个样子 ⇒

[32:19]–[32:28]：这篇 paper 放到网路上的时间是 **2019 年 11 月** ⇒「所以你知道，这些我们今天上课里面讲的东西，其实都是**很新的资讯**」。

### 6.5 更 flexible 的代价：资料量实验（ViT）（[32:19]–[34:48]）

[32:28]–[32:45]：既然 CNN 是 self-attention 的 subset、self-attention 比较 flexible —— 那记不记得讲 overfitting 时说过：

> 「**比较 flexible 的 model 比较需要更多的 data**，如果你 data 不够就有可能 overfitting；而比较有限制的 model，它适合在 **data 少**的时候，它可能比较不会 overfitting，那如果你这个限制设得好，也会有不错的结果。」

[32:57]–[33:06]：用不同的 data 量来训练 CNN 跟 self-attention，**确实可以看到这个现象**。

[33:06]–[33:37] 实验出处：Google 的 paper **`An Image is Worth 16x16 Words`**（`arXiv 2010.11929`）—— 它把一张影像拆成 **16×16 的 patch**，「它把每一个 patch 就想象成是一个 **word**」，因为 self-attention 比较常用在 NLP 上，「所以它就取了一个很 fancy 的 title，叫做**一张图值 16×16 个文字**」。

[33:37]–[34:26] **怎么看这张图**：

- **横轴 = 训练影像的量**：`10M`（1000 万张 —— 对 Google 来说这是"资料量比较小"的 setting）→ `30M` → `100M` → `300M`（3 亿张）；
- **self-attention = 浅蓝色的线；CNN = 深灰色的线**；
- ⭐「随着资料量越来越多，self-attention 的结果就越来越好，**最终在资料量最多的时候，self-attention 可以超过 CNN**；**但在资料量少的时候，CNN 可以比 self-attention 得到更好的结果**。」

[34:26]–[34:48] **怎么解释**（把结论接回弹性）：

> 「self-attention 它**弹性比较大**，所以需要**比较多**的训练资料，训练资料少的时候就会 overfitting；而 CNN 它**弹性比较小**，在训练资料少的时候结果比较好，**但训练资料多的时候，它没有办法从更大量的训练资料得到好处**。」

⭐ 这一节的骨架**全压在一页投影片上** —— 先把整页放出来当总览（上半是 RNN 的运作、下半是 self-attention 的对比），底下 7.1–7.4 再逐块拆开：

![[P39_15_SelfAttentionVsRNN_平行化与天涯若比邻.png]]
> 图注（投影片 **p38**，整节的内容都压在这一页上）：**上排 = `Recurrent Neural Network (RNN)`** —— 最左边一个灰色的 `memory` 方块，接着四个 `RNN` 方块串起来（每个箭头都吃"前一个 RNN 的输出 + 下一个输入"），每个 RNN 上面接一个 `FC`；两个红框标出最左与最右的 token，配红字 **`hard to consider`**；右下角蓝框写 **`nonparallel`**（蓝虚线连接四个 FC 的输出 = "必须一个一个来"）。**下排 = `Self-attention`** —— 一根灰色长条（自注意力层），上面四个输出（蓝绿蓝黄四色竖条）用蓝虚线框起来、标 **`parallel`**，配红字 **`easy to consider`**，中间还有一个红色爆炸贴纸写 **`WIN`**。底部是论文标题 **`Transformers are RNNs: Fast Autoregressive Transformers with Linear Attention`** + `https://arxiv.org/abs/2006.16236`。

### 7.1 先看 RNN 长什么样（[35:13]–[36:52]）

[35:13]–[35:18]：RNN = **recurrent neural network**。

⚠️⭐⭐ [35:18]–[35:32] **老师先声明这门课不讲它**：

> 「其实在这门课里面，我们现在就**不会讲到 recurrent neural network**，因为 **RNN 的角色很大一部分都可以用 self-attention 来取代了**，所以在这门课里面，我们就不会再特别把 RNN 拿出来讲。」

[35:32]–[36:52] 那就"很快的三言两语把它带过去"：

- RNN 跟 self-attention 一样，**都是要处理 input 是一个 sequence 的状况**；
- 有一个 **memory 的 vector** + 一个 **RNN 的 block**；RNN block **吃 memory 的 vector、吃第一个 input 的 vector**，然后 output 一个东西（通常叫 hidden layer 的 output），再通过 fully connected 去做你想要的 prediction；
- 第二个 vector 进来的时候：**把第二个 vector 当作 input、把前一个时间点吐出来的东西当作下一个时间点的输入**，再丢进 RNN，产生新的 vector，再拿给 FC；
- 第三个、第四个时间点同理。

[40:14]–[40:32]：RNN 的部分这门课不提，「以下是这一门课之前的上课录影」，而且「因为这一次不会讲到，所以特别有做了**英文的版本**，RNN 是中文英文版本都同时有放在 YouTube 上面」。
⇒ **本笔记库 对应 P40/P41（选修）RNN Part I / Part II**。

### 7.2 相同点（[36:52]–[37:19]）

- **input 都是一个 vector sequence**（老师把这句话讲了两遍 [36:57]、[37:00]）；
- self-attention 的 output 是另外一排 vector，**里面的每一个 vector 都考虑了整个 input 的 sequence**，再给 fully connected 做处理；
- RNN 也会 output 另外一排 vector，也会给 fully connected 做进一步的处理。

### 7.3 三个不同（[37:20]–[39:36]）

**(1) "看不看得到右边"—— ⚠️ 这个差别可以被抹平**

[37:20]–[37:38]：「当然一个非常显而易见的不同，你可能会说这边的每一个 vector 它都考虑了整个 input sequence，而 RNN 每一个 vector **只考虑了左边已经输入的 vector，它没有考虑右边的 vector**。那**这是一个很好的观察** ……」

⚠️ [37:40]–[37:55] 但是：「**RNN 其实也可以是双向的**（bidirectional），所以如果你 RNN 用双向的 RNN，其实 …… 每一个 memory 的 output 其实也可以看作是考虑了整个 input 的 sequence。」
⇒ **所以"只能往前看"不是本质差别**，别拿它当 self-attention 的优势。

**(2) 远距离的资讯"要一路搬、还不能忘"** ⭐

[37:55]–[38:23]：「就算你用 bidirectional 的 RNN，还是有一些差别的 —— 对 RNN 来说，假设最右边这个黄色的 vector 要考虑最左边的这个输入，那**它必须要把最左边的输入存在 memory 里面，然后接下来都不能够忘掉，一路带到最右边**，才能够在最后一个时间点被考虑。」

[38:23]–[38:36] 对比：「但对 self-attention 来说**没有这个问题** —— 它只要这边输出一个 query、这边输出一个 key，**只要它们 match 的起来，天涯若比邻**，你可以从非常远的 vector、在整个 sequence 上非常远的 vector，**轻易的抽取资讯**。」

**(3) ⭐ 更主要的不同：RNN 没有办法平行化**（[38:42]–[39:36]）

- [38:42]–[39:07]：「RNN 今天在处理的时候，input 一个 sequence、output 一个 sequence 的时候，**RNN 是没有办法平行化的**。你要先产生这个向量，接下来产生这个向量，才产生这个向量、才产生这个向量。所以 RNN …… **没有办法一次处理、没有办法平行处理所有的 output**。」
- [39:07]–[39:30]：「但 self-attention 有一个优势，是**它可以平行处理所有的输出** —— 你今天 input 一排 vector，在 output 这四个 vector 的时候，**这四个 vector 是平行产生的，并不需要等谁先运算完才把其他人运算出来**。」
- ⇒「所以在**运算速度**上，self-attention 会比 RNN 更有效率。」
- [39:36]–[39:46]：「那你今天发现说，**很多的应用都往往把 RNN 的架构逐渐改成 self-attention 的架构了**。」

⭐ 这条(3) 正好接回 §2.1 埋的伏笔：老师在开场就说过 `b¹`–`b⁴` 是**一次同时被计算出来的** —— 那就是"平行化"本身。

### 7.4 想更深入：论文《Transformers are RNNs》（[39:46]–[40:14]）

[39:46]–[39:58]：「如果你想要更进一步了解 RNN 跟 self-attention 的关系的话，你可以看下面这篇文章 —— **Transformers are RNN**（= Transformers are RNNs，`arXiv 2006.16236`），里面会告诉你说 **self-attention 你加上了什么东西以后，其实它就变成了 RNN**。」

[40:03]–[40:09]：这篇是**去年六月**放到 arXiv 上的 ⇒「所以今天讲的都是一些**很新的研究成果**」。

## §8 还能用在哪：graph（GNN）与各式各样的变形（[40:32]–[45:03]）

### 8.1 graph：edge 就是现成的"关联性"（[40:32]–[43:30]）

[40:32]–[40:50]：self-attention 也可以被用在 **graph** 上面 —— 「记得我们在这一份投影片一开始的时候就跟你说过说，**graph 也可以看作是一堆 vector**，那如果是一堆 vector，就可以用 self-attention 来处理」。

[40:55]–[41:20] ⭐ **graph 上特别的地方**：

> 「在 graph 上面，**我们不只有每一个 node**（每一个 node 可以表示成一个向量），**但我们不只有 node 的资讯，我们还有 edge 的资讯** —— 我们知道哪些 node 之间是有相连的，也就是哪些 node 是有关联的，我们知道哪些向量间是有关联的。」

[41:20]–[41:41] ⭐⭐ **这一步是本段的关键**：

> 「那之前我们在做 self-attention 的时候，所谓的**关联性是机器自己找出来的**。但是现在既然有了 graph 的资讯、有了 edge 的资讯，那**关联性也许就不需要透过机器自动找出来** —— **这个图上面的 edge，已经暗示了我们 node 跟 node 之间的关联性**。」

[41:41]–[42:29] 于是你用 self-attention 时**有一个选择**：

- **计算 attention matrix 的时候，只计算有 edge 相连的 node 就好了** —— 例：`1` 跟 `8` 有相连，那只算 1 跟 8 之间的 attention 分数；1 跟 6 相连 ⇒ 只算 1 跟 6；1 跟 5 相连 ⇒ 只算 1 跟 5；2 跟 3 相连 ⇒ 只算 2 跟 3；以此类推；
- 「那如果两个 node 之间没有相连，那其实很有可能就暗示我们这两个 node 之间没有关系。既然没有关系，**我们就不需要再去计算它的 attention score，直接把它设为 0 就好了**。」

[42:29]–[42:41]：为什么可以这么理直气壮？—— 「因为这个 graph 往往是**人为根据某些 domain knowledge 建出来的**，那 domain knowledge 已经告诉我们说这两个向量彼此之间没有关联，**我们就没有必要再用机器去学习这件事情**。」

⭐⭐ [42:42]–[43:07] **这就叫 GNN**：

> 「其实当我们把 self-attention **按照我们这边讲的这种限制**用在 graph 上面的时候，**其实就是一种 graph neural network，也就是一种 GNN**。 …… 那我不会说 self-attention 就能够涵盖所有 GNN 的各种变形，但 **self-attention 用在 graph 上面，是某一种类型的 graph neural network**。」

[43:07]–[43:27]：「GNN 这边坑也是很深」，助教之前上课大概花了**快三个小时**在讲 graph neural network 而且**还没讲完** ⇒ 不是今天这堂课能讲的内容。
⇒ **本笔记库 对应 P42–P43（选修 GNN）**。

### 8.2 各式各样的变形：xx-former 用 performance 换速度（[43:30]–[45:03]）

[43:30]–[43:51]：self-attention 有**非常非常多**的变形 —— 可以看 **Long Range Arena** 这篇 paper，里面比较了各种不同的 self-attention 的变形。**为什么会有这么多变形？**

> 「因为 self-attention **最大的问题就是它的运算量非常的大**，所以**怎么样减少 self-attention 的运算量，是一个未来的重点**。」

[43:56]–[44:21] ⭐ 一个很好用的名词线索：

- self-attention 最早用在 **transformer** 上，所以「**很多人讲 transformer 的时候，其实它指的就是 self-attention**」；
- [44:04]–[44:08]「有人说，**广义的 transformer 指的就是 self-attention**」；
- ⇒ 所以后来各式各样 self-attention 的变形**都叫做什么 former** —— 投影片举的例子是 **Linformer、Performer、Reformer**（字幕 `Limformer` = Linformer）。

[44:21]–[44:41] 怎么看投影片那张二维图：**往右 = 运算的速度**（横轴）、**纵轴 = performance** ⇒「有很多各式各样新的 xx-former，它们的**速度会比原来的 transformer 快**，**但是快的速度带来的就是 performance 变差** …… 所以它们往往比原来的 transformer performance 差一点，但是速度会比较快。」

[44:41]–[44:52]：「那到底什么样的 self-attention 才能够真的**又快又好**？这仍然是一个**尚待研究**的问题。」

[44:49]–[45:03]：想进一步研究可以看 **Efficient Transformers** 那篇 paper，「这个就不是我们这一门课可以讲的东西了」。
⇒ **本笔记库 对应 P51（2022）「各式各样神奇的自注意力机制变型」**。

## §9 我的理解（本轮复述与判定）

### 9.1 复述照录（原文不改）

> **第一部分**：老师延续上一集的内容继续讲（没有讲另外两种 self-attention 的模式），第一个部分是将上一集的数学部分整理为矩阵（用线性代数的思路的话，v1-v4 是向量吗？如果是的话那么 V 应该是一个矩阵，乘起来感觉会有点奇怪？），Wk,Wq,Wv 是需要从训练资料中找出来的参数
>
> **第二部分**：多头注意力——将 q,k,v 乘上多个不同的矩阵分裂出多个 head，每个 head 代表一种类别的联系
>
> **第三部分**：位置编码，将训练资料上一行行（列）的向量加到 a_i 上来让模型能够辨认输入向量之间的位置关系
>
> **第四部分**：self-attention 在语音辨识中的应用：由于语音的切片过多，导致算出来的 α′ 矩阵的 L 太大不好计算，可以将多个输入向量放在一起考虑（不知道这样是不是对应了上节课讲的整个 sequence 对应一个 label 的 self-attention，还是说这个内容要到 P51 讲）
>
> **第五部分**：self-attention 与 CNN 架构做对比，指出 CNN 架构是一种特殊的 self-attention（感受野固定），而 self-attention 能根据训练资料自行推断出感受野的形状位置和大小，能凭借适当的参数达到和 CNN 一样的效果。同时在使用大的训练资料的情况下，CNN 的辨识能力不如 self-attention 用于图像辨识
>
> **第五部分（实为第六）**：self-attention 与 RNN 架构做对比，RNN 架构是由 memory 向量对一个 sequence 中的所有向量依次进行考虑，将考虑后的记录留在 memory 向量中并继续考虑下一个向量——因此不能并行运算，且后面考虑的向量受到前面的向量的影响会比较少（可能会"遗忘"），而 self-attention 能够直接考虑一个 sequence 中所有向量的联系并进行并行运算，所以 self-attention 对比 RNN 会有很多优势（RNN 的技术细节下面两节课会细讲）
>
> **总评**：感觉 self-attention 从对 sequence 的向量进行考虑出发，变成一个非常万能（什么领域都能做好）并且效果强大的架构

## §10 易错点与纠正

1. **矩阵乘法的左右顺序：以投影片为准，别跟着口述抄。** 本集至少出现两次"口述顺序与投影片相反"：
   - `Q = Wq·I`（投影片 p25）vs 口述 [05:26]「把 I 乘上 Wq」；
   - `O = V A′`（投影片 p24）vs 口述 [12:41]「把 A′ 乘上 V」。
   ⇒ 记住老师的**图纸约定**：**一个向量 = 直着写的一列**；在这个约定下 `Kᵀ Q`、`Wq·I`、`V A′` 才是对的。
2. **softmax 是"对 column"做**（[10:15]–[10:21]），不是对 row —— 因为一个 column 里的那一排 α′ 正好是"某个位置对所有位置"的权重、加起来 = 1。
3. **`Â`／`α̂` 与 `A′`／`α′` 是同一个东西**（老师当场改记号，p24 上还留着旧版，见 §2.4）。
4. **位置资讯是加在 `a^i` 上**（进 self-attention 之前），**不是加在 q/k/v 上**。
5. **多头不是"多套独立的 self-attention 层"，而是同一层里把 q/k/v 各分裂成几份**；而且**每个 head 只跟"同一号"的 k、v 打交道**（`q^{i,1}` 不管 `k²`），最后接起来过一张 `W^O` [17:46]–[19:05]。
6. **"RNN 只能往前看"不是 self-attention 的优势**（双向 RNN 就能解决）；真正的优势是 **① 远距离资讯不必一路搬运 ② 可以平行化**。
7. **CNN 与 self-attention 的胜负和资料量是"交叉"的**：资料少 → CNN 好；资料多 → self-attention 好 [33:59]–[34:24]。
8. ⭐ **RNN 的两条毛病要分成"前向／反向"两条线，别混，也别用"遗忘"这个词**（2026-09-29 追问轮补）：

|                                  | 说的是什么                                                           | 在哪讲                                                                                           |
| -------------------------------- | --------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **①（前向）远方的资讯必须一路搬运、不能丢**         | **能力要求／负担** —— 最右边要考虑最左边，就得把最左边**存在 memory 里、接下来都不能忘掉、一路带到最右边** | ⭐ **P39** [38:06]–[38:23]（本集）                                                                 |
| **②（反向）梯度沿时间连乘 ⇒ 消失 ⇒ 长距离依赖学不到** | **训练上的失败模式**，正式名字 = **梯度消失（vanishing gradient）**                | ⭐ **P41** [19:21]「为什么 LSTM 可以做到……Gradient Vanishing 的问题呢」；⚠️ **P39 没讲，P40 也完全不讲**（P40"梯度"零命中） |

- ⚠️ **"遗忘"是专有名词**：**P40** [26:47]–[26:52] 讲 **forget gate** 时明说「**它打开的时候代表的是记得，它被关闭的时候代表的是遗忘**」（老师还吐槽"它名字我觉得取得有点怪"）⇒ 用"遗忘"描述 RNN 的毛病会和**遗忘门**撞名。
- **前瞻**：到 **LSTM**，一路带下去的会变成**两个**东西（hidden output 与 **memory cell**）—— 所以"把记录留在 memory 向量里"这句话到那时就不够用了（见 §7.1 的 ⚠️）。
