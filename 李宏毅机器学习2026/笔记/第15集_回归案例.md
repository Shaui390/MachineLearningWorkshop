# 第15集：回归案例（预测宝可梦进化后 CP 值）

> 本集主题：Regression 完整案例（把机器学习三步骤从头到尾实跑一遍，顺便引出几个重要观念）。讲稿：[[raw/第15集_字幕|字幕存档]]。
> 一句话总结：三步骤 × 宝可梦 CP 值——线性模型（train 31.9 / test 35.0）→ 加高次项：二次 15.4/18.4、三次 15.3/**18.1（最佳）**、四次 14.9/28.8、五次 12.8/232（测试爆炸 = **overfitting**）→ 分物种不同系数（用 δ 函数仍写成**线性模型**，train 3.8 / **test 14.3**）→ 全属性大杂烩（train 1.9 / test 102.3 翻车）→ **regularization 救场**（L = Σe + λ·Σw²，λ=100 → **test 11.1**；⚠️ **b 不参与正则化**）→ 结尾爆点：**今天用了 testing set 来选 model，上线误差会高于 11.1 → 需要 validation（下一讲预告）**。

---

## 本集讲了什么

1. **任务定义**：回归任务应用举例（股票等、Amazon 购买预测）→ 更"实用"的例子：预测宝可梦进化后 CP 值（value = 战动力；预测它决定要不要进化，省糖果）
2. **输入表示**：一只宝可梦 X，含 X_cp（进化前 CP）、X_s（物种）、X_hp（HP）、X_w（重量）、X_h（高度）…；输出 Y = 进化后 CP（scalar）→ Regression problem
3. **Step 1**：先胡乱写个简单 model：y = b + w·x_cp（w、b 未知参数；填不同值得不同 function f₁ f₂…）
4. **Step 2**：Loss = function 的 function；每只宝可梦的误差 **e = (ŷ − y)²**，全部相加（average）→ L；画 **error surface**（每点 = 一组 (w,b) = 一个 function；红大蓝小；示例 b=−180, w=−2）
5. **Step 3**：优化（"修过线代会有 closed form solution，但你大概忘了"→ 教**通用**的 gradient descent：只要 L 可微就能用）；手算偏微分：∂L/∂w = Σ2(ŷ−y)·(−x_cp)、∂L/∂b = Σ2(ŷ−y)·(−1)
6. **线性模型结果**：b\*=−188.4, w\*=2.7；train **31.9** / test **35.0**（红线不能完全拟合；测试集 = 另外 10 只宝可梦）
7. **高次项实验**（本集第一个大节）：二次式 15.4/**18.4** → 三次式 15.3/**18.1**（最好）→ 四次式 14.9/**28.8** → 五次式 12.8/**232+**（测试爆炸：CP≈500 的宝可梦被预测为负值）
8. **overfitting**：模型越复杂 train 越低是必然（function space 嵌套：w₄=0 四次式退化成三次式；候选越多当然能找更低），**但 test 不一定**——四次、五次就是 overfitting；驾训班比喻；结论：**选三次式**（五个模型里 test 最低）
9. **分物种模型**（第二个大节）：60 只宝可梦画图发现"另一个力量" = 物种 → y = b₁+w₁·x_cp（波波）/ b₂+w₂·x_cp（独角虫）/ 绿毛虫 / 伊布；用 **δ（delta）函数**写成没有 if 的**线性模型**（δ·x_cp = 新 feature）；train **3.8** / test **14.3**
10. **全属性大杂烩**：物种×（CP、CP²）+ HP、HP²、高度、高度²、重量、重量² 都塞进去 → train **1.9** / test **102.3** 翻车（"我不是大木博士，不能手动删 input"）
11. **regularization**（第三个大节）：重定义 loss = Σe + **λ·Σwᵢ²**；λ 越大函数越平滑（w 小 → 输出对输入不敏感 → 对噪声鲁棒）；λ 实验：0→102、1→68、10→25、**100→11.1（最佳）**、1000→12.8、10000→26.8；⚠️ **b 不参与正则化**（只上下平移、不影响平滑度）
12. **结论**：CP 进化值主要取决于进化前 CP + 物种；其他 factor（HP/高度/重量）+ regularization 后略有帮助（但 data 少，不太 confident）；**最终 test error = 11.1**
13. **结尾爆点**：今天我们**用了 testing set 来选 model**（选三次式、调 λ 都是拿测试集结果挑的）→ 上线后实际误差**会高于 11.1** → 需要 **validation** 的观念 → **下一讲预告**；然后助教公告作业一

## 核心概念

### 1. Loss 是"function 的 function"
- L 的 input 是一个 function f，output 是"这个 f 有多不好"；f 又由 (w,b) 决定 → **L 本质在衡量一组参数的好坏** [14:37–15:33]
- 误差定义：`e = (ŷ − y)²`（平方差；本集就是"估测误差的平方和"），每只宝可梦的 e 相加 → L [15:43–17:20]
- error surface 每一点 = 一组 (w,b) = 一个 function；颜色：红 = loss 大（差）、蓝 = loss 小（好）[17:27–18:58]

### 2. closed form solution vs gradient descent
- 线性模型有**闭式解**（修过线性代数就会，但是"你大概忘了"）[20:26–20:59]
- 为什么教 gradient descent：**通用**——只要 L 可微，任何 function 都能处理 [21:01–21:37]（呼应 P3：这是"以后所有方法"的统一框架）
- 手算（作业会体验"10 个 example 就出严重的数值问题"😄）：
  - `∂L/∂w = Σₙ 2·(ŷⁿ − yⁿ)·(−x_cpⁿ)`
  - `∂L/∂b = Σₙ 2·(ŷⁿ − yⁿ)·(−1)`
  - 关键：括号里只有 −w·x_cp 项与 w 有关（求导后 −x_cp）、只有 −b 与 b 有关（求导后 −1）[35:03–36:48]

### 3. 高次项实验：function space 嵌套与过拟合
- 五个 model：一次 → 二次 → 三次 → 四次 → 五次（只加 x_cp 的高次项）
- **function space 嵌套**：三次 ⊂ 四次 ⊂ 五次——w₄=0 时四次式就是三次式 [49:36–50:20]
- 推论：**模型越复杂，train 上必然能找越低**（候选多）——前提是 gradient descent 真的找到 best [50:33–51:00]
- 但 **test 不是单调**：到三次为止都在降，**四次、五次就坏掉** [51:04–51:46]
- **overfitting 定义（本集版）**：复杂 model 在 training data 上有好结果，在 testing data 上不一定有好结果 [52:03–52:14]（与 P4 的 4 层 0.10k/0.44k 版互证）
- 驾训班比喻：场内练得太熟会学到"后照镜贴纸对到正中间就左转半圈"这种在真实路上没用的技能 [52:43–53:24]

### 4. 分物种模型：δ 函数把 if 写成线性
- 动机：**"针不在海里"**——只考虑 CP 值的 function set 里根本没有好函数，先重新设计 function set 再说（domain knowledge：物种是关键 factor）[54:17–56:28]
- 定义：`δ(x_s = 波波) = 1`，否则 0（信号处理里的 δ 函数/one-hot）[57:54–58:22]
- 改写：`y = b₁·δ(波波) + w₁·δ(波波)·x_cp + b₂·δ(独角虫) + …`——**它还是 linear model**！因为 "δ(波波)"、"δ(波波)·x_cp" 这些整体就是 **feature**，b₁w₁…b₄w₄ 就是参数 [58:29–60:22]
- 结果：train **3.8** / test **14.3**（比之前最好的 18.x 好）[61:36–62:03]
- 遗留：伊布（进化成不同种类精灵）"应该就没救了"；有的点还是略高/略低于线 → 可能是 random 数值，也可能还有别的 factor [62:05–63:13] → 引出全属性大杂烩

### 5. 全属性大杂烩 → 过拟合翻车
- 4 物种 × (x_cp + x_cp²) + HP/HP²/高度/高度²/重量/重量² → train **1.9**，test **102.3** [65:29–66:07]
- 手动救法（大木博士式）：删掉没用的 input——但我不是大木博士 → **用 regularization** [66:07–66:25]

### 6. Regularization（本集新概念，前四集没出现过）
- **重定义 Step 2**：`L = Σₙ (ŷⁿ − yⁿ)² + λ·Σᵢ wᵢ²`——在 loss 里"放知识"：**预期参数越小越好** [66:29–68:15]
- **为什么 w 小 = 平滑**：输入变化 Δx → 输出变化 = **Δx·w**；w 越接近 0，输出对输入越不 sensitive [68:16–69:31]
- **为什么喜欢平滑**：测试时输入被噪声干扰 → 平滑函数受影响小 → 结果好 [69:35–70:06]
- **λ 实验**（λ = 超参数，手调）：

| λ | 0 | 1 | 10 | **100** | 1000 | 10000 |
|---|---|---|---|---|---|---|
| test error | 102 | 68 | 25 | **11.1** | 12.8 | 26.8 |

- 规律：train error 随 λ 单调**升**（越来越不考虑拟合、只考虑平滑）；test error **先降后升**（U 型：太平滑 → 水平线 → 啥都干不成）→ 转折点 λ=100 [70:21–73:09]
- ⚠️ **b 不参与正则化**（本集"很多人不知道"的知识点）：① 实验证明不加 b 效果更好；② 原理：调 b 只是把 function **上下平移**，跟平滑程度无关 [73:15–74:45]

### 7. 用测试集选模型的陷阱（本集结尾彩蛋/爆点）
- 老师提问：系统上线后误差会比 11.1 高、低还是一样？（大家举手："一样"的人很少…）
- 答案：**会更高**——因为今天**用了 testing set 来选 model**（选三次式、调 λ 都是）→ 11.1 是"看着答案挑出来的"乐观估计
- 解法预告：**validation（验证集）的观念**，下一堂课再讲 [77:55–78:22]

## 公式与推导要点

**Model（Step 1）**：`y = b + w·x_cp`；分物种版本：`y = Σᵢ δ(x_s = 物种ᵢ)·(bᵢ + wᵢ·x_cp)`

**Loss（Step 2）**：`L = Σₙ (ŷⁿ − (b + w·x_cpⁿ))²`；正则化版：`L = Σₙ eⁿ + λ·Σᵢ wᵢ²`（无 b）

**梯度（Step 3）**：`∂L/∂w = Σₙ 2(ŷⁿ − yⁿ)·(−x_cpⁿ)`；`∂L/∂b = Σₙ 2(ŷⁿ − yⁿ)·(−1)`

**实验总表（train / test）**：

| 模型 | train | test | 备注 |
|---|---|---|---|
| 1. 一次式（b=−188.4, w=2.7） | 31.9 | 35.0 | 起点 |
| 2. 二次式（b=−10, w₁=10, w₂=2.7×10⁻³） | 15.4 | 18.4 | 有进步 |
| 3. 三次式 | 15.3 | **18.1** | 五个模型里 test 最低 → **最终选择**（口述偶有 18.3） |
| 4. 四次式 | 14.9 | 28.8 | 🚩 test 反而变差 |
| 5. 五次式 | 12.8 | 232（"200 多"） | 💥 爆炸（CP≈500 预测为负）→ **overfitting** |
| 6. 分物种线性（δ 技巧） | 3.8 | 14.3 | 比 18.x 更好 |
| 7. 全属性大杂烩 | 1.9 | 102.3 | 💥 翻车 → 引出正则化 |
| 8. 7 号模型 + 正则化（λ=100） | — | **11.1** | 本集最终结果 |

我提交的三点理解，逐条核对：

| 我记的 | 判定 | 订正/佐证 |

| 1a. 用 x_cp 的例子，把线性模型扩展到高次项 | ✅ | y = b + w·x_cp → +w₂x_cp² → 到 x⁵ [41:16–48:52] |
| 1b. 高次项越来越多后出现过拟合 | ✅ | 四次 test 28.8 > 三次 18.1、五次 test 232+ 爆炸 [46:37–48:52]；术语 [52:03–52:14] |
| 1c. "故选择只考虑到**二次项**就结束" | ❌ | **选的是三次式**：train 15.3 / test 18.1，是五个 model 中 test 最低 [45:05–45:12][53:42–53:58]；二次式 test 18.4 反而略差。过拟合的是**四次、五次**，不是二次 |
| 2. 不同种类宝可梦用不同系数 → 测试集更好 | ✅ | 分物种线性 model：train 3.8 / test **14.3** < 之前最好的 18.1 [61:36–62:03]。补充：它还是**线性模型**（δ 函数 one-hot 技巧）[57:44–60:22]；动机是"针不在海里"——原 function set 里没有好函数 |
| 3a. 提出 regularization 优化损失函数 | ✅ | 重新设计 Step 2：L = Σe + **λ·Σwᵢ²** [66:25–67:41] |
| 3b. "**加入更多的 w** 会惩罚 loss" | 🧩 用词错 | 不是"加更多的 w"：是**给每个 w 求平方再相加**（Σwᵢ²），惩罚的是 w 的**值的大小**（越接近 0 越好），不是 w 的**个数**；λ 是惩罚强度（超参数）[67:27–68:15] |
| 3c. "不确定哪些 feature 重要 → 保证训练合理性" | ✅ 方向对，补全动机链 | 我不是大木博士 → 不能手动删 input → 用 regularization 让参数小 → function **平滑** → 输出对输入不敏感 → **对噪声鲁棒** [66:07–70:06]；λ 要手调，λ=100 时 test 11.1 最佳 [71:36–71:55] |

### 我漏掉的重点（笔记已补）

1. ⚠️ **b 不参与正则化**——老师说"很多人不知道"：调 b 只上下平移、不影响平滑度，且实验证明不加 b 更好 [73:15–74:45]
2. ⚠️ **本集结尾最重要的问题：今天用了 testing set 来选 model**（三次式、λ=100 都是），所以上线后误差**会高于 11.1** → 需要 validation（下一讲）[77:55–78:22]
3. **function space 嵌套**：w₄=0 时四次式退化为三次式 → 模型越复杂 train error 必然越低（候选多），训练误差根本不是选模型依据 [49:36–51:00]
4. **分物种模型的线性化技巧**：δ（one-hot）× 特征 = 新 feature → "有 if 的式子"仍是 linear model → 还能用梯度下降 [57:44–60:22]
5. 全属性模型 train 1.9 / test 102.3 这个"巨大落差"正是正则化的登场舞台 [65:29–66:25]
6. 线性模型有 **closed form solution**（线代），但 gradient descent 通用（只要可微）[20:26–21:37]

## 易错点与纠正

1. **"选到二次项"❌ → "选三次式"**：五次模型的 test 才爆炸；二次(18.4) 比三次(18.1) 略差。记忆点：**测试误差最低 ≠ 最简单的模型**——是"刚好不复杂也不简单"的三次式
2. **正则化惩罚的是 w 的"平方和"**，不是"w 的个数"；λ 越大 → w 被压得越小 → function 越平滑
3. **b（bias）不进正则化**：只在 Σwᵢ² 里求和，不要写成 Σ(wᵢ²+b²)
4. **λ 不是越大越好**：太平滑 → 水平线 → test 又变差（U 型曲线，λ=100 转折点）
5. **model 越复杂 train 越低 ≠ 好**：function space 嵌套使训练误差必然单调降——**选模型只看测试集**（这句话的坑：测试集看着挑也算"作弊" → validation）
6. **分物种模型 ≠ 非线性**：δ 函数把它拉回线性世界（同 P13 的 W 每行一个 neuron 逻辑一样：特征可以人工构造）
7. 数值细节：train 35.0 是**线性**模型的测试误差；**三次式才是最终选择**；**λ=100 → 11.1** 是全部环节的最终答案
