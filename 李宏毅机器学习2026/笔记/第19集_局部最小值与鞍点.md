## 二、核心概念

### 1. optimization 失败 = 卡在 critical point

- **判据**（接 P18）：先看 **`loss on training data`**。如果它**很大**，病在两处之一——**model bias** 或 **optimization**；**本集专治后者**。
- **表现**：参数不再更新（[01:29]），loss 降不下去。
- **原因**：走到了 **critical point**——梯度为 0 的点。

**⭐ 为什么梯度为 0 就走不动（要的是机制，不是结论）**：

> 参数的更新量**由梯度决定**（P15 的三步骤 Step 3：`θ ← θ − η·g`）。梯度是 0 → 更新量就是 0 → **参数一动不动**。
> 所以"卡住"不是"到了最低点"，而是"**这一站的斜率是 0，按规矩就该停**"。

> 🔗 **P20 伏笔（本集没讲）**：上面这条**只在纯梯度下降里成立**。P20 加了**动量**之后，即使当前梯度 = 0，参数仍能靠"之前累积的方向"继续动——这正是逃出鞍点/平坦区的思路。

### 2. critical point 有三类

![[P19_03_Hessian正负定判别_极小极大鞍点.png]]

| 类型 | 直觉 | 形态 |
|---|---|---|
| **local minima** | 四面都高，是坑底 | 碗 |
| **local maxima** | 四面都低，是山顶 | 倒扣的碗 |
| **saddle point** | 有的方向往上、有的方向往下 | **马鞍 / 山口** |

![[P19_02_临界点处梯度项消失_只剩Hessian项.png]]

> ⚠️ **"看图很好分辨"只在示意图上成立**。真实网络参数千万维，**error surface 根本画不出来**——所以需要一个**不用看图、能直接算出来的判据**。这就是 🔶 那一段（Hessian 的特征值正负）存在的**唯一理由**。

### 3. 高维里，鞍点才是主角

**推理链**（本集的主线，零公式）：

```
要从"坑底"才算 local minimum
   → 必须"所有方向都向上翘"
   → 维度越高，凑齐"所有方向都上翘"越难
   → 所以高维 error surface 里的 critical point，大多不是 local minimum
```

**三体类比**（[26:00]–[28:45]）：三维看封闭的石棺，四维看处处是路。
**对应事实**：**你在低维看到"无路可走"的地方，在更高维可能到处都是下坡路。**

### 4. ⭐ 实测：minimum ratio（本集最硬的一张图）

![[P19_08_EmpiricalStudy_minimumRatio实测.png]]

- **做法**（[30:47]–[31:15]）：**训练很多个网络**，每个都训到 loss 降不下去（卡在 critical point），**把那组参数拿出来算特征值**，判断它更像 saddle point 还是 local minimum。
  ⚠️ **一个点 = 一个网络**（不是同一个网络的不同时刻）。
- **坐标轴**：
  - **纵轴 = 卡住那一刻的 training loss**（[31:17]："卡住了、loss 没办法再下降了，那个 loss 是多少"；
    老师顺带点出：**有时候 loss 还很高就卡住，有时候能降得很低才卡住**）。
  - **横轴 = minimum ratio = 正特征值个数 ÷ 特征值总个数**（[31:41]–[31:51]）。
    → 读作"**这个点有多接近真正的坑底**"：= 1.0 表示所有方向都上翘（真坑底）；≈ 0.5 表示一半方向还能继续下降。

**⭐ 这张图要读两层，第二层才是关键**：

| 读法 | 看到什么 | 结论 |
|---|---|---|
| **(a) 只看横轴** | 整张图 minimum ratio **最大也不过 0.5–0.6**（[32:20]） | **至少有一半方向的特征值是负的 → 一半的路还能让 loss 下降**（[32:49]）→ 投影片那句 **"never reach a real local minima"**。最左两个点 ratio ≈ 0，**更加不是** |
| **(b) 横纵一起看** ⭐ | loss 从 ≈0.09（很差）到 ≈0（很好）的点，ratio **全挤在 0.4–0.6 那条竖带里** | **"卡住时有多接近坑底"和"训练得好不好"没有相关性** → ⇒ **"local minima 不常见"这个结论对训练好/坏都成立**，不是"只有训练差的才卡鞍点" |

> **怎么看出"没有相关性"**：散点图上，点排成斜线 = 有关系；挤成一团/一条竖带 = 没关系。这里就是一条竖带。

### 5. 三种"梯度很小"的情形（本集收尾，也是 P20–P22 的目录）

![[P19_09_SmallGradient三种卡住情况.png]]

参数轴上有 **4 个红点 = 1 个正常 + 3 种问题**：

| 红点 | 状态 | 梯度 | 症状 |
|---|---|---|---|
| 第 1 个（最左） | 陡坡上，**正常下降中** | ≠ 0 | **不是问题** |
| 第 2 个 | **plateau（高原/平坦区）** | **≈ 0，但往往不是 0** | **走得极慢**（"Very slow at the plateau"） |
| 第 3 个 | **saddle point** | **= 0** | **停住不动** |
| 第 4 个 | **local minima** | **= 0** | **停住不动** |

**⇒ 病灶分两类**：**plateau 是"慢"**（还有梯度，只是很小）；**saddle point / local minima 是"停"**（梯度恰好为 0）。

## 三、公式与推导要点（🔶 整节待补：需要线性代数）

> ⚠️ **本节的推导用户 2026-09-16 决定延后**（原话："没看懂，等我学了再看吧，我连矩阵都没学"）。**这里只留结论与回看路标；学完线代（特征值/特征向量/二次型那章）后回看 `[04:50]`–`[25:20]` 即可补齐。**
> 自查判据：能自己算出 `H·[1,1]ᵀ = −2·[1,1]ᵀ` 就够用了。

**本段老师做了什么（结论版）**：

1. **泰勒展开**（[05:28]）把 error surface 在 θ′ 附近近似成三项：
   `L(θ) ≈ L(θ′) + (θ−θ′)ᵀg + ½(θ−θ′)ᵀH(θ−θ′)`
   —— 第一项是"不动时的基线"，第二项用**斜率**修正，第三项用**曲率**修正。
   （截图：![[P19_01_泰勒展开式_梯度项与Hessian项.png]]）
2. **在 critical point 处 g = 0**（[08:21]–[08:37]）→「**绿色的这一项完全都不见了**，只剩下红色的这一项」→ 于是能**只看二阶项**判断类型。
3. **判据**：令 `v = θ − θ′`（[09:25]），看 `vᵀHv` 的符号——
   恒正 = **local minima**；恒负 = **local maxima**；**有正有负 = saddle point**。
   等价说法：**H 的特征值全正 / 全负 / 有正有负**。
4. **顺手能逃出去**（[19:57]–[22:14]）：鞍点处「**它指出了我们参数可以 update 的方向**」——取**负特征值对应的方向 u**，令 `θ = θ′ + u`，理论上能让 loss 下降。
   （截图：![[P19_06_沿负特征向量下降_推导.png]] ![[P19_07_例子_沿u等于11方向更新逃离鞍点.png]]）
5. ⚠️ **老师亲口说实作上别这么干**（[24:41]–[25:12]）：「实际在 implementation 里面你**几乎不会真的把 Hessian 算出来**……运算量非常非常的大，更遑论还要把 eigenvalue 跟 eigenvector 找出来。实作上你几乎没有看到有人用这一个方法来逃离 saddle point。」
   → **这一段是"理解现象"用的，不是工具**；能逃鞍点的实用方法在后面几集。

**例子（`y = w₁w₂x`，[16:07]–[23:10]）**：两层线性网络、`x = 1`、`ŷ = 1` → `L = (1 − w₁w₂)²`；
在原点 `(0,0)` 处 `g = 0`、`H = [[0,−2],[−2,0]]` → 特征值 `λ = ±2`（一正一负）→ **鞍点**。
（截图：![[P19_05_例子手算Hessian_特征值2与-2.png]]）
⭐ 这个例子里**原点的 H 对角元是 0**，因为只要 `w₁ = 0` 或 `w₂ = 0`，`L` 恒等于 1——**沿两根参数轴看，原点是平的**；信息全在"斜方向"上。

## 五、易错点与纠正

1. ❌ **`θ′` 不是"更新之后的 θ"** —— 是**脚下**（出发地 / 展开锚点）。见 4.2。
2. ❌ **"g 处处为 0"** —— **`g = 0` 只在临界点成立**。梯度为零是"你正好站在临界点上"这个**位置**的性质，不是参数的固有属性；否则训练根本走不动。（用户已在 Q1 澄清）
3. ⚠️ **判断类型不需要"去取邻点 θ 采样"** —— `θ` 是结论要**覆盖的范围**（"附近的点都比它高"才是 local minimum 的**定义**），而**工具是 H**：靠它的正负性一次性覆盖**无穷多个方向**。
4. ⚠️ **本集只分类，没给方法** —— [33:19] 只说"接下来讲有什么样可能的解决方法"，随即下课。**别把 P19 当"解决方案集"。**
5. ⚠️ **"看图很好分辨"是假象** —— 只在 2D/3D 示意图上成立；真实网络千万维画不出来，**才需要能算的判据**。
6. ⚠️ **Hessian 那条路实作上几乎不用** —— 老师原话 [24:46]「你几乎不会真的把 Hessian 算出来……运算量非常非常的大」。**它是理解工具，不是工程工具。**
7. ⚠️ **别把 minimum ratio 的方向记反** —— 它是**正特征值所占比例**，所以**越大越像坑底**（1.0 = 真坑底），**不是"越大越像鞍点"**。
8. 🧩 **"梯度小"不等于"梯度为 0"** —— plateau 的梯度 ≈ 0 **但往往不为 0**（所以是"慢"）；只有 saddle point / local minima 才是**恰好为 0**（"停"）。
