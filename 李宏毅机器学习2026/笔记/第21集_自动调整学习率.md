## 一、本集讲了什么（大纲）

一条主线：**"卡住"的锅不该让 critical point 背 → 让 LR 自己会变 → 三个零件拼成现代 optimizer**。

| 段 | 时间 | 内容 |
|---|---|---|
| **① 破题** | [00:00]–[05:04] | critical point 不一定最大障碍 → ⭐ **loss 不降 ≠ gradient 小** → ⭐ P19 那张图是**特别训练出来的** |
| **② 一个凸曲面的反例** | [05:06]–[09:38] | 椭圆等高线 → LR 太大震荡 / 太小走不到 → ⭐ **大原则**：陡的地方 LR 要小、平的地方 LR 要大 |
| **③ AdaGrad** | [09:38]–[17:32] | 让 LR 除以 gradient 的 root mean square → 机制 → ⭐ **不足：同一参数在不同时间也需要不同 LR** |
| **④ RMSProp** | [17:32]–[23:14] | 用 α 给新旧 gradient 加权 → 可以**动态踩刹车/加速** → ⚠️ **没有论文**（Hinton 的 Coursera 课） |
| **⑤ Adam** | [23:14]–[24:31] | **RMSProp + Momentum**；⚠️ 老师原话：**用预设参数就够好** |
| **⑥ AdaGrad 实测 + 爆炸** | [24:32]–[27:21] | 能走更远，但**会突然喷出去**，之后自己回来 |
| **⑦ LR Scheduling** | [27:23]–[34:08] | **decay**（越来越小）→ 解决爆炸；**warm up**（先小后大）→ ⭐ **BERT 作业要用**；为什么需要 warm up（未完全解答） |
| **⑧ 总结** | [34:09]–[37:42] | 完整 optimizer = **Momentum + σ + Scheduling** → ⭐ **一个常见困惑：两者不是抵消了吗？** → 预告下一集"把 error surface 铲平" |

1. **破题**（[00:00]–[00:39]）：上周讲 critical point；今天要说的是 **Adaptive Learning Rate** —— 「我们要给**每一个参数不同的 Learning Rate**」，因为 critical point **不一定是**训练时最大的障碍。
2. ⭐ **第一个反直觉：Loss 不再下降，不代表 gradient 变小**（[00:39]–[03:10]）：多数人看到 loss 卡住就猜"走到 critical point，gradient = 0"，但**很少有人真的去确认 gradient 是不是真的小**。实测（下面画了 gradient 的 norm）：**loss 早就不动了，但 gradient 的 norm 并没有真的变小**，训练最后甚至**还突然上升了一下**。
3. **机制：在峡谷两壁之间来回震荡**（[02:16]–[03:10]）：参数在谷壁间不断震荡 → **loss 不再下降，但 gradient 仍然很大**。⇒ 老师原话：「你不要随便说**我卡在 Local Minimum、我卡在 Saddle Point**，**有时候根本两个都不是**，你只是单纯的 Loss 没有办法再下降。」
   - 📝 **呼应作业**（[03:10]–[03:32]）：这就是为什么作业 2-2 要大家**算 gradient 的 norm**，去分析"你到底是卡在 saddle point 还是别的"。
4. ⭐ **一个"秘密"**（[03:32]–[05:04]）：P19 那张"用 Hessian 特征值正负号判断 critical point 类型"的图，**用一般的 gradient descent 是训练不出来的** —— 「你要训练到参数很接近 critical point，用一般的 Gradient Descent 其实是做不到的……往往在 gradient 还很大的时候，loss 就已经掉不下去了」。**那是需要特别方法 train 出来的。**
   - ⇒ 老师的结论：**走到 critical point 其实是困难的一件事**；⚠️ 但「这并不代表 critical point 不是一个问题」，只是说 —— **你真正应该怪罪的对象往往不是 critical point，而是其他的原因。**
5. **一个凸（convex）error surface 反例**（[05:06]–[08:42]）：只有两个参数，等高线是**椭圆**：**横轴非常平坦**（gradient 小）、**纵轴非常陡峭**（gradient 大）。
   - **LR = 10⁻²** → 参数在**峡谷两端不断震荡**，loss 掉不下去，**但 gradient 仍然很大**。
   - **一路调到 10⁻⁷** 才终于不震荡、滑到谷底然后左转 —— **但走不到终点**：「因为我的 Learning Rate 已经太小了」，到平坦处**根本推不动**（那边有 10 万个 update 点，还是靠近不了 minimum）。
   - ⇒ 「就算是 Convex 的 error surface，你用 gradient descent 都很难做好。」而深度学习里 **gradient descent 是你唯一能仰赖的工具**，所以必须把它做得更好。
6. ⭐ **大原则**（[09:40]–[10:15]）：「**如果在某一个方向上 gradient 的值很小、非常的平坦，我们会希望 Learning Rate 调大一点；如果在某一个方向上非常的陡峭、坡度很大，那我们期待 Learning Rate 可以设得小一点。**」
7. **AdaGrad**（[10:21]–[17:09]）：把固定的 η 换成 **η/σᵢᵗ**（见第三节公式），σ = **过去所有 gradient 的 root mean square**。
   - ⚠️ **第一步无所谓**（[12:57]–[13:48]）：σ⁰ = |g⁰| → 第一步**只走 η**（正负 1 × η），跟 gradient 大小无关。老师原话：「这一步没有特别重要，如果你听到有点模模糊糊就算了。」
   - **机制**（[16:02]–[17:09]）：θ₁ 方向平坦 → gradient 一直小 → σ 小 → **LR 自动变大**；θ₂ 方向陡峭 → gradient 一直大 → σ 大 → **LR 自动变小**。
8. ⭐ **AdaGrad 的不足**（[17:09]–[17:32]）：「**就算是同一个参数，它需要的 Learning Rate 也会随着时间而改变。**」刚才的假设是"同一个参数的 gradient 大小固定差不多"，但**事实上不一定**（星月形曲面：同一方向有的地方陡、有的地方平）。
9. ⭐ **RMSProp**（[17:41]–[23:14]）：σ 改成**用 α 加权**（见第三节）。**α 是新的超参数**：α→0 ⇒ "现在这个 g 比较重要"；α→1 ⇒ "之前的比较重要"。
   - **效果**：走到陡的地方可以**很快踩刹车**（把 LR 变小）——「如果你没有踩刹车，走到这个地方 learning rate 太大了、gradient 又很大，两个很大的东西乘起来，你可能就啪的一下**飞出去了**」；走到平的地方又能**很快加速**。
   - ⚠️ **传奇之处**（[18:30]–[19:01]）：**这个方法找不到论文** —— 出自 Hinton 在 Coursera 的深度学习课，「所以你要 cite 的话，你要 cite 那个影片的连结」。
10. ⭐ **Adam**（[23:14]–[24:31]）：「**Adam 就是 RMSProp 加上我们上周讲过的 momentum。**」
    - ⚠️ 老师原话（重要）：「今天你不用担心这个，**PyTorch 里面都帮你写得好好的了**」；「里面也有一些 hyperparameter 需要人工决定，**但是你往往用预设的那一种参数就够好了，你自己调有时候反而会调到比较差的**。」
11. **AdaGrad 实测 + 为什么会爆炸**（[24:32]–[27:21]）：加上 AdaGrad 后**可以继续走**（左右方向 gradient 小 → LR 自动变大 → 步伐变大）→ **但走到某处突然爆炸**。
    - **原因**：σ 是**过去所有 gradient 的平均** → 纵轴方向**一路累积了很多很小的 gradient** → σ 累积到很小 → **step 变得很大 → 喷出去**。
    - **会自己回来**：喷出去以后走到 gradient 大的地方 → σ 又慢慢变大 → 步伐又变小 → 「有摩擦力让它慢慢回到中间这个峡谷」→ 但**过一段时间又会喷**。
12. **Learning Rate Scheduling**（[27:23]–[29:38]）：
    - ⭐ **Learning Rate Decay**：让 η **随时间越来越小**。理由：「一开始我们距离终点很远，随着参数不断 update 距离终点越来越近，所以把 LR 减小，**踩一个刹车**」→ 刚才那个爆炸**就能被压住**（因为 η 已经非常小，想乱喷也喷不动）。
    - ⭐ **Warm Up**：LR **先变大、后变小**。⚠️ **老师说本来犹豫要不要讲** —— 「但是其实我们有一个**跟 BERT 有关的作业**，你可能**需要用到 warm up 才能够得到好的结果**，所以我们还是把它拿出来讲一下。」
13. **Warm Up 是个"黑科技"**（[29:38]–[32:38]）：远古时代就有 ——
    - **ResNet**（arXiv 15 年 12 月，[30:05]–[31:38]）：论文里就写了用 **0.01 去 warm up，再改成 0.1**，而且**特地加注解说"你一开始用 0.1 反正就是训不好，不知道为什么"**。
    - **Transformer**（[31:38]–[32:38]）：论文里用一个"神奇的 function"（equation 3）设定 LR，「你乍看之下会觉得不知道在写些什么」，**但把它画出来就会发现它就是 warm up** —— LR 先增加、之后递减。
    - ⇒ 这些论文**都不解释为什么**，只是偷偷在一个小地方告诉你"要用这种黑科技才训得起来"。
14. ⭐ **为什么需要 Warm Up？（仍未完全解答）**（[32:38]–[34:08]）：老师原话「**我并不认为为什么要用 warm up 这件事已经获得了完全的解答**」，但有一个**可能的解释**：
    - σ 是一个**统计量**（某个方向到底多陡/多平滑）→ **要看了够多笔数据之后统计才精准** → **一开始 σ 是不精准的**。
    - 所以**一开始不要让参数走离初始点太远**，先在原地**"探索"**、搜集关于 error surface 的情报；**等 σ 统计比较精准以后，再让 LR 慢慢爬升**。
    - 📎 想深入 → **RAdam**（Adam 的进阶版）。
15. **总结：完整版 optimizer**（[34:09]–[36:23]）：**Momentum**（方向）+ **σ / root mean square**（步伐大小）+ **LR Scheduling**。
    - ⭐⭐ **一个常见困惑（值得单独记）**：momentum 和 σ **都看过去所有 gradient**，一个在分子一个在分母，**不是正好抵消了吗？**
    - ⇒ **不会**。因为**使用历史的方式不一样**：
      - **momentum 是把 gradient 直接加起来** → **考虑方向/正负号**（往左还是往右）
      - **σ 是把 gradient 取平方后再加** → **只考虑大小，不考虑方向**
    - ⇒ 其他 optimizer 的种种变形 = 换一种算 momentum / 换一种算 σ / 换一种 LR scheduling。
16. **收尾与预告**（[36:41]–[37:42]）：本集是「**山不转，路转**」—— 绕过那座山；**下一集要把山直接铲平**：改 network 架构 / activation function 等，**直接让 error surface 变得好 train** → 引到 **P22（loss function 也可能有影响）**。

## 二、核心概念

### 1. ⭐ 本集最重要的一句话：Loss 不再下降 ≠ critical point

| 你看到的 | 你的直觉 | 实际可能是 |
|---|---|---|
| Loss 卡住不动 | 走到 local minima / saddle point（gradient = 0） | **gradient 还很大**，只是参数在两个很陡的谷壁间**来回震荡**，loss 抵消掉了 |

⚠️ 老师的态度很明确（[02:53]–[03:07]）：「你不要随便说我卡在 Local Minimum、我卡在 Saddle Point，**有时候根本两个都不是**。」
👉 **实作判据**：卡住时**先把 gradient 的 norm 打出来看**（作业 2-2 就是干这个）。

![[P21_02_训练卡住不等于梯度小_双曲线图.png]]
> 图注：左 = 参数在两壁之间来回震荡；右上 = **loss 很早就平掉了**；右下 = **norm of gradient 并没有跟着变小**（红圈处还在 0.5 上下飘）。

### 2. ⭐ "P19 那张图是特别训练出来的"——这句要单独记

- P19 用 **Hessian 特征值正负号**判断 critical point 类型的那张实验图，**一般 gradient descent 训练不出来**。
- 含义有两层，**别只记一层**：
  - ① **走到 critical point 本身就很难**（多数时候还没走到就卡住了）
  - ② **但 critical point 不是"不是问题"** —— 老师说得很清楚「这并不代表 critical point 不是一个问题」，只是**你该怪的对象往往不是它**。

### 3. 三种"卡住"的区分（本集把 P19 那张图补完了）

| 现象 | gradient 的大小 | 归属 | 解法 |
|---|---|---|---|
| local minima / saddle point | **≈ 0** | critical point（P19） | 动量（P20）；实作上很少遇到 |
| **在峡谷两壁震荡** | **很大** | **不是 critical point**，是 LR 不会变（**本集**） | **Adaptive LR** |
| plateau（很平但不为 0） | 很小但不为 0 | 走得慢（P19 结尾） | Adaptive LR **把它调大** |

### 4. Adaptive Learning Rate 的三种算法（一条演化链）

![[P21_03_凸曲面_陡方向小LR_平方向大LR.png]]
> 图注：椭圆曲面上 **陡的方向（纵轴）配小 LR、平的方向（横轴）配大 LR**；右边那一步就是本集的招牌改写 —— **把固定的 η 换成 η/σᵢᵗ（Parameter dependent）**。

| | 核心式子 | 解决的问题 | 遗留的问题 |
|---|---|---|---|
| **AdaGrad** | σ = **所有历史 g 的 RMS**（每个 g 等权） | 不同**参数**方向陡缓不同 | 同一参数**不同时间**需要的 LR 也不同 → 反应太慢 |
| **RMSProp** | σ = **α 加权的 RMS**（新 g 权重可调） | 同一参数**随时间**动态调整（快速踩刹车/加速） | 仍会**爆炸**（历史累积） |
| **Adam** | **RMSProp + Momentum** | 方向 + 步伐一起解决 | 需要 **LR Scheduling** 收尾 |

⚠️ 三处容易记错的细节：
- **AdaGrad 第一步与 gradient 大小无关**（σ⁰ = |g⁰|，整个分数只剩 ±1）→ 老师明说这一步**不重要**。
- **RMSProp 的 α 是超参数**，不是常数；α 越小 = 越看重"新鲜"的 gradient。
- **Adam 不需要你自己实现**：PyTorch 有；**老师建议直接用预设参数**（[24:11]「你自己调有时候反而会调到比较差的」）。

### 5. LR Scheduling：decay 与 warm up

| | 形状 | 为什么 | 老师的保留态度 |
|---|---|---|---|
| **Learning Rate Decay** | η **越来越小** | 一开始离终点远、越走越近 → 踩刹车；**顺便压住上面的爆炸** | — |
| **Warm Up** | η **先小 → 大 → 再小** | σ 是统计量，一开始统计不准 → **先在原地探索、搜集情报，别走远**，统计准了再爬升 | ⚠️「**我并不认为为什么要用 warm up 这件事已经获得了完全的解答**」——这只是**一个可能的解释** |

![[P21_06_LR_Scheduling_Decay与爆炸对比.png]]
> 图注：**Learning Rate Decay** —— ηᵗ 一路递减（"越走越接近终点 → 踩刹车"）；下面两张对比 = **左边爆炸乱飞 vs 右边平顺走到终点**。

![[P21_07_WarmUp曲线与RAdam.png]]
> 图注：**Warm Up** —— ηᵗ **先升后降**；老师的解释是"一开始 **σᵢᵗ 这个估计量的 variance 很大**"；最后一行指向 **RAdam**（arXiv 1908.03265）。

📌 **Warm Up 与你的作业直接相关**：老师明说「我们有一个**跟 BERT 有关的作业**，你可能**需要用到 warm up 才能够得到好的结果**」（[28:56]–[29:10]）→ 这是 **HW7（BERT）** 的伏笔。

📌 **两处论文出处（老师当场翻的）**：
- **ResNet**：arXiv **15 年 12 月**（[30:31]–[30:51] 教你怎么读 arXiv 编号：前两位是年、后两位是月）
- **Transformer**：equation 3 —— 画出来就是 warm up

### 6. ⭐ 为什么 momentum 和 σ 不会互相抵消（本集最容易被问倒的一问）

| | 怎么用历史 gradient | 保留下来的信息 |
|---|---|---|
| **Momentum**（分子，决定**方向**） | 直接**相加** | **方向 / 正负号**（往左还是往右） |
| **σ**（分母，决定**步伐大小**） | **取平方**后再加 | **只有大小**，方向信息被平方抹掉了 |

⇒ 一个管"往哪走"、一个管"走多大步"，**不是重复计算**。

## 三、公式与推导要点

✅ **本集不需要线性代数**。要带走四组式子（都在投影片上，老师逐项念过）：

**① 一般 gradient descent（复习）**
```
θᵢᵗ⁺¹ = θᵢᵗ − η · gᵢᵗ          # η 是固定常数，所有参数共用
```

**② AdaGrad：把 η 换成 η/σᵢᵗ（parameter + iteration dependent）**
```
θᵢᵗ⁺¹ = θᵢᵗ − (η / σᵢᵗ) · gᵢᵗ

σᵢᵗ = sqrt( 平均( (gᵢ⁰)², (gᵢ¹)², …, (gᵢᵗ)² ) )        # root mean square
     = sqrt( (1/(t+1)) · Σ_{k=0}^{t} (gᵢᵏ)² )
```
> 下标 i = 哪个参数；上标 t = 第几次 update。**两个都 dependent** ⇒ 这就是"客制化 LR"的全部含义。

![[P21_04_RootMeanSquare_逐步展开.png]]
> 图注：σ 的逐步展开（投影片 p.6）—— σ⁰ = |g⁰|（⚠️ **第一步只走 η，与 gradient 大小无关**）→ σ¹ → σ² → σᵗ 通式：**先平方 → 再平均 → 再开根号**。

**③ RMSProp：把"平均"换成"α 加权移动平均"**
```
σᵢᵗ = sqrt( α · (σᵢᵗ⁻¹)² + (1 − α) · (gᵢᵗ)² )
```
> **α 是超参数**：α→0 ⇒ 新的 gᵢᵗ 更重要；α→1 ⇒ 历史的更重要。
> ⚠️ 注意：**σ 是被反复代回去的**（σᵗ 里含着 σᵗ⁻¹，σᵗ⁻¹ 里含着 g⁰…gᵗ⁻¹）—— 老师专门花了 [20:35]–[21:04] 讲这一点。

![[P21_05_RMSProp_公式与大小步示意.png]]
> 图注：上半 = 递推式与前提 `0 < α < 1`（"最近的 gradient 影响大、过去的越来越小"）；下半 = 三个位置分别是 **small σ → larger step / increase σ → smaller step / decrease σ → larger step**。

**④ Adam = RMSProp + Momentum**（老师不细讲，投影片上给了论文）
```
mᵗ⁺¹ = λ·mᵗ − η·gᵗ              # ← P20 的动量：管方向
θᵗ⁺¹ = θᵗ + mᵗ⁺¹ / σᵗ           # ← 本集的 σ：管步伐大小（老师口述的合并形式）
```
> ⚠️ **别把这两个式子当论文里的精确形式背** —— Adam 论文里有偏差校正（bias correction）等细节，老师明确说"不细讲"。**要带走的是"Adam = RMSProp + Momentum"这个身份**。

![[P21_08_Adam演算法_momentum加RMSprop.png]]
> 图注：Adam 论文 **Algorithm 1** 原样（投影片 p.11）—— `m₀` 旁边标 "for momentum"、`v₀` 旁边标 "for RMSprop"；`m̂ₜ`、`v̂ₜ` 那两行就是老师说的**偏差校正**。

**⑤ 要记住的只有三件事**：
1. **σ 是 gradient 的 root mean square**（先平方 → 再加 → 再开根号）
2. **gradient 小 → σ 小 → LR 大**（平的地方走大步）；**gradient 大 → σ 大 → LR 小**（陡的地方走小步）
3. **momentum 管方向、σ 管大小，两者不抵消**

![[P21_01_优化总结页_三个零件.png]]
> 图注：本集纲领图（投影片 p.17）—— 从 vanilla GD 到完整版：**ηᵗ（scheduling）+ mᵢᵗ（momentum，考虑方向）+ σᵢᵗ（root mean square，只管大小）**。

1. **开场破题（本集题眼）**：**loss 不再下降 ≠ 走到 critical point** —— 实测里 loss 早就不动了，但 **gradient 的 norm 并没有真的变小**（[00:39]–[03:10]），机制是参数在**峡谷两壁之间来回震荡**、loss 互相抵消。老师原话：「你不要随便说我卡在 Local Minimum、我卡在 Saddle Point，**有时候根本两个都不是**。」⚠️ 实作判据：**卡住时先把 gradient 的 norm 打出来看**。
2. **P19 那张图的"秘密"**：用 Hessian 特征值判临界点类型的那张实验图，**一般 gradient descent 训练不出来**（还没走到 critical point，loss 就掉不下去了）—— 那是"特别训练出来的"。但 ⚠️「**这并不代表 critical point 不是一个问题**」，只是你该怪的对象往往不是它。

4. **AdaGrad 的 σ 怎么算 / 为什么有效 / 第一步的特殊**：σ = **先平方 → 再平均 → 再开根号**（[24:46]–[24:58] 老师又当场念了一遍）⇒ 平坦方向 g 一直小 → σ 小 → **LR 自动变大**；陡的方向反之。⚠️ **第一步与 gradient 大小无关**（σ⁰ = |g⁰| ⇒ 第一步只走 η），老师明说这一步不重要。
5. **爆炸的因果链**：σ 是**历史累积** → 纵轴方向一路都是很小的 g → σ 累积到很小 → **step 变得很大 → 喷出去**（[25:51]–[26:36]）；喷出去后走到 g 大的地方 → σ 又变大 → 步伐变小 →「有摩擦力让它慢慢回到峡谷」（[26:39]–[27:21]），**过一阵又会喷** ⇒ 这才引出 **decay**（[28:05]–[28:46]：一开始离终点远、越走越近 → 踩刹车，**顺便压住爆炸**）。
6. **warm up 的"为什么"（老师自己也没定论）+ 一个常见困惑**：可能的解释 = σ 是**统计量**，要看了够多笔才准 → **一开始别让参数走太远，先在原地探索、搜集情报**，统计准了再让 LR 爬升；⚠️ 老师原话「**我并不认为为什么要用 warm up 这件事已经获得了完全的解答**」（[32:38]–[34:08]）。另一个常见困惑：**momentum 与 σ 都看历史 gradient，为什么不抵消？** → momentum **直接相加，保方向 / 正负号**；σ **取平方后相加，只剩大小**（[34:53]–[35:54]）—— ⭐ **就是你贴的那张图右下的两个蓝框**（Consider direction / only magnitude）。

## 五、易错点与纠正

1. ❌ **「Loss 不降 = 卡在 critical point」是错的** —— 本集的主题就是拆掉这个直觉。**先打 gradient 的 norm**，再下结论。
2. ❌ **「P19 那张图说明实作上经常走到 critical point」是反的** —— 恰恰相反：那张图**是特别训练出来的**，一般 GD 走不到。但 ⚠️ **也别过度纠正成"critical point 不是问题"**——老师专门说了「这并不代表 critical point 不是一个问题」。
3. ⚠️ **AdaGrad 的第一步不特别** —— σ⁰ = |g⁰| ⇒ 第一步**只走 η**，与 gradient 大小无关。**别拿第一步举例证明"自适应有效"**（和 P20 动量第一步与普通 GD 相同是同一类坑）。
4. ⚠️ **σ 是"平方后平均再开根号"** —— 不是"gradient 的平均"。**平方这一步就是"只留大小、丢掉方向"的原因**，也是 E1 那一问的答案所在。
5. ⚠️ **RMSProp 的 σ 是递推的** —— σᵗ 里含着 σᵗ⁻¹，不是只看最近一次 gradient。
6. ⚠️ **α 是超参数**（和 λ、η 一样要调），不是固定值。
7. ⚠️ **Adam 不用自己实现**，也别乱调它的预设参数 —— 老师原话：「往往用预设的那一种参数就够好了，你自己调有时候反而会调到比较差的。」
8. ⚠️ **Warm Up 只有"可能的解释"，没有定论** —— [32:41]「我并不认为为什么要用 warm up 这件事已经获得了完全的解答」。**笔记里必须带着这句**（和 P20 的"平坦/尖锐极小只是一个解释"同类）。
9. ⚠️ **两种 scheduling 不能混**：**decay = 一路变小**；**warm up = 先小后大再小**。warm up 那个"先变大"是反直觉的部分，也正是它被叫做**黑科技**的原因。
