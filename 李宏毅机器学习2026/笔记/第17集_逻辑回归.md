## 本集讲了什么

1. **Step 1（模型）**：`f(x) = σ(Σᵢwᵢxᵢ + b)`；和 linear regression 唯一差别是**多套了一层 sigmoid** → 输出被压在 0~1（可当概率），而 linear regression 输出可以是任何实数 [00:00–03:50]
   - 图像化：**一排 weight + 一个 bias + 一个 sigmoid** [01:53]
2. **Step 2（loss）**：假设 training data 由这个 posterior probability 产生 → **最大化 likelihood** → [06:01] 取 `−ln`（max 变 min）→ [07:22] 符号转换（class1 → ŷ=1、class2 → 0）→ 整理成 [10:29] **两个 Bernoulli 分布的交叉熵**
3. **cross entropy 的含义** [11:03]：衡量"两个 distribution 有多接近"；**一模一样时为 0**；来源是最大似然而不是 information theory
4. **Step 3（梯度下降）** [15:00–21:44]：算 `∂(−lnL)/∂wᵢ` → 结果 **`Σₙ −(ŷⁿ − f(xⁿ))xᵢⁿ`**；[21:44] ⭐ **与 linear regression 的更新式一模一样**（只差 target 是 0/1、f 在 0~1）
5. **⭐ 为什么不能用 square error** [24:31–30:24]：square error 的微分会**多乘一个 `f(1−f)`** → 离目标远时梯度**也接近 0** → 一开始就卡住（画图对比见 [[#⭐ 六、为什么不能用 square error]]）
6. **⭐ discriminative vs generative** [31:26–47:20]：两者 **model / function set 一模一样**（都是 σ(wᵀx+b)），**只差怎么找 w、b** → 找出来**不会是同一组** → 7 特征时 **79% vs 73%**；toy example 说明 generative 会**脑补**；data 少/有噪声/需要拆 prior 时 generative 有优势
7. **多分类** [47:20–56:26]：每个 class 一组自己的 w、b → z₁…z_K → **softmax** → 与 **one-hot** target 算交叉熵（[51:56] 老师指出：**三个高斯共用 Σ 就能推出 softmax**）
8. **⭐ 单层的极限** [56:26–67:14]：XOR 型四点**一条直线永远分不开** → 手工 feature transformation → [61:02] **"我们希望这个 transformation 是由机器自己产生的"** → [61:12] **把很多个 logistic regression cascade 起来** → [66:43] **每个叫一个 neuron，串起来 = neural network → deep learning**

## 核心概念

### 〇、三步骤总览：逻辑回归 vs 线性回归

![[P17_01_三步骤对照_逻辑回归vs线性回归.png]]
*左右并排的对照投影片（[03:00–03:50]）。**Step 1** 差在一层 σ；**Step 2** 差在 loss 的形式与 target 的类型；**Step 3 的更新式两边一模一样**——这是本集最"反直觉但漂亮"的结论。*

| | **Logistic Regression** | **Linear Regression** |
|---|---|---|
| **Step 1** | `f = σ(Σwᵢxᵢ + b)`，输出 **0~1** | `f = Σwᵢxᵢ + b`，输出**任意值** |
| **Step 2** | target `ŷ ∈ {0,1}`；`L = Σₙ C(f(xⁿ), ŷⁿ)`（交叉熵） | target `ŷ ∈ ℝ`；`L = ½Σₙ(f(xⁿ) − ŷⁿ)²` |
| **Step 3** | `wᵢ ← wᵢ − η Σₙ −(ŷⁿ − f(xⁿ))xᵢⁿ` | **完全相同的式子** |

### 一、Step 1：模型就是"一个 neuron"

```
f(x) = σ(z),   z = Σᵢ wᵢxᵢ + b
```
- 结构 = **加权求和 + bias → sigmoid**，也就是 **1 个 neuron**（φ = sigmoid）
- 与 P16 的关系：P16 推导出的 `σ(wᵀx+b)`，在这里被**直接当成模型写下来**（不再经过高斯）

### 二、Step 2：loss 从哪来 —— **为什么是交叉熵**

**主目的：把 likelihood 的"连乘"翻译成"连加"** [06:01–06:43]

likelihood 天生是连乘（N 笔资料独立 → 机率相乘），而我们整套工具（求导、求和、mini-batch、梯度下降）都是为连加设计的。

| 好处 | 怎么来的 |
|---|---|
| **不下溢** | 连乘 → 连加的副产品：N=1000、每项 0.5 → 0.5¹⁰⁰⁰ ≈ 10⁻³⁰¹（float64 都快撑不住）；取 log 后只是 −693 |
| **求导简单** | 乘法法则（N 项）→ 逐项相加 `d/dw Σln fₙ = Σ(1/fₙ)(dfₙ/dw)`（这正是 [15:13] "接下来都只是一些数学式的无聊的运算"的前提） |
| **能做 mini-batch** | loss 变成"每样本一项的**和**"才能按 batch 拆开算 → 直接决定 SGD 可实现（呼应 P4 的 update ≠ epoch） |

**三个独立性质**（不是从"连乘变连加"来的）
1. **ln 单调递增 → 保序** → `argmax L = argmax ln L`（等价变换的**合法性依据**，[06:21] 原话"取 log，它的 order 是不会变的"）
2. **加负号 → max 变 min** → `argmax L ⟺ argmin(−ln L)` ⚠️ 不是 `argmin(L − ln L)`
3. **形式自动变成交叉熵** → `−ln L = Σₙ −[ŷⁿln f + (1−ŷⁿ)ln(1−f)]` = 两个 Bernoulli 分布的交叉熵。**"联系"是结果不是目的**（[10:29] 先推式子、后命名）
![[Pasted image 20260915221857.png]]

**两个边界**
- log 只对**正的乘积**成立（有 0/负数不能直接取）→ 这也是 likelihood 必须用高斯/Bernoulli 这类**正的概率**的原因
- 取 log 改变了 loss 的**数值尺度** → **学习率的手感会变**

> ⚠️ **两个独立步骤别混**：**取 log** 解决"连乘"；**加负号** 解决"max 变 min"。
>
> 🅿️22 **[13:14]–[13:48] 老师给的一句话口径（问到了就这么答）**：如果有人问"**maximize likelihood 跟 minimize cross entropy 是什么关系**"，**不要回答"它们其实很像、但是又有很微妙的不同"** —— 「**它们就是一模一样的东西，只是同一件事不同的讲法而已**」。
> ⚠️ **但本课讲不了这条推导**：🅿️22 [12:58]「因为这堂课里面我们**甚至把 likelihood 拿掉了**，所以我们现在根本就没有 likelihood 这个东西，所以我们就不能往这个方向解释。」⇒ 正课（P22 那版）只能改用**举例**（error surface）来说服你。

**⭐ 为什么非要加负号（2026-09-19 补｜➕ 补充的）**

`p ≤ 1 ⇒ ln p ≤ 0` ⇒ **对数似然整体是负数，它的最大值是 0**；而 `−ln L` 的最小值也是 0。
⇒ ⭐ **"越接近 0 越好"跟负号无关**（两边的最优解都是 0）——**负号改的是"从哪个方向靠近 0"**：

| | `ln L`（对数似然） | `−ln L`（交叉熵） |
|---|---|---|
| 取值范围 | (−∞, **0**] | [**0**, +∞) |
| 完美预测（p=1） | 0 | 0 |
| 怎么靠近 0 | **往上爬**（maximize） | **往下走**（minimize） |
| 我们工具有吗 | ❌ 梯度下降只会"往下走"（没有 `loss.maximize()`） | ✅ |

⇒ 负号就是 `max 似然 ⟺ min 交叉熵` 那个等价号的**铰链**。

- ⚠️ **不加负号会怎样**：直接把 `ln L` 当 loss 丢给优化器去最小化 → 它会把"模型给正确答案的概率"压向 0 —— **方向彻底反了**
- ⚠️ **文字上要写 `max 似然 ⟺ min 交叉熵`，不能写等号**（差一个负号、方向相反）
- ⚠️ 负号和 log 都是**单调变换**，**不改变最优点在哪** ⇒ `argmax L = argmin(−ln L)` 是**严格等价**，不是"差不多"（呼应易错点 2）

### 三、Step 3：梯度下降（推导见下方截图三步）

结果极简：

```
∂(−lnL)/∂wᵢ = Σₙ −(ŷⁿ − f(xⁿ))·xᵢⁿ
→ wᵢ ← wᵢ − η Σₙ −(ŷⁿ − f(xⁿ))·xᵢⁿ
```

**更新量取决于三件事** [20:26–21:44]：① learning rate（自己挑）② `xᵢⁿ`（来自 data）③ **`ŷⁿ − f(xⁿ)`：现在的输出离目标有多远**（越远，更新越大 → 合理）

⭐ **[21:44] 与 linear regression 的更新式一模一样**：唯一的差别是"target 一定是 0/1、f 一定在 0~1"，而 linear regression 的 target 和输出都可以是任意实数。
→ 所以老师说**作业二"八成都不用改 code"** [22:50]

**推导三步（老师投影片的三个叠加阶段）**

![[P17_02_推导1_ln-sigma的偏导.png]]
*第 1 步 [16:47–18:21]：`∂lnσ(z)/∂z = (1/σ(z))·σ(z)(1−σ(z)) = 1−σ(z)`（红笔划掉 σ(z)）；右上角配了 σ(z) 与 σ′(z) 的曲线（头尾平、中间陡）*

![[P17_03_推导2_ln-1-sigma的偏导.png]]
*第 2 步 [18:22–19:06]：`∂ln(1−σ(z))/∂z = −1/(1−σ(z))·σ(z)(1−σ(z)) = −σ(z)`*

![[P17_04_推导3_合并得结果.png]]
*第 3 步 [19:07–20:26]：两项合并 → `Σ −[ŷⁿ(1−f)xᵢⁿ − (1−ŷⁿ)f xᵢⁿ]` → 消项 → `Σ −(ŷⁿ − f)xᵢⁿ`*

> 📌 插话（[22:58–24:17]，老师说给作业一写的）：**真实资料上 gradient descent 并不容易**；linear regression 还能"偷用 least square 求最佳解当初值"，**但 deep learning 不能这么做**，那时才会真正卡翻。

### 四、多分类：softmax + one-hot

```
每个 class 一组自己的 w、b：
  z₁ = w₁ᵀx + b₁,  z₂ = w₂ᵀx + b₂,  …,  z_K = w_Kᵀx + b_K
  y = softmax(z)      yᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}
  ŷ = one-hot（class1 → 100，class2 → 010，class3 → 001）
  loss = 交叉熵(y, ŷ)
```

![[P17_09_多分类_softmax与交叉熵_缺负号.png]]
*整条链路（[48:03–54:26]）：`x` → **三组各自的 w、b** → `z₁ z₂ z₃` → **Softmax** → `y` ⇄ 与 target `ŷ` 算 **Cross Entropy**；下方是三种情况的 one-hot。*

> ⚠️ **投影片笔误（老师当场自己发现）**：图中的 `Σᵢ ŷᵢ ln yᵢ` **少了最前面的负号**。老师 [54:15] 原话：*"我就发现我写错了……这边前面应该要有一个负号。"*
> **正确写法：`−Σᵢ ŷᵢ ln yᵢ`** —— 交叉熵定义里那个负号不能丢（丢了整个值就是负的，也不能当 loss 去最小化）。

- **数字例** [49:31]：`z = [3, 1, −3]` → `exp = [20.09, 2.72, 0.05]`，总和 22.85 → `y = [0.88, 0.12, 0.002]`
- **softmax 的效果**：输出值一定 **0~1**、总和一定 **1** → 可以当 posterior probability [51:32]
- **为什么叫 soft**max [50:37]：取 exp 会把大值和小值的差距**拉得更开**（强化大值），所以不是 hard 的取最大
- ⭐ **为什么是 one-hot 而不是 1/2/3** [54:43–55:26]：
  1. `1/2/3` 的总和是 6 **不是概率分布 → 根本没法算交叉熵**（[54:43] 原话："ŷ 显然也必须要是一个 probability distribution"）
  2. `1/2/3` 还暗示了"class3 和 class2 比较近"这种**不存在的序关系**
- **[55:46] 多分类的交叉熵同样来自最大化 likelihood**，"和 binary 的情况**一模一样**"

**🅿️22 短版补的五条（同一件事，换个说法/多给一个理由）**

- 🅿️22 [02:52]–[03:24] **什么情况下"编号成 1/2/3"勉强可以**：class 之间**真的有某种关系**时 —— 例："根据身高体重预测他是**几年级**的小学生"，一年级确实离二年级比较近；class 之间**没有特定关系**时就很奇怪（会对 class1↔class2 与 class1↔class3 预设远近）。
- 🅿️22 [03:24]–[04:21] **one-hot 第一条理由的原始出处**：「如果你把这个 one-hot vector 拿来算距离的话，**class 之间量量它们的距离都是一样的**」（= 不再暗示远近）。
- 🅿️22 [08:06]–[08:27] **为什么先取 exponential**：「本来不管 y 是正的还是负的，**取完 exponential 以后就都变成正的**」，然后才拿去 normalize（⚙️ 两步：**exp → 除以总和**）。
- 🅿️22 [09:56]–[10:04] **名字**：softmax 的**输入** y 往往就叫 **logit**。
- 🅿️22 [10:04]–[11:01] **两个 class 时**：更常见的写法是**不套 softmax、直接取 sigmoid**，而且两者**等价**（老师让你自己推 —— 结论见上文「公式与推导要点」的 `softmax([z₁,z₂])₁ = σ(z₁−z₂)`）。

**🅿️22 ⭐⭐ PyTorch 实作：softmax 藏在 `CrossEntropyLoss` 里（[13:48]–[14:57]）**

- 老师原话：「在 PyTorch 里面，**cross entropy 跟 softmax 它们是被绑在一起的**，它们是一个 set。**你只要 call cross entropy，里面就自动内建了 softmax**。」
- ⇒ **助教作业二的程式里找不到 softmax 是正常的**（不是漏写）：softmax 应该在网络最后一层，但它被放进 loss 里了。
- ⚠️ **反过来的坑**：「如果你今天在用 PyTorch，**你自己在网络里加 softmax 的时候，你用 cross entropy 就会变成加了两次 softmax**。」

### 五、cross entropy 的直观含义

one-hot 让交叉熵只剩一项：

```
C = −Σᵢ ŷᵢ ln yᵢ    →  ŷ=[0,1,0] 时  →  C = −ln y₂
```
→ **只惩罚"你给正确答案分配的概率有多低"**：给 0.88 → C=0.13；给 0.99 → C=0.01

### ⭐ 六、为什么不能用 square error

![[P17_05_交叉熵vs平方误差_loss曲面.png]]
*老师投影片的 3D loss 曲面（[27:37–29:35]）：**黑网格 = Cross Entropy，红网格 = Square Error**。投影片左下角引用了出处 `jmlr.org/proceedings/papers/v9/glorot10a/glorot10a.pdf`（= **Glorot & Bengio 2010**）。*

**理由（一句话）**：square error 的梯度会**多乘一个 `f(1−f)` 因子**。

| 情况 | square error 的梯度 | 合理吗 |
|---|---|---|
| `ŷ=1`，`f` 已经 = 1（**离目标很近**） | `2(f−ŷ)f(1−f) = 0` | ✅ 该停 |
| `ŷ=1`，但 `f` = 0（**离目标很远**） | 也 `= 0`（因为乘了 `f`） | ❌ **该大步走，却一动不动** |

→ 所以 **square error 在"离目标远"的地方非常平坦**，随机初始值通常就在远处 → **一开始就卡住**、跑几小时也不动 [29:07]

**而且不能靠调大 learning rate 补救** [29:35]：微分小**也可能**代表"离目标很近"，你分不清 —— 老师原话：*"你在玩世纪帝国，你不知道你距离目标到底是很近还是很远。"*

**对比**：cross entropy 离目标越远、微分越大 → 走得越快 → **训练顺很多** [30:20]

> 📌 做题时的记忆钩子：**"平方误差在犯错时反而不给力"** —— 错得越离谱，梯度越小。

#### 🅿️22 短版的版本：几何视角（[14:57]–[19:14]）—— 同一件事，从"曲面形状"看

![[P22_01_MSE与CE误差曲面对比与实验设定.png]]
*P22 的核心投影片（[15:47]–[18:33]）。**上**=实验设定：`x` → **Network** → `y₁ y₂ y₃`（**y₁: −10~10、y₂: −10~10、y₃ 固定 −1000**）→ **softmax** → `y₁′ y₂′ y₃′` ⇄ 与正确答案 `ŷ=(1,0,0)`（最左的 one-hot）算距离 **e**。**下**=两种 loss 的 error surface：**左 MSE** 左上角是一整片没有斜率的平台（蓝点标 **stuck!**）；**右 cross-entropy** 同一位置有斜率，箭头一路指向右下角的 small loss。*

| | cross entropy | MSE |
|---|---|---|
| 左上角（y₁ 小、y₂ 大 → **错得离谱**）的斜率 | **有斜率** ✅ | **非常平坦、gradient 趋近 0** ❌ |
| 右下角（y₁ 大、y₂ 小 → 接近正确答案） | loss 小 | loss 小 |
| 从左上角出发 | [18:03]「有办法透过 gradient **一路往右下的地方走**」 | [18:07]「**你就卡住了**」 |

⚠️ **一个前提别漏**（[18:42]–[19:02]）：「**当然这个是在你没有好的 optimizer 的情况下**……今天如果你用 **Adam**，这个地方 gradient 很小，那 gradient 很小之后**它 learning rate 会自动帮你调大，也许你还是有机会走到右下角**。不过这会让你的 training 比较困难一点、让你的 training **起步比较慢一点**。」

⭐⭐ **P22 要传达的最后一句话**（[19:02]–[19:14]）：「就算是 **loss function 的定义**，都可能影响 training 是不是容易」→「**你可以改 loss function，居然可以改变 optimization 的难度**」（呼应 P21 那句"把 error surface 铲平"）。

> 📌 **两版合起来记**：**本集（代数）**= 梯度里多一个 `f(1−f)` 因子 → 远处梯度也趋 0；**P22（几何）**= error surface 在 loss 最大的地方**就是平的**。**同一现象、两个视角**；"救不救得回来"的口径见文末易错点 5。

### ⭐ 七、discriminative vs generative

|              | **discriminative**（本集）       | **generative**（P16）                  |
| ------------ | ---------------------------- | ------------------------------------ |
| 做什么          | **直接**把 w、b 当未知参数，梯度下降最小化交叉熵 | **先**最大似然估 μ¹、μ²、Σ → **再套公式**算出 w、b  |
| function set | `σ(wᵀx+b)`                   | `σ(wᵀx+b)`（**共用 Σ 时）→ 一模一样** [31:43] |

| 受数据量影响       | **大**（"看着 data 说话"）          | **小**（"有时会无视 data，遵从内心的假设"）          |
| P16 数据集成绩    | **79%**                      | 73%                                  |

*两个方法在**同一组资料**（All: total, hp, att, sp att, de, sp de, speed，共 7 个特征）上画出的边界（[35:07–36:01]）：**左 generative = 73%，右 discriminative = 79%**。*

## 公式与推导要点

**Model（Step 1）**
```text
f(x) = σ(z),   z = Σᵢ wᵢxᵢ + b
```

**Loss（Step 2）**
```text
likelihood:  L(w,b) = Πₙ P(正确类别 | xⁿ)，  二分类时 = Πₙ f^{ŷⁿ}(1−f)^{1−ŷⁿ}
等价转换:    argmax L  ⟺  argmin (−ln L)
展开:        −ln L = Σₙ −[ ŷⁿ ln f(xⁿ) + (1−ŷⁿ) ln(1−f(xⁿ)) ]   ← 两个 Bernoulli 的交叉熵
多分类:      −ln L = Σₙ Σᵢ −ŷⁿᵢ ln yᵢⁿ   （y = softmax(z)，ŷ = one-hot）
```

**Gradient（Step 3）**
```text
∂(−lnL)/∂wᵢ = Σₙ −(ŷⁿ − f(xⁿ))·xᵢⁿ
wᵢ ← wᵢ − η Σₙ −(ŷⁿ − f(xⁿ))·xᵢⁿ          ← 与 linear regression 的更新式【完全相同】
```

**softmax**
```text
yᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}      性质：yᵢ ∈ (0,1)；Σᵢ yᵢ = 1
二分类退化：softmax([z₁,z₂])₁ = σ(z₁ − z₂)
```

**square error 的梯度（对比用）**
```text
∂/∂wᵢ [½(f−ŷ)²] = (f − ŷ)·f(1−f)·xᵢ      ← 多了 f(1−f) → 离目标远时它 → 0 → 卡住
```

**🅿️22 两种"距离"（[11:01]–[12:37]；MSE = 作业一同款写法）**
```text
MSE:  e = Σᵢ (ŷᵢ − y′ᵢ)²
CE :  e = − Σᵢ ŷᵢ · ln(y′ᵢ)      ← ŷ 是 one-hot ⇒ 实际只剩"正确那一类"的 ln 项
恒等式：minimize cross entropy  ⟺  maximize likelihood（同一件事的两种讲法）
```

| **discriminative（logistic regression）** | **79%** |

## 📐 老师留的两个推导（补全）

> 老师在本集留了两个练习：**A. K 个高斯共用 Σ → softmax**（[51:56–52:14]，并让参考 Bishop 的书）；**B. 多分类交叉熵 = 最大化 likelihood**（[55:46–56:26]）。
> ⭐ **这两个练习不是新知识点，而是「同一件事的两面」——都是「2 类 → K 类」的推广**：
> | 练习 | 来源 | 推广动作 |
> |---|---|---|
> | A. softmax | P16「2 个高斯 → sigmoid」 | 类别数 2 → K |
> | B. 多分类 CE | 本集 [06:01–13:30]「二分类 CE = 最大似然」 | 类别数 2 → K |
> 两个练习问的是同一个问题：**"把'二选一'的写法换成'K 选一'的写法，会变成什么？"**（问模型 → softmax；问 loss → 多分类 CE）
> **旁证**：老师把它们**留成作业而非讲课内容**，本身就说明"这是练手，不是新知"。

### 推导 A：K 个高斯（共用 Σ）→ softmax

```text
设定：K 个类别；每类一个高斯，【共用同一个 Σ】；先验 P(Cᵢ) = Nᵢ/N

P(Cᵢ|x) = P(x|Cᵢ)P(Cᵢ) / Σⱼ P(x|Cⱼ)P(Cⱼ)

代入 P(x|Cᵢ) = 1/((2π)^{D/2}|Σ|^{1/2}) · exp(−½(x−μⁱ)ᵀΣ⁻¹(x−μⁱ))
指数展开：−½(x−μⁱ)ᵀΣ⁻¹(x−μⁱ) = −½xᵀΣ⁻¹x + μⁱᵀΣ⁻¹x − ½μⁱᵀΣ⁻¹μⁱ

于是 P(x|Cᵢ)P(Cᵢ) = [1/((2π)^{D/2}|Σ|^{1/2})] · exp(−½xᵀΣ⁻¹x) · exp(μⁱᵀΣ⁻¹x − ½μⁱᵀΣ⁻¹μⁱ) · P(Cᵢ)
                     └────── 与 i 无关 ──────┘  └─ 与 i 无关 ←【共用 Σ 的全部作用】─┘  └ 与 i 有关 ┘
                                   ↑ 前两个因子分子分母都有 → 约掉
剩下：P(Cᵢ|x) = exp(zᵢ) / Σⱼ exp(zⱼ)            ← softmax
其中 zᵢ = μⁱᵀΣ⁻¹x − ½μⁱᵀΣ⁻¹μⁱ + ln P(Cᵢ)       ← 对 x 是【一次式】
```

- **反过来**：若 Σᵢ ≠ Σⱼ → `−½xᵀΣᵢ⁻¹x` 随 i 变 → 约不掉 → zᵢ 含二次项 → **就不是 softmax**（对应 P16 的弧线边界）
- **验算（K=2 退化成 P16 的 sigmoid）**：`softmax([z₁,z₂])₁ = σ(z₁−z₂)`，而
  `z₁ − z₂ = (μ¹−μ²)ᵀΣ⁻¹x − ½μ¹ᵀΣ⁻¹μ¹ + ½μ²ᵀΣ⁻¹μ² + ln(N₁/N₂) = wᵀx + b` ✅ **与 P16 的 z 完全一致**

### 推导 B：多分类交叉熵 = 最大化 likelihood

```text
① 单笔——模型给"正确类别"的概率：
     P(正确类别|xⁿ) = Πᵢ yᵢⁿ^{ŷⁿᵢ}      ← one-hot 让其余项变成 yᵢ⁰ = 1
     （categorical 版的 p^x(1−p)^{1−x}；K=2 时退化成 Bernoulli 版）

② N 笔独立 → 相乘：L = Πₙ Πᵢ yᵢⁿ^{ŷⁿᵢ}

③ 取 log（乘 → 加）+ 加负号（max → min）：
     −ln L = −Σₙ Σᵢ ŷⁿᵢ ln yᵢⁿ          ← 多分类交叉熵

④ one-hot 让内层求和只剩一项：
     −ln L = −Σₙ ln yⁿ_{cⁿ}              （cⁿ = 第 n 笔的正确类别）
     →「让正确答案的概率越大越好」
```

- **验算（K=2 退化成 [10:16] 的式子）**：`y₁=f, y₂=1−f`，`Πᵢ yᵢ^{ŷᵢ} = f^ŷ(1−f)^{1−ŷ}` → `−ln L = −Σₙ[ŷⁿ ln f + (1−ŷⁿ)ln(1−f)]` ✅

**⭐⭐ `Πᵢ yᵢ^ŷᵢ` 到底在算什么（2026-09-19 补｜➕ 补充的算例；🧠 "多分类 CE 的计算"是你本轮点名的卡点）**

**(1) 指数在这里不是"幂运算"，是"开关"** —— 这是整条推导唯一需要"想通"的地方：

- `ŷᵢ = 1` → 这一项**打开**（留下 `yᵢ`）
- `ŷᵢ = 0` → 这一项**关掉**（因为**任何数的 0 次方 = 1**，"乘 1"不影响结果）

⇒ **K 个开关、one-hot 保证只有一个开着** ⇒ 乘积 = `y_正确类` = "**模型给正确答案的概率**"。
⇒ 二分类的 `f^ŷ(1−f)^{1−ŷ}` 是**同一招**（2 个开关，一开一关）；`f^0 = 1` **不是** `f^0 = 0`。

**(2) 逐项算一遍**（用 §四 [49:31] 那组数：`z=[3,1,−3]`、正确答案 = **class 2**）

| k | zₖ | exp(zₖ) | yₖ = exp/Σ | ŷₖ（开关） | ŷₖ·ln yₖ |
|---|---|---|---|---|---|
| class1 | 3 | 20.09 | 0.88 | **0** | 0 × ln0.88 = **0** |
| **class2** | 1 | 2.72 | **0.12** | **1** | 1 × ln0.12 = **−2.12** |
| class3 | −3 | 0.05 | 0.002 | **0** | 0 × ln0.002 = **0** |
| | | Σ = 22.85 | Σ = **1** ✓ | | Σ = **−2.12** |

```text
CE = −(−2.12) = 2.12        且   −ln 0.12 = 2.12 ✓
⇒ 不论 K 是 3 还是 1000，永远化简成同一句话：CE = −ln(模型给正确答案的概率)
```

⚠️ **由此可知一件容易漏的事**：**CE 并不直接惩罚"你给错误类别分配了多少概率"** —— 它只看**正确答案那一格有多高**。错误类别之所以会被压低，是因为 **softmax 强制和为 1**（给对了就没得分给别人）。
⇒ 这个"耦合"是 **softmax 带来的，不是 CE 带来的** ⇒ 又一条"[激活函数] 与 [损失函数] 该分成两个零件"的实证（见下一节）。

### ⭐ 两个推导的「一句话版本」（必须能说出来）

| 练习 | 一句话 |
|---|---|
| **A. softmax 从哪来** | K 个高斯**共用 Σ** → 与类别无关的底座**约掉** → zᵢ 是 x 的**一次式** → 归一化 = softmax |
| **B. 多分类 CE 从哪来** | 把"模型给正确类别的概率"`Πᵢ yᵢ^{ŷᵢ}` 对 N 笔**相乘** → 取 log 变**加** → 加负号变**最小化** = 交叉熵 |

**这两句里藏着的两个要点**：① 不共用 Σ 就约不掉 → 二次 → 不是 softmax；② **loss 不是随便定的，都是从最大似然推出来的**

## 🧭 两条「产出 w、b」的路线 —— MLE 是**共用的原则**，不是其中一条路的名字

> 📅 **2026-09-19 追加（本轮问答沉淀）**。
> **起因（🧠 你自己的纠正）**：一开始把"贝叶斯 + 高斯"和"最大似然"当成**两条对立的路** —— ⚠️ **不对**。**最大似然不是"方法流派"，它是两条路共用的"找参数的原则"**；真正对立的是**生成式 vs 判别式**。
> ⭐ **这一节解决的就是"为什么交叉熵和激活函数容易记混"的根**：**MLE 在两条路上各出现一次 —— 一次落在 μ、Σ（→ 激活函数），一次落在 w、b（→ 交叉熵）。**

### 1. 正确的对比轴

|  | **生成式（generative）** [[第16集_如何做一个分类任务\|第16集]] + 推导 A | **判别式（discriminative）** 本集 |
|---|---|---|
| 建什么模 | 先建 `P(x\|C)` + `P(C)`，再用贝叶斯公式得 `P(C\|x)` | **直接**建 `P(C\|x) = σ(wᵀx+b)` |
| 假设了什么 | **高斯（共用 Σ）** —— 对 x 的分布下了假设 | **不假设 x 的分布** |
| **找参数的原则** | **最大似然** | **最大似然** ← **同一行，两条路共用** |
| MLE 作用在**哪个分布** | **联合 / 类条件**似然 `Πₙ P(xⁿ\|Cⁿ)·P(Cⁿ)` | **条件**似然 `Πₙ P(Cⁿ\|xⁿ)` |
| MLE **直接产出**什么 | **μ、Σ、prior** → 再**算出** w、b | **w、b 本身** |
| 怎么解 | 微分 = 0，**闭式解**（平均值 / 协方差） | **梯度下降**（= 最小化交叉熵） |
| σ / softmax 是什么 | 贝叶斯公式的**推论**（副产品）—— 所以 P16 必须推给你看 | **出发点**（直接假设）—— 所以本集拿来就用 |
| function set | `σ(wᵀx+b)` —— **相同** [31:43] | 同左 |
| 成绩（7 特征） | 73% | **79%** |

**区分两条路只有一句话：likelihood 里"对谁求概率"。**
（学术名 = **联合似然 vs 条件似然**；Ng & Jordan 2001 讲的就是这条轴。）

### 2. MLE 在度量什么 —— **不是准确度，也不是纯粹的分类能力**

⚠️ **似然/CE 与 accuracy 是两套完全不同的度量，甚至会反向**（二分类、2 笔资料）：

| | 例1 给正确类 | 例2 给正确类 | **accuracy** | **总 CE** |
|---|---|---|---|---|
| 模型 X | 0.51（判对） | 0.51（判对） | **1.0** | **1.35** |
| 模型 Y | 0.99（判对） | 0.40（判错） | **0.5** | **0.93** |

→ **Y 准确度更低、CE 反而更低**（两套度量可以指向相反方向）；而两个"都判全对"的模型 accuracy 相同、CE 可以**差几十倍** —— **accuracy 分不出的东西，CE 能分**。
→ 之所以仍用 CE：**"数分错几个"不可微**（[[第16集_如何做一个分类任务|第16集]] [13:42–15:49] 老师明说这条路走不通），**CE 是它的可微代理（surrogate loss）** —— **代理与最终想要的指标不必完全一致**。

**三层分清**

| 层 | 是什么 | 在哪 |
|---|---|---|
| ① 找参数的**原则** | 最大似然 | **两条路共用** |
| ② 好坏的**具体度量** | 似然 `Π P(…)` / 负对数 = CE | 两条路**各一个**（对**不同**的分布） |
| ③ 真正想要的**指标** | accuracy / **分类能力** | 不可微，**不能直接优化** |

> 🧠 **你的口径澄清（2026-09-19）**：「我说的准确度实际上是模型的**分类能力**。」
> **判定：判别式那边 ✅，生成式那边仍然 ❌** —— 因为生成式优化的**不是"纯分类能力"**，而是"**分类项 + 一个与分类无关的密度拟合项**"的混合（见下条）。
> ⇒ **把"准确度"放宽成"分类能力"，也救不回"两种方法**都**在度量它"这个"都"字。**

### 3. ⭐⭐ 为什么生成式的"分类能力"更差：多出来的那一项

```text
log P(x, C)  =  log P(C|x)   +   log P(x)
     ↑              ↑                ↑
  联合似然      分类那一项     "x 分布拟合"那一项（与分类无关）
```

- **判别式**：只优化 `Σₙ log P(Cⁿ|xⁿ)` ← **纯分类项**
- **生成式**：优化 `Σₙ log P(Cⁿ|xⁿ) + Σₙ log P(xⁿ)` ← 分类项 **+ 额外项**

⇒ 生成式那条路的似然**确实含**分类项（🧠 **你的直觉有来源**），但它被**与分类无关的密度拟合项稀释**了；而且它的 w、b 被 μ、Σ、prior 这个参数化**绑住**，取不到任意的 w、b。
⇒ ⭐ **这就是 73% vs 79% 的机制。**

> ⚠️ **但那一项不全是坏处**：**数据少 / 有噪声 / label 有问题**时，它正是"**脑补**"的来源 → 反而赢（见 §七 [43:06–47:20]）。
> ⇒ **它不是"错"，是"押注"** —— 押"x 的分布大概长这样"：押对了赚，押错了亏。
> ⚠️ **别把口径说死**："生成式 ≠ 分类能力"不等于"生成式更差" —— 胜负取决于**你的假设对不对 + 数据够不够**，73% vs 79% 只是**宝可梦那组数据**下的实测。

## 易错点与纠正

1. **取 log 和加负号是两件事**：log 解决"连乘"（顺便防下溢）；负号解决"max 变 min"。别混成一步
2. **`argmax L ⟺ argmin(−ln L)`**，不是 `argmin(L − ln L)`
3. **逻辑回归没有高斯**：它是 discriminative，**直接假设 `σ(wᵀx+b)`**；高斯是 P16（generative）那条路的事
4. **generative 与 discriminative 的 function set 相同，但找出的 w、b 不同** —— 因为目标不同（联合似然 vs 条件似然），且 generative 多了一层"脑补"
5. **square error 的致命伤是"犯错时不给力"**：多了 `f(1−f)` 因子 → 离目标越远梯度越小 → 一开始就卡住。⚠️ **"救不救得回来"要拆开说（🅿️22 补的口径）**：**固定地调大 learning rate 救不了**（本集 [29:35]：分不清远近）；**自适应 LR（如 Adam）有可能救得回来**（🅿️22 [18:42]–[19:02]），只是**起步更慢、训练更困难**。两句话不矛盾 —— 说的是**两种不同的 LR**。
6. **多分类必须 one-hot**：不只是"避免暗示距离"，更硬的理由是 **`1/2/3` 的总和不是 1、不是概率分布 → 没法算交叉熵**
7. **Gaussian naive Bayes ≠ logistic regression**：默认（各自方差）它是**二次**边界；要线性得强制方差相同
8. **共用 Σ 是"要线性"的取舍，不是普遍真理**：data 少或需要曲线时，各自 Σ（QDA）可能更好
9. **naive（独立）与 generative/discriminative 是两条独立的轴**：naive 管参数多少（高斯）或非线性与否（Bernoulli），**不管**走哪条路
10. **P17 没有回答 "why deep"**：它只回答了"为什么要不止一层"（每层 = 一次特征变换）；**fat vs deep 的坑还挂着**
11. **数字**：7 特征 73%（generative）vs **79%**（discriminative）；`z=[3,1,−3]` → `y=[0.88,0.12,0.002]`；toy example P(C₁\|x)=0.428
12. ⚠️ **投影片有两处笔误，都是老师当场自己发现的** —— 抄式子时别照抄：
    - **toy example 图最下面一行**：`P(x₁=1|C₁) = 1/3`、`P(x₂=1|C₁) = 1/3` → **下标应为 `C₂`**（1/3 是 class 2 的频率）。老师 [38:49]："我发现我犯了一个错……这边应该是 c2"
    - **多分类图里的交叉熵**：`Σᵢ ŷᵢ ln yᵢ` **少了负号** → 正确是 **`−Σᵢ ŷᵢ ln yᵢ`**。老师 [54:15]："我就发现我写错了……这边前面应该要有一个负号"
    - 💡 本集老师**总共当场发现自己写错 6 次**（[02:34] 漏 +b、[08:03] "我怎么会犯这么弱智的错误"、[38:49] 下标、[54:15] 负号、[60:11] 01 写成 10、[65:01] 两轴画反）—— **听到"写错了"别慌，不是你没听懂**
13. 🅿️22 ⚠️⚠️ **PyTorch 实作坑（最容易被扣分的一条）**：**`nn.CrossEntropyLoss` 内部已经含 softmax** —— 网络输出 **logits 直接喂**；自己再加 `nn.Softmax()` = **加了两次 softmax**。「助教作业二里搜不到 softmax」是**正常的**，不是漏写
14. 🅿️22 ⚠️ **"平坦"在两个地方指不同的东西，别混**：[[第20集_批次与动量|P20]] 的"**平坦极小**"说的是 **loss 谷底的形状**（平坦 = 泛化好，是**好事**）；P22 说的"平坦"是 **MSE 在大 loss 区域一整片没有斜率**（= **走不动**，是**坏事**）。同一个词、两个尺度
15. 🅿️22 📝 **符号约定**：本课是 **正确答案加 hat（ŷ）、模型输出不加 hat（y / y′）** —— 老师 [00:54] 说 notation **没有统一规定**（别的课可能反过来），**看到别的资料不一致别慌**
16. 🅿️22 ⚠️ **MSE 不是"永远不能用"**：它是**回归**的标准 loss（HW1 用的就是 MSELoss），**只是不适合配 softmax 做分类**
17. ⚠️ **术语：softmax 干的是「输出归一化」，不是「数据标准化」**（2026-09-19 补）—— 两件事**对象完全不同**：
    | | **数据标准化**（standardize / feature scaling） | **softmax 归一化**（normalize） |
    |---|---|---|
    | 作用在**谁**身上 | **输入 x**（或中间特征） | **输出 z（logits）** |
    | 干什么 | 减均值除标准差之类，**量纲对齐** | exp → **除以总和** |
    | 为什么 | 让**梯度下降好走** | 让输出**能当概率**（0~1 且和 = 1） |
    | 出现在哪 | P3/P15、HW1 的 `StandardScaler` | 本集 §四 / 🅿️22 |
    共同点只有"都做了某种缩放"一句。💡 **提前量**：**P48 批次标准化（Batch Norm）**会让 "normalization" 这个词第三次出现 —— 养成"先说清作用在**输入 / 中间 / 输出**哪一层"的习惯，那时不会乱
18. ⚠️ **交叉熵不是"反映预测结果"，它是训练信号**（2026-09-19 补）—— 链条是 `输出概率 → CE 打分 → ∂L/∂z = f−ŷ → 更新 w、b → 重新预测`，**CE 处在弯道上、不是终点**。说"反映"是被动观察，实际它**主动指挥**参数往哪改
19. ⭐ **"似然越大" ≠ "分类越准"**（2026-09-19 补）—— 生成式那条路的似然更高、分类却更差（73% vs 79%）；CE 与 accuracy 甚至可以**反向**（反例表见新增的「两条产出 w、b 的路线」一节）。⇒ **似然/CE 是"可微代理"，不是"准确度"本身**
