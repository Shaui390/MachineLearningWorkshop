## 本集讲了什么

**第一堂（00:00–42:16）**

1. **分类任务**：找 function，input 是 object x，output 是它属于哪个 class；应用：贷款审核（accept/refuse）、医疗诊断、手写辨识（中文至少 8000 类）、人脸辨识 [00:01–01:58]
2. **案例：预测宝可梦的属性**（18 种属性）；意义 = 遇到图鉴上没有的宝可梦也能预判属性，用 18×18 属性相克表应对 [02:02–06:11]
3. **数值化**：一只宝可梦 = **7 个数字**的 vector（total strength / HP / 攻击力 / 防御力 / 特殊攻击力 / 特殊防御力 / 速度）；皮卡丘 = [320, 345, 55, 40, 50, 50, 90] [03:43–04:50]
4. **资料切分**：编号 **<400 → training、>400 → testing**（模拟"未来才发现的新宝可梦"）；老师补一句：想更严谨可以从 training 再切 validation [06:29–07:07][21:28]
5. **不要用回归硬做**：class1 = 1、class2 = −1，testing 时以 0 为界判断 [07:25–08:31] → 见"核心概念 1"的两个问题
6. **理想做法**：function 里藏一个 g(x)，g(x)>0 → class 1；loss = **在 training data 上分错的次数** → **但不可微**，所以这节课不走（Perceptron、SVM 走这条路，投影片标 Not Today）[13:42–15:49]
7. **改用几率模型**：需要 4 个值：P(C1)、P(C2)、P(x\|C1)、P(x\|C2)；用两个盒子的机率问题做类比 [15:53–19:19]
8. **generative model 的命名**：因为能算出每个 x 出现的机率 → 知道 x 的 distribution → **可以 sample X 出来** [19:43–20:38]
9. **prior**：training data 里水系 **79** 只、一般系 **61** 只 → P(C1)=0.56、P(C2)=0.44；只挑这两类是因为它们数量最多（18 类分不出来）[20:43–22:00]
10. **为什么 P(x\|C) 可以估**："海龟"例子——不在那 79 只里，但机率不可能是 0 → 假设 79 个点是从**一个机率分布** sample 出来的（79 只只是冰山一角）[22:43–27:07]
11. **高斯分布**：由 **μ（vector）** 和 **Σ（matrix）** 决定；⚠️ 严格说它给的是 **probability density**，不是机率（老师明说，为了不混乱才当机率讲）[27:07–29:43]
12. **Maximum Likelihood**：任何 μ、Σ 都可能 sample 出这 79 个点，但 likelihood 不同 → 找 likelihood 最大的 μ\*、Σ\*；**79 个点是 independent → 机率相乘**；解 = 对 μ、Σ 微分 = 0（μ\* = 平均值、Σ\* = (x−μ\*)(x−μ\*)ᵀ 的平均）[30:48–36:19]
13. **结果**：2 维、各自 Σ → **47%**（边界是**曲线**）；7 个特征 → **54%**（"很糟"）[36:26–42:12]

**第二堂（42:31–69:41）**

14. **老师的观察**："每个 Gaussian 都有自己的 mean 和自己的 variance，是比较少见的做法"；**常见做法是不同 class share 同一个 covariance matrix** [43:42–44:20]
15. **共用 Σ 的理由**：covariance matrix 的大小**与 input feature size 的平方成正比** → feature 大时参数爆炸 → **参数多 → variance 大 → 容易 overfitting** [44:20–44:52]
16. **共用 Σ 时的 likelihood 与 Σ 的算法**：x¹–x⁷⁹ 用 (μ1, Σ)、x⁸⁰–x¹⁴⁰ 用 (μ2, Σ)；**μ1、μ2 算法不变**（各自平均），**Σ = (79/140)Σ¹ + (61/140)Σ²**（按样本数加权平均）[46:20–49:39]；推导老师让引用 **Bishop 的书** [48:43–48:55]
17. **结果的形状**：共用前边界是**曲线** → 共用后变成**直线**；这种 model 叫 **linear model**（"Gaussian 不是 linear 的，但它分两个 class 的 boundary 是 linear 的"）[49:45–51:15]
18. **成绩**：7 个特征 **54% → 73%**；老师补：73% 为什么做到很难分析，因为"这是在**七维空间**中发生的事情……这个就是 machine learning fancy 的地方" [51:17–52:06]
19. **三步骤版本**：Step 1 = posterior probability 那个式子（参数 = prior + distribution）；**Step 2 = 最大化 likelihood（不是 minimize loss）**；Step 3 = trivial [52:08–54:36]
20. **为什么用 Gaussian**："如果我选了别的几率模型，你也会问我同样的问题"；**"这个就不是人工智慧，是你凭人的智慧去决定"**；简单几率模型 → bias 大 variance 小，复杂 → bias 小 variance 大 [54:38–55:25]
21. **独立假设**：假设每个 dimension 独立 → P(x\|C) 拆成乘积（每项一维高斯）→ **等于强迫高维高斯的 Σ 变成 diagonal（非对角线为 0）** → 老师试了，**"坏掉了"**（"feature 间的 covariance 看来是必要的"）[55:26–57:22]
22. **binary feature**（是/不是神兽）不该用高斯（"太自欺欺人"）→ 用 **Bernoulli distribution** [57:23–58:13]
23. **naive Bayes classifier**：假设所有 feature 独立的方法；naive = "它真的很 naive、真的很简单"；**"它强不强，就代表你的假设是否精准"**（假设不成立 → bias 太大就不是好 classifier）[58:14–59:11]
24. **后验概率 → sigmoid**：分子分母同除 → `1/(1+exp(−z))` = σ(z)；z→∞ 输出 1、z→−∞ 输出 0 [59:12–60:50]
25. **z 的推导（数学段）**：log 拆开 → 先验比 = N1/N2 → 两高斯相除取 log（常数项约掉、指数相减）→ 二次型展开、中间两项合并 → **令 Σ1=Σ2=Σ：determinant 项消掉 + 两个 `±½xᵀΣ⁻¹x` 相消** → 剩 5 项 → 提出 x → `wᵀ=(μ1−μ2)ᵀΣ⁻¹`；剩下三项都是 scalar → `b` [61:04–67:40]
26. **结论 + 反问**：generative model = 先估 N1、N2、μ1、μ2、Σ → 再算 w、b；老师反问"这不是舍近求远吗？你在做一件你根本就不需要做的事……能不能直接找 w 和 b？"——**"这个就是我们下一份要讲的东西"**（视频结束）[67:42–69:41]

## 核心概念

### 1. 不要用回归硬做分类：两个问题

**问题一：回归会惩罚"太正确的答案"** [07:34–12:45]
- 右下角那堆点属于 class 1（target = 1），但回归模型给出的值**远大于 1** → MSE `(ŷ−y)²` 巨大 → 梯度下降为了压低它，把分界线往右转 →
- **对回归来说紫色线更好，对分类来说绿色线才对**：同一个 function，两种任务的好坏标准不同
- 老师结论 [12:04]：**regression 定义 function 好坏的方式对 classification 不适用**

**问题二：多分类编号暗含不存在的"距离"关系** [12:48–13:35]
- class1→1、class2→2、class3→3 等于宣称"class 3 和 class 2 比较近、有某种关系"；如果实际上没有这种关系，就得不到好结果

### 2. 理想做法为什么不用：不可微 [13:42–15:49]
- Model：`if g(x) > 0 → class 1, else class 2`
- Loss：`L(f) = Σₙ δ(f(xⁿ) ≠ ŷⁿ)`（δ = 0/1，加起来 = **分错几次**）
- **致命伤：不能微分** → 梯度下降用不了（[15:28]"叫你解这个 function 你八成不会……这个没办法微分，通通不能微分"）
- Perceptron、SVM 是这条路（投影片标 Not Today）→ 所以改走**几率模型**：可微 + 能套三步骤 + 顺便解释了 sigmoid 从哪来

### 3. 几率模型的框架 [15:53–22:34]
- 需要 4 个值：两个 **prior** P(C1)、P(C2)，两个 **likelihood** P(x\|C1)、P(x\|C2)
- 判定：`P(C1|x) > 0.5 → class 1`
- **为什么叫 generative**：能算每个 x 出现的机率 → 知道 x 的 distribution → **可以 sample 出 X**，所以叫"生成式"
- prior 好算：79/140 = 0.56、61/140 = 0.44

### 4. 高斯 + 最大似然（本集第一个技术核心）[27:07–36:19]
- 假设同一类的点是从**一个高斯** sample 出来的 → 只要估 μ、Σ 两个东西
- **μ 是 vector（中心）、Σ 是 matrix（形状/胖瘦/歪斜）**
- 真实数值 [29:15][36:26]：水系 μ¹=[75.0, 71.3]、Σ¹=[[874, 327], [327, 929]]；一般系 μ²=[55.6, 59.8]、Σ²=[[847, 422], [422, 685]]
  - **Σ 的对角线 = 各特征自己的方差；非对角线 = 两个特征之间的协方差**（327 > 0 → Defense 与 SP Defense 正相关）
- **最大似然的逻辑**：任何高斯都可能 sample 出这 79 个点（因为高斯处处不为 0，只是机率有高有低），但**likelihood 大小不同** → 取 likelihood 最大的那组
- **⚠️ 79 个点是 independent sample → 机率相乘**：`L(μ,Σ) = f(x¹)·f(x²)···f(x⁷⁹)`
- 解：对 μ、Σ 微分 = 0 → **μ\* = 平均值**；**Σ\* = (1/79)Σ(xⁿ−μ\*)(xⁿ−μ\*)ᵀ**
- ⚠️ **老师自己承认的符号坑** [32:45]：likelihood 也写成 **L**，"我想不到更好的 **notation（记法）**，它可能会跟 loss 有点混淆" → **loss 要最小化、likelihood 要最大化，方向相反**

### 5. 共用 Σ（本集第二个技术核心，也是从 54% 到 73% 的关键）[43:42–51:15]
- **动机（老师原话）**：covariance matrix 的**大小与 feature size 的平方成正比** → 7 个特征时 Σ 是 7×7；每类各一个 → **参数多 → variance 大 → 容易 overfitting** → 所以强迫两类**共用同一个 Σ**
- **怎么算**：`Σ = (79/140)·Σ¹ + (61/140)·Σ²`（两个协方差矩阵按样本数**加权平均**）；**μ¹、μ² 不变**（还是各自平均）
- **后果（形状）**：边界从**曲线**变成**直线** → 这种 model 叫 **linear model**
  - 老师特意澄清 [50:57]：**"Gaussian 不是 linear 的，但是它分两个 class 的 boundary 是 linear 的。"**
- **后果（成绩）**：7 个特征 54% → **73%**
  - 老师的态度 [51:32]：为什么能做到很难分析，"因为这是在七维空间中发生的事情……但这个就是 machine learning fancy 的地方"
- **数学上的原因**（见第 7 节）：共用 Σ 使 z 里的**二次项相消** → z 只剩 x 的一次项 → 边界是超平面

### 6. 这套几率模型也是机器学习三步骤 [52:08–54:36]
| 步骤 | 几率模型版 |
|---|---|
| Step 1 function set | `P(C1\|x) = P(x\|C1)P(C1)/[P(x\|C1)P(C1)+P(x\|C2)P(C2)]`；参数 = 两个 prior + 各自 distribution |
| Step 2 好坏的标准 | ⚠️ **最大化 likelihood**（这组参数产生 training data 的似然），**不是 minimize loss** |
| Step 3 怎么找 | "很 trivial"：平均值 + 协方差 |

### 7. 独立假设 → naive Bayes；binary feature → Bernoulli [54:38–59:11]
- **为什么用 Gaussian？** "选了别的几率模型，你也会问我同样的问题"；**"这个就不是人工智慧，是你凭人的智慧去决定"**；简单几率模型 → bias 大 variance 小
- **独立假设**：每维独立 → `P(x|C) = P(x₁|C)P(x₂|C)···P(x_K|C)`，每项一维高斯 → **等于把高维高斯的 Σ 强制变成 diagonal**（非对角线 = 特征间相关性，全部置 0）→ **老师试了：坏掉了**（"不同的 feature 间的 covariance 看来是必要的"）
- **binary feature**（是/不是神兽）用高斯"太自欺欺人" → 用 **Bernoulli**
- **naive Bayes classifier** = 假设所有 feature 独立的方法；naive = 真的很简单；**强不强取决于假设是否精准**（假设不成立 → bias 太大 → 不是好 classifier）

### 8. 后验概率 → sigmoid（其实只有三行）[59:12–60:50]
```text
P(C1|x) = P(x|C1)P(C1) / [P(x|C1)P(C1) + P(x|C2)P(C2)]
        = 1 / [1 + P(x|C2)P(C2)/(P(x|C1)P(C1))]      ← 上下同除 P(x|C1)P(C1)
        = 1 / (1 + exp(−z)) = σ(z)
其中 z = ln[ P(x|C1)P(C1) / (P(x|C2)P(C2)) ]
```
- 形状：z→∞ → 1；z→−∞ → 0
- **意义**：sigmoid **不是被设计的激活函数**，而是"把一个几率比取 log"的必然产物

### 9. z 的推导：为什么最后变成 `wᵀx + b` [61:04–67:40]
（老师说"觉得无聊就睡一下，听结论就好"——步骤表见"公式与推导要点"）
- **最关键一步**：令 **Σ1 = Σ2 = Σ** → ① determinant 项 `ln|Σ²|^½/|Σ¹|^½` 消掉 ② **`−½xᵀΣ1⁻¹x` 与 `+½xᵀΣ2⁻¹x` 相消**
- 于是 z 里**没有 x 的二次项**，只剩一次项 → 边界是直线
- **w、b 的定义**：`wᵀ = (μ1−μ2)ᵀΣ⁻¹`；`b = −½(μ1)ᵀΣ⁻¹μ1 + ½(μ2)ᵀΣ⁻¹μ2 + ln(N1/N2)`
- 老师对 b 的安抚 [66:43]："看起来可怕，但它很简单……vector × matrix × vector 就是一个 **scalar**，它就是个数字"

### 10. 结尾反问 → 下一集 [67:42–69:41]
- generative model 流程：**先估 N1、N2、μ1、μ2、Σ → 再算出 w、b**
- 反问："为什么要这么麻烦呢？……**这不是舍近求远吗？你在做一件你根本就不需要做的事**……所以我们能不能够直接把 w 和 b 找出来？"
- [69:35] **"这个就是我们下一份要讲的东西。"** → 下一集 = 判别模型／逻辑回归（直接把 w、b 当参数用梯度下降）

## 公式与推导要点

**贝叶斯公式（判定规则）**
```text
P(C1|x) = P(x|C1)P(C1) / [P(x|C1)P(C1) + P(x|C2)P(C2)]        （分母 = 全概率公式）
if P(C1|x) > 0.5 → class 1 (Water)，否则 class 2 (Normal)
```

**高斯密度（D 维）**
```text
f_{μ,Σ}(x) = 1/((2π)^{D/2} |Σ|^{1/2}) · exp{ −½ (x−μ)ᵀ Σ⁻¹ (x−μ) }
```

**最大似然（79 个点独立 → 相乘）**
```text
L(μ,Σ) = f(x¹)f(x²)···f(x⁷⁹)
μ* = (1/79) Σ xⁿ
Σ* = (1/79) Σ (xⁿ − μ*)(xⁿ − μ*)ᵀ
```

**共用 Σ 时的最大似然**
```text
L(μ1,μ2,Σ) = f_{μ1,Σ}(x¹)···f_{μ1,Σ}(x⁷⁹) × f_{μ2,Σ}(x⁸⁰)···f_{μ2,Σ}(x¹⁴⁰)
Σ = (79/140)Σ¹ + (61/140)Σ²          （μ1、μ2 不变）
```

**z 的推导（8 步速查）**

| # | 动作 | 结果 |
|---|---|---|
| 1 | `z = ln[P(x\|C1)P(C1)/(P(x\|C2)P(C2))]`，乘法取 log 变加法 | 拆成"似然比 + 先验比" |
| 2 | 先验比 `ln[P(C1)/P(C2)]` | `= ln(N1/N2) = ln(79/61)`（"小学生的数学"） |
| 3 | 似然比：两个高斯相除取 log | 常数 `1/(2π)^{D/2}` 约掉；`|Σ|` 项提出；指数相减 |
| 4 | 展开二次型 | `(x−μ)ᵀΣ⁻¹(x−μ) = xᵀΣ⁻¹x − 2μᵀΣ⁻¹x + μᵀΣ⁻¹μ`（中间两项一样 → 合并） |
| 5 | ⭐ 令 Σ1 = Σ2 = Σ | determinant 项消掉；**两个 `±½xᵀΣ⁻¹x` 相消** |
| 6 | 剩下 5 项 | 只有 2 项含 x，3 项不含 |
| 7 | 把 x 提出来 | 得到 `wᵀ = (μ1−μ2)ᵀΣ⁻¹` |
| 8 | 剩下三项都是 scalar | 加起来 = `b = −½(μ1)ᵀΣ⁻¹μ1 + ½(μ2)ᵀΣ⁻¹μ2 + ln(N1/N2)` |

**最终形式**
```text
P(C1|x) = σ(wᵀx + b)        ← x 只有一次项 → 分界线是直线（linear model）
```

**成绩总表**

| 模型 | 正确率 |
|---|---|
| 2 个特征（Defense、SP Defense），各自 Σ | **47%**（边界是曲线） |
| 7 个特征，各自 Σ | **54%**（老师："很糟"） |
| 7 个特征，**共用 Σ** | **73%** |

## 易错点与纠正

1. **likelihood ≠ loss，但都写成 L**：loss 越小越好、likelihood 越大越好，方向相反。老师自己也说这个 notation 会混淆 [32:45]
2. **likelihood 是"相乘"不是"相加"**：默认样本 independent → 联合机率 = 各点机率相乘；取 log 之后才是相加
3. **g(x)、f(x) 输出的是 probability density**，不是机率（老师明说，为了不混乱才当机率讲）[27:39]
4. **"全概率公式" vs "贝叶斯公式"**：整个后验概率式子 = 贝叶斯公式；分母那一坨 = 全概率公式
5. **不要用回归做分类**：MSE 会惩罚"太正确但数值太大"的点 → 分界线被拉歪；多分类编号还会暗含不存在的距离关系
6. **共用 Σ 不是"随便简化"**：它是"参数少 → variance 小 → 不过拟合"的取舍（Σ 大小 ∝ 特征数的平方），代价是"假设两类的形状一样"
7. **"独立假设"不是更好而是更简单**：它把 Σ 强制成 diagonal → 实测坏掉（特征间的协方差是必要的）
8. **sigmoid 在这集是被"算出来"的**：`1/(1+e^{−z})` 来自"几率比取 log"，不是人为挑的激活函数
9. **z 的线性完全来自"共用 Σ"**：不共用 Σ 时 z 里有二次项 → 边界是曲线（这就是 47% 那张图的弧线）
10. **数字**：2 维 47% → 7 维 54% → 共用 Σ 73%；μ¹=[75.0,71.3]、Σ¹=[[874,327],[327,929]]；样本 79 + 61 = 140

### B. softmax 和 sigmoid 是同一条推导 ⭐

**老师本人在 P17 [51:56–52:14] 说了**：*"如果有三个 class，假设那三个 class 通通都是 Gaussian 的 distribution，他们又共用同一个 covariance matrix，在这个情况下，你做一番推导以后，你得到的就会是这个 softmax 的 function。那这个就留给大家自己做。"*（并让参考 Bishop 的书；[52:26] 又提了从 information theory 推的 **maximum entropy**，那是同一个东西换个名字）

推导套路跟本集**完全一样**，只是把 2 个高斯换成 K 个：

```text
P(Cᵢ|x) = P(x|Cᵢ)P(Cᵢ) / Σⱼ P(x|Cⱼ)P(Cⱼ)
代入高斯、指数展开：exp( −½xᵀΣ⁻¹x + μⁱᵀΣ⁻¹x − ½μⁱᵀΣ⁻¹μⁱ )
分子分母都有同一个 −½xᵀΣ⁻¹x（共用 Σ）→ 约掉（就是本集图上红笔划掉那两行）
→ P(Cᵢ|x) = exp(zᵢ)/Σⱼexp(zⱼ)，zᵢ = μⁱᵀΣ⁻¹x − ½μⁱᵀΣ⁻¹μⁱ + ln P(Cᵢ)   ← 仍是 x 的一次式
```

⭐ **收尾**：二分类时 `z₁ − z₂` 正好等于本集推出来的 `wᵀx + b`（因为 `wᵀ=(μ¹−μ²)ᵀΣ⁻¹`）—— 两条路在这里对上了。

### C. 输出是"行向量"还是"列向量"？

softmax 的输出是 **K 维向量**。若要写成矩阵形式，**K×1 叫列向量、1×K 叫行向量**（"列矩阵"不是标准叫法）。

- **李宏毅的写法 `xW+b` 里 x 是行向量 → 输出也是行向量**；教科书常写 `Wx+b`（列向量）。**纯粹是排版约定，数字一样。**
- softmax **不在乎行还是列**——它只是"对一组数取 exp 再归一化"。
- 对照：本集的 `wᵀx` 里 w 是**列**向量、wᵀ 是行向量，所以 wᵀx 是标量。
- 统一记：**行 × 列 = 一个数；列 × 行 = 一个矩阵。**

### D. K 是谁定的？

- **本质：K = 类别数**（否则无法与 one-hot 标签算交叉熵）
- **结构：K = output layer 的 neuron 个数**（`xW+b` 约定下 = W 的列数）
- **⚠️ softmax 本身完全没有参数、也不改变维度**（K 进 K 出）——它和 sigmoid 一样是无参数运算。所以"K 由前一层决定"与"K 由类别数决定"是**同一件事的两种说法**。
- ❌ **不能"让 output layer 干脆就是一层 softmax"**：softmax 无参数、K 进 K 出，做不了"256 → 10"这一步。少了那个带权重的 Linear，维度会停在 256 → 你会得到一个 **256 类**的概率分布。**决定 K 的永远是最后一个带权重的层**（想改 K 就改 `nn.Linear(256, K)`）。
- ⚠️ **别把"前一层"理解成"最后一个 hidden layer"**：hidden layer 的宽度是**自由超参数**（256、1000 随便选），只有 **output layer 的宽度被类别数锁死**。
- **三样东西要分清**：**logits（z，output layer 算出的 K 个分数）→ softmax（无参数运算，把分数变概率）→ y（K 维概率，和为 1）**

### E. softmax 算不算"一层"？

- **两种术语都通行**：Keras 写成**一层** `Dense(10, activation='softmax')`（Linear + softmax 合成一层）；PyTorch 习惯 `nn.Linear(256, 10)` 单独一层、softmax 塞进 loss。**同一个东西，两种写法。**
- ✅ **本笔记采用 PyTorch 记法：softmax 不算一层。** 这也和课程自己的定义一致——P13 说"每一排 neuron = 一层"，而 softmax 不是由 neuron 组成的。
- **实践含义：数"几层网络"时只数带权重的层。** AlexNet 8 层 = 5 conv + 3 FC；VGG19 = 16 conv + 3 FC——**ReLU / pooling / softmax / dropout 都不计入**（呼应 P13 的 ResNet 152 层）。
- ⚠️ 但 **"不是一层" ≠ "可以忽略"**：softmax 仍在计算图里、反向传播要穿过它——[[第14集_反向传播|第14集]] 那条漂亮结论 **`∂C/∂z = y − ŷ`** 正是"softmax + 交叉熵"合起来的结果。准确说法是"**无参数的运算**"，不是"无梯度的部分"。

### F. 输出层的 neuron 要不要激活函数？

> 起因：我一度说"输出 logits 不需要神经元，用线性就行"——**前半句要修**。

- **那个线性层正是由神经元组成的。** **神经元的判据是"有没有一组自己的权重 + bias"，不是"有没有激活函数"**；每个输出维度 = 一个神经元（一组 D 个 w + 1 个 b）。`nn.Linear(256,10)` 的 2570 个参数 = 10 个 neuron × (256 w + 1 b)，正好印证 → **P13 说"output layer 有 N 个 neuron"是对的**。
- **严格的 neuron 定义**：`输出 = φ(Σwᵢxᵢ + b)` —— **φ（激活函数）是定义的一部分**；sigmoid/ReLU 只是 **φ 的实例**。
- **⚠️ 所以"没写激活" = φ 取恒等函数（identity）**，是**特例**，不是"少了一个零件"。**不是"有没有激活"的区别，而是"φ 取什么函数"的区别。**
- **只有 output layer 的 φ 可以是 identity**：hidden layer 若不加非线性，整个网络会退化成**一个大线性模型**（两层 Linear 叠起来 = `x·(W₁W₂) + …` 还是一个 Linear）——这就是 P4/P13 里激活函数"必须要"的根本原因。
- 💡 **"线性 neuron = φ 取 identity"这个看法有三个用处**：① 所有 neuron 统一成一个式子；② 参数量公式统一（φ 不带来参数 → "数 neuron 个数看权重"成立）；③ **反向传播统一**——identity 的导数 `φ′(z)=1` → [[第14集_反向传播|第14集]] 的递推式退化成 `∂C/∂z = Σwⱼ∂C/∂zⱼ`，**线性层的梯度"原样穿过"、没有任何缩放**（P14 那个"三角形"的放大倍率 = 1）

### G. 四种任务的输出层对照（二分类只需 **1** 个 neuron，不是 2 个）

| 任务 | output layer 宽度 | 激活函数 | 写在哪 | loss |
|---|---|---|---|---|
| **回归** | 1（或几个） | **无（identity）** | —— | MSE / MAE |
| **二分类** | **1** | **sigmoid** | 模型里 | BCELoss；或输出 logits 配 CrossEntropyLoss |
| **多分类**（互斥 K 类） | **K** | **softmax** | 常省略、搬进 loss | CrossEntropyLoss（内建 softmax） |
| **多标签**（不互斥 K 个） | **K** | **K 个独立 sigmoid** | 模型里 | BCEWithLogitsLoss |

- **二分类有两种等价写法**：① 1 个 neuron + sigmoid（常见）② 2 个 neuron + softmax —— 因为 `softmax([z₁,z₂])₁ = σ(z₁−z₂)`，输出同一个数。所以"二分类用哪个"不是对错题，是等价写法。
- **多分类不能用 sigmoid**：sigmoid 是**逐元素独立**的 → K 个输出各自 0~1 但**和不必为 1**（例如 0.9/0.8/0.7，和 = 2.4）→ 不是概率分布 → 不能跟 one-hot 算交叉熵。
- **"多分类 output 干脆没有"要理解对**：那是**输出 logits、把 softmax 搬进 CrossEntropyLoss**（[[第13集_深度学习简介#13. softmax 深挖：它是激活函数吗？logits 能直接算交叉熵吗？|第13集]]"三种场景"表里已记过），**不是"不需要 softmax"**。
- **K 个标签不互斥时**（一张图同时有"猫"和"狗"）→ **K 个独立 sigmoid**，这是 **multi-label** 而非 multi-class。

### H. 怎么判断任务是回归还是分类？（⚠️ 不能靠激活反推）

**两个模型的最后一层可能长得一模一样：**

```python
# 多分类（代码里最常见）
nn.Sequential(..., nn.Linear(256, 10))   # φ = identity、后面什么都不接
loss_fn = nn.CrossEntropyLoss()          # softmax 在这里面

# 回归
nn.Sequential(..., nn.Linear(256, 1))    # 同样 φ = identity
loss_fn = nn.MSELoss()
```

所以"output 层是 identity、不接 softmax"只是**回归的典型做法**：**既不是判据**（分类也这样），**也不是必要条件**（预测 0~1 的量时会加 sigmoid 再配 MSE）。

**真正的判据是三个**：① 标签 y 是什么（实数 / 类别）② loss 是什么（MSE / CrossEntropy）③ 输出怎么被解读（直接读数 / argmax）。

💡 **更值钱的认识**：网络本身只是"输入 → 实数向量"的一组函数，**任务由"怎么解释这些数 + 用什么 loss 训练"定义**。以后迁移学习（换 head + 换 loss）、多任务学习（共享 backbone + 多个 head）、BERT 的"预训练 + 微调"都是这个套路。

### I. "逻辑回归"这个名字：留给 P17

- **逻辑回归特指 sigmoid**（不是"任何非 identity 激活"）——ReLU 在输出层就不是。
- **"输出层套 sigmoid" ≠ 逻辑回归**：逻辑回归是**没有 hidden layer 的单层模型**（一个 neuron + 交叉熵 + 梯度下降）；深层网络最后一层是 sigmoid，那叫**神经网络**。
- **softmax 版叫** softmax regression / 多项逻辑回归。
- ⭐ **名字里"regression"的来由**（P17 会正式讲）：它线性回归的是 **log-odds（对数几率）**——
  `z = ln[P(C₁|x)/P(C₂|x)] = ln[P(x|C₁)P(C₁)/(P(x|C₂)P(C₂))]`（**就是本集推的 z**）`= wᵀx + b`（对 x 线性）
  → 我们是在**对 log-odds 做线性回归**，所以叫 logistic **regression**，而任务却是 classification。
