# 第03集：机器学习基本概念（第1讲 P3）

> 本集主题：Machine Learning / Deep Learning 基本概念。讲稿：[[raw/第03集_字幕|字幕存档]]；我的自写笔记：[[第03集_机器学习基本概念（自己写的）]]（已逐条检查，结果见下）。
> 一句话总结：机器学习就是"找一个函数"，分三步（写函数 → 定义 Loss → 梯度下降找参数），用 YouTube 点阅人数预测串起来，最后发现数据有 7 天周期。

---

## 本集讲了什么

1. **机器学习 = 让机器具备"找一个函数"的能力**（语音辨识、影像辨识、AlphaGo 都是函数）
2. **三类任务**：Regression（输出数值）/ Classification（从预设选项里选）/ Structured Learning（产生有结构的物件）
3. **找函数的三步骤**：带未知参数的函数 → 定义 Loss → 优化（Gradient Descent）
4. **真实案例**：预测频道隔天点阅人数，从"只看 1 天"逐步改进到"看 7 天/28 天/56 天"
5. **关键转折**：训练误差 vs 测试误差（2021 没看过的数据上表现更差）；发现数据有 7 天周期性 → 用 domain knowledge 改进模型

## 核心概念

### 1. 机器学习 = 找一个函数
函数太复杂（人类写不出来），所以期待机器自己找出来。机器能找不同的函数 → 任务分三类：

| 任务 | 输出 | 例子 |
|---|---|---|
| **Regression 回归** | 一个数值（scalar） | 预测明天中午 PM2.5（输入：今天 PM2.5/温度/臭氧浓度） |
| **Classification 分类** | 从预设选项（class）里选一个 | Gmail 垃圾邮件（Yes/No）；AlphaGo = 19×19=361 个选项里选落子位置 |
| **Structured Learning 结构化学习** | 产生有结构的物件 | 画一张图、写一篇文章（"黑暗大陆"；拟人化：让机器学会**创造**） |

> 判据：不是"输出是不是被创造出来的"，而是**有没有人类预先准备好的、可枚举的选项集合**。

### 2. 第一步：写出带未知参数的函数
- 模型 y = b + w·x₁：y 是目标值，x₁ 是 **feature**（已知资讯，如前一天观看数），w 是 **weight（权重）**、b 是 **bias（偏差）**，w/b 都叫 **parameter（参数）**——是**未知的**，准备让机器通过资料找出来。
- 带未知参数的 function 就叫 **model（模型）**。
- 怎么猜函数长什么样？靠 **domain knowledge**（对问题的理解，与数学无强相关）——用在**第一步**。

### 3. 第二步：定义 Loss
- **Loss 也是一个 function**：输入是参数（w, b），输出是"这组参数好不好"。
- 用训练资料（2017–2020，3 年 = 365×3 天）算：每天用前一天预测隔天，算误差 e，**L = (1/N) Σ eₙ**，N = 训练资料个数。
- 误差 e 的算法（**不同定义 → 不同 Loss**）：
  - **MAE**：`e = |ŷ − y|`（绝对值）——本课例子用这个
  - **MSE**：`e = (ŷ − y)²`（平方）——作业 1 用这个
  - **Cross Entropy 交叉熵**：当 y 和 ŷ 都是**概率分布**时用（以后细讲）
- 真实值（已知道的答案）叫 **label**。
- 穷举 (w, b) 组合算 Loss → 画 **Error Surface**（误差表面）：横轴 w、纵轴 b、颜色表示 Loss 大小（红=大/差，蓝=小/好）的等高线图；最优点大致在 w≈1、b≈100 多（直觉：前一天观看数 ≈ 隔天观看数）。

### 4. 第三步：Optimization（Gradient Descent 梯度下降）
- 目标：找 w\*, b\* = argmin L。
- 流程（先简化成只有一个参数 w）：
  1. **随机**选初始点 w⁰（先当它是随机的；老师预告以后会有更好的初始方法）
  2. 算 w 对 L 的**微分**（= Error Surface 在 w⁰ 处的**斜率**）
  3. 斜率负（左高右低）→ w 往右变大；斜率正 → 往左变小
  4. 步伐大小 = **斜率 × η**（learning rate）
  5. 更新：**w¹ = w⁰ − η·∂L/∂w**，重复到 w²…
- 停止条件①：**失去耐心**——自己设定最多更新次数（这也是 hyperparameter）；②微分恰好为 0（参数不再移动）。
- **hyperparameter（超参数）**：做机器学习时**需要自己设定**的东西（η、更新次数上限、批次大小……）。本质判据：**谁在更新它**——机器训练中更新的 = 参数；人设好、训练全程不动的 = 超参数。
- 微分不用自己算：PyTorch 等框架**自动微分**，一行代码。
- 两个参数（w, b）时同样：随机 w⁰/b⁰ → 算 ∂L/∂w、∂L/∂b → w¹ = w⁰ − η·∂L/∂w，b¹ = b⁰ − η·∂L/∂b。

### 5. 训练 vs 测试（重要！）
- 三个步骤合起来叫**训练**（training）。
- **训练误差 = 自嗨**：2017–2020 的答案都知道了，只是"假装不知道"再算误差，不是真本事。
- 真正要在意的是：**没看过**的 2021 资料上的误差 **L′**。
- 真实结果（1 天模型）：训练 L = 0.48k（平均误差约 500 人次），测试 L′ = 0.58k（约 580 人）。**训练误差小 ≠ 测试误差小。**

---

## 公式与推导要点

**1 天模型**：y = b + w·x₁ → 实际解 w\* = 0.97，b\* = 0.1k（≈100），训练 0.48k / 测试 0.58k
- 预测曲线几乎就是"把红色真实线**往右平移一天**"（因为 w≈1, b≈100）——只会抄昨天的值。
- 观察真实数据：**每 7 天一个循环，周五、周六观看人数最少**（老师也没参透原因，猜是 YouTube 算法周末不推）→ 需要 domain knowledge 改进模型。

**7 天模型**：y = b + Σ_{j=1}^7 wⱼ·xⱼ（j = 几天前）→ 训练 0.38k / 测试 0.49k

最优参数（训练集上最佳）：

| b | w₁ | w₂ | w₃ | w₄ | w₅ | w₆ | w₇ |
|---|---|---|---|---|---|---|---|
| 0.05k | 0.79 | −0.31 | 0.12 | −0.01 | −0.10 | 0.30 | 0.18 |

- **反直觉**：老师本以为机器会"直接复制 7 天前"（w₇=1, 其他=0），但机器没有——**w₁ 最大（最新信息为主）**，w₇ 只当辅助（周期性），**w₂/w₄/w₅ 是负数**（"刹车/扣除重复"）。机器不知道周期是什么，它只是**最小化误差**，结果是数学自动优化出来的。
- ⚠️ 微负的 w₄ = −0.01（字幕："w4 跟 w5 最佳的值...很反比"）。

**28 天模型**：训练 0.33k / 测试 0.46k（又更好一点）
**56 天模型**：训练 0.32k / 测试 0.46k（**训练还在降、测试不动了**——"考虑天数这件事也许已经到了一个极限"）

> 这些都是 **linear model（线性模型）**：feature × weight + bias 的组合。下一集开场："怎么把 linear model 做得更好"。

## 易错点与纠正（本次互问互答产出）

1. **参数 vs 超参数**：w、b 是**未知参数**，机器学的（不是"设计好的"）！超参数才是人设定的（η、更新次数）。判据：**谁在更新它**。（人设计的是"模型模板长什么样"+"超参数"；机器学的是"填空答案"。）
2. **local minima ≠ 鞍点**：local minima = 碗底（**所有方向**都往上）；saddle point = 马鞍（**一半方向往上、一半往下**——还有路可走）。老师说"local minima 是假议题"的真正伏笔就在这：高维里梯度下降卡住的地方多半是**鞍点**。（🍬彩蛋，后集验证）
3. **梯度方向**：梯度是**上升最快**的方向，梯度下降要走它的**反方向**（w − η·∇L 里的负号）。
4. **训练误差 ≠ 测试误差**：0.48k（自嗨）vs 0.58k（真的）——机器学习真正在意的是没看过的数据。
5. **负权重 ≠ 机器"懂"了什么**：机器不知道星期几，它只是在最小化误差；"为什么长这样"的解释（重复扣除/刹车）是人讲故事，不是机器心路历程。
