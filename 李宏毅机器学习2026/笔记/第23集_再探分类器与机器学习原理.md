## 二、核心概念

### 2.1 玩具模型：一个阈值 H

- **E(图)** = 做 Edge Detection 后白点个数 = 线条复杂程度。
- **f_H(图)** = `数码宝贝 if E(图) > H else 宝可梦`。
- 唯一未知参数：**H（阈值）**。
![[P23_01_Function with unknown parameters_fh阈值与大H.png]]
> 图注（[09:19]–[11:47]）：本集的模型全貌 —— **f(图) = 数码宝贝 if e(图) ≥ h，否则宝可梦**；下方点名 **f_h = function with threshold h**，最后一行给出 **𝓗 = {1, 2, …, 10000}**。⚠️ 注意投影片用的是 **≥ h**，字幕口述说"超过 H / 小于 H"（两种写法在整数白点数上等价，边界那一格归谁无所谓）。

- ⚠️ **模型只有一个数** —— 这是本集刻意的简化，老师明说「以下的讨论，**你完全可以把这个 function 一般化到更复杂的情境**，完全可以把这个 H 换成 deep network 里面的参数」。
- ⭐ **本集结论与 loss 怎么选无关** —— 这是老师**先声明、后使用**的一条：他用错误率只是因为它**直观**（[16:14]–[17:31]「**等一下的讨论跟 Loss Function 的选择是没有关系的**」，另见 §2.4 引的那个理由 2）。⚠️ 但要看清"无关"的**边界**（[42:26]–[43:21]、[55:25]–[55:48]）：
  - 推导**用到**的只有两件事：① loss 的**值落在 [0, 1]**（Hoeffding 的前提）② loss 是一个**可以取平均**的量（好训练集的定义里要比较 `L(h,D_train)` 与 `L(h,D_all)`）；
  - 推导**用不到**的是：loss 具体写成什么式子、**能不能微分**、是分类用的 cross entropy 还是回归用的 MSE；
  - ⇒ 所以同一个结论**换个 loss 原样成立**（[42:55]「你完全可以把今天的讨论直接套到 Regression 上面」）。
  - ⭐ **一句话**：**换 loss 改变的是"你要求模型答得多好"，不改变"资料抽得好不好"** —— 而本集整篇讲的都是后者。

### 2.2 ⭐ `|𝓗|`：模型复杂程度的定义（本集地基）

- **𝓗（大 H）** = H 所有可能取值的集合；**`|𝓗|`** = 这个集合里有多少个选择。
- ⭐ **`|𝓗|` = 模型的复杂程度** = 「你能选多少种不同的 function」。听到"模型很复杂"，说的就是这个。
- 🔍 **`|𝓗|` 到底从哪来？（= 用户 Q2 的产物，字幕没有明说，见 4.3）**
  - **第一层：结构是你选的** —— "我要做阈值分类"这件事本身是你定的。换成线性回归，𝓗 就变成"所有直线"。
  - **第二层：范围也是你选的** —— 老师说「这个位置参数 H，**它有哪些可能性呢？它的可能性其实是你自己决定的**」（[11:12]）。这集他定 1~10000，是因为"白点数最多不超过 1 万"；**你完全可以定成 1~20000，那 |𝓗| 就是两万**。
  - ⇒ ⭐ **`|𝓗|` 不是天上掉下来的常数，而是模型设计的一个可调旋钮** —— 而它**恰好**出现在最后那个不等式的乘号左边（见 3.5）。
- ⚠️ **`|𝓗|` 从来没有被真正算准过**：玩具模型里 10000 是真数得出来的；但真实模型（作业 1 那种百万参数）代进不等式，**上界往往 > 1**，所以「实际做机器学习时几乎没有人会拿这套理论去算」（[61:01]）。⇒ **这个理论不是拿来算的，是拿来看清因果结构的。**

### 2.3 ⭐ 理想 vs 现实（本集的两大主角）

| | **理想** | **现实** |
|---|---|---|
| 资料集 | **D_all** —— 全宇宙所有的宝可梦与数码宝贝 | **D_train** —— 手上抓到的 N 笔（从 D_all 里 sample 出来） |
| 找出的参数 | **h^all** —— 让 `L(h, D_all)` 最小的 h | **h^train** —— 让 `L(h, D_train)` 最小的 h |
| 记号读法 | 上标 = 在哪组资料上找到的；下标 = 在哪组资料上量 | 同左 |

> 图注（[20:35]–[21:24]）：第二行给出 **𝓓_train = {(x¹,ŷ¹), …, (x^N,ŷ^N)}**，底部补上本集唯一的统计假设 **(xⁿ,ŷⁿ) ~ 𝓓_all**、**independently and identically distributed (i.i.d.)** —— ⭐ **这就是"每笔资料独立抽、分布固定"那句话的投影片出处**。

![[P23_05_Training Examples_理想hall与现实htrain.png]]
> 图注（[21:26]–[23:04]）：**理想 vs 现实**的正式对照页 —— 上框 **h^all（理想）**、下框 **h^train = arg min_h L(h, 𝓓_train)（现实）**，底部蓝框写下全集的追求：**We hope L(h^train, 𝓓_all) and L(h^all, 𝓓_all) are close**，并在两个 L 底下分别标了 **現實 / 理想**。

- ⚠️ **IID 假设**（[20:55]–[21:24]）：训练资料是**从 D_all sample 出来的**，而且满足 **IID = Independent（每笔互相独立）+ Identical Distribution（每次抽的分布固定）**。老师：「多数的情况，你都可以假设你的资料满足这个 IID 的特性。」
- 🔍 **D_all 为什么拿不到**（[19:20]–[19:56]）：有人会说"不是有图鉴吗？" —— 老师答：**宝可梦/数码宝贝每年都出新品种**，所以「**我们并不知道全宇宙的宝可梦跟数码宝贝有哪些**」。（口语化，但正是"训练集永远只是全体的一部分"的比喻）
- ⚠️ **本集的 optimization 是"作弊"的**：大 L 是错误率、**不可微分**，但 [18:40]「**因为 H 毕竟是有限的，总共才 1 万个而已，就每一个都试一下**」⇒ **暴力枚举**保证找得到 D_train 上最好的 h。
  - ⭐ 这一点很重要：**本集里没有任何 optimization 误差**（对比 P18 四岔路里的"optimization"那一格）—— 所以它推出的"悲观结论"是在**优化绝对完美**的前提下得到的。
  - 老师顺手对比（[18:52]）：「如果你今天面对的是 Deep Learning 的问题，**有百万个参数、千万个参数**，这个时候你可能就**需要让你的 Loss function 是可以微分的**。」⇒ ⭐ **参数一多就枚举不了、只能梯度下降，于是 loss 必须可微** —— 玩具模型买到的"可以不管可微性"的便宜，正是深度网络付不起的那份。

### 2.6 ⭐ "参数是连续的，|𝓗| 不就无穷大了吗？"

老师在 [64:46] 自己挖出这个坑：「一般在 train network 的时候……我们的参数不是都是**连续**的吗？**如果参数是连续的，那这个 |𝓗| 不是应该是无穷大吗？**如果它是无穷大的话，那这个式子还有什么用呢？」

![[P23_19_Model Complexity_参数连续两答与VCdimension.png]]
> 图注（[64:46]–[67:26]）：**Model Complexity 那页** —— 公式里 **|𝓗|** 被箭头指住，下方原文标注它的含义：**"The number of possible functions you can select"**（⚠️ 这个英文定义就是本集给 `|𝓗|` 的官方措辞，值得背）；下半 **What if the parameters are continuous?** → **Answer 1: Everything that happens in a computer is discrete. ☺**（那个笑脸就是老师自嘲"牵强"的出处）、**Answer 2: VC-dimension (not this course)**。

**两个回答方向**：

1. **「世界上没有真正连续的东西」**（[65:42]–[66:39]）：数位世界里参数用 **8 / 16 / 32 bit** 描述，**精度终究有限** ⇒ 还是离散的、还数得出来，**只是非常大而已**。
   - ⚠️ 老师自己心虚：「**希望你不要觉得这个解释的方法太牵强**。」（注意这层的口径：**同一个数学函数用不同 bit 精度表示，会被算成不同的 h**，所以 |𝓗| 不只数"函数有几种"，还数"精度有几种"。）
2. ⭐ **VC dimension**（[66:44]–[67:26]）：「有另外一个方法来计算一个**参数是 continuous 的模型**的复杂程度……**就算有一个模型它的参数是连续的，并不代表它的复杂程度就是无穷大**。」
   - 老师明说 **本课不会讲**：「如果你想知道 VC dimension 是什么，你可以去修**林轩田老师**的机器学习，你会更深入地了解怎么评量一个模型的复杂程度。」
   - 🔶 **本条属"待补"**（需概率统计 / 学习理论）→ 记入疑问清单。

### 2.7 ⭐ 本集为什么敢枚举：枚举 vs 梯度下降，是**一次取舍**

本集能"每个 H 都试一下"，靠的是 **|𝓗| = 10000 真的很小**（[18:40]）。换到真实模型上这一条立刻断掉，因为两种搜索方式给的是**两种不同的东西**：

| | **枚举（暴力搜索）** | **梯度下降** |
|---|---|---|
| 要碰多少个点 | **\|𝓗\|** —— 参数个数 D、每个 b bit ⇒ **≈ (2^b)^D**，**随参数个数指数爆炸** | **T 步**（T 是自己定的迭代数），**与 D 大致线性** |
| 最优性保证 | ✅ **全局最优**（每个都算过了） | ❌ **只保证局部** —— local minima / saddle point / 平坦区（[[第19集_局部最小值与鞍点\|第19集]]、[[第20集_批次与动量\|第20集]]） |
| 什么时候用得起 | **\|𝓗\| 很小**（1 万个） | **\|𝓗\| 大到数不清**（百万、千万参数） |

⇒ ⭐ **两者不是"同一件事的两种做法"，而是一次交换**：**梯度下降是拿"放弃全局最优的保证"换来"可负担的搜索代价"**。

⚠️ 由此可以看清本集两处设定的**性质**（都成立，但都是"特权"）：
1. **"不可微 ⇒ 只能枚举"是本集的特殊设定，不是通例** —— 玩具模型若改用 **cross entropy**（可微），**一维参数、梯度下降几步就下来了**，根本不必枚举 1 万次。老师挑错误率是因为它**直观**，不是因为非它不可（见 §2.1）。
2. **反向那条才是通例**：「**参数一多就枚举不了 ⇒ 只能梯度下降 ⇒ loss 必须可微**」（[18:52]）。
3. ⭐ **本集的"优化绝对完美"是由枚举买的** —— 所以它的结论**不含 optimization 误差**（§2.3 末），是"即使优化做到满分，理想与现实的差距也抹不掉"的**悲观下界**。

🔶 **与 §2.6 的分工别混**：那里说"**参数在电脑里是离散的**"，是为了让 **|𝓗| 是个有限的数**（证明能写下来）；这里说"**离散 ≠ 数得完**" —— **离散化只是让 |𝓗| 可数，丝毫没有让它变小**，所以枚举在真实模型上照样不可行，**梯度下降的必要性跟"连续还是离散"无关**。

### 2.8 ⭐⭐ 两难（本集的落点）

**让理想跟现实接近的两个旋钮，各有代价：**

| 旋钮 | 效果 | 代价 |
|---|---|---|
| **增大 N**（训练资料笔数） | 抽到坏资料的机率变小 ✅ | 成本高；⭐ **「你往往没有办法自己决定说你的训练资料要用多少」**（[67:42]）—— 课堂上资料是给定的，只能用完；在公司里主管会说「**机器自己会学习，收什么训练资料？**」（[68:16]） |

> ⭐⭐ **补充讨论（2026-09-24，用户提出）：「训练量其实可以自己决定，只要做 augmentation 就好了。」**
> ⚠️ **来源标注：本条字幕没有 —— 属讨论产物。** 判定 = **对一半，而且那一半很重要**。
>
> - ✅ **对的部分**：augmentation 确实是**你能自己拧的旋钮**，工程上真有用（[[_播放列表|HW3]] 影像分类就会用到）。
> - ⚠️ **但它不会让上表那个 N 变大** —— P23 的 N 是**独立样本数**：Hoeffding 的 `e^(−2Nε²)` 全靠"**每一笔都是独立抽的**"。而 augmentation 产出的图是原图的**确定变换**（翻／裁／转），**跟母本 100% 相关**，没新增一丝独立信息 ⇒ **公式里的 N 一动不动**。
> - ⭐ **那它为什么有用？它在 P23 的语言里干的是另一件事：把 `|𝓗|` 缩小。**「翻转后的猫还是猫」是一条**先验**，等于告诉模型"**那些函数你别选**" —— 砍小的是**允许的 h 的集合**，改善的是**落差**（ε），**不是资料量**。
> - ⭐⭐ **而这件事正好和 [[第31集_卷积神经网络|第31集]] 是同一个目的的两条路**：
>
> | 路 | 先验写在哪 | 老师的说法 |
> |---|---|---|
> | **CNN**（RF + 参数共享） | 写进**结构** | **model bias 变大**（[28:08]） |
> | **augmentation** | 写进**资料** | 效果上 ≈ "不让你学那些对翻转/平移不变的函数" |
>
> - ⇒ **更准的说法**：**N 你决定不了，但你可以拿"先验"去换** —— 要么写进架构，要么写进资料。**两条路都不是"增加 N"。**
> - 🔍 **一个可检验的推论**：若 augmentation 真等价于加 N，那"**无限做 augmentation**"就该无限逼近 D_all —— 实际不会，**做过头会把它自己的 bias 带进来**（左右翻转把 6 看成 9 就是现成例子）。⇒ **它注入的是先验，不是信息。**
| **减小 \|𝓗\|**（模型复杂程度） | 同样让机率变小 ✅ | ⭐⭐ **会把理想本身弄坏** —— 见下 |

![[P23_20_为什么不直接用很小的H_好训练集的定义.png]]
> 图注（[67:30]–[69:50]）：⭐ **老师自己把"那为什么不干脆把 |𝓗| 弄得很小？"问出来了**（页面上那行 **Why don't we simply use a very small |𝓗|?**）—— 上半先把"好训练集"的定义与它的推论（`L(h^train,𝓓_all) − L(h^all,𝓓_all) ≤ δ`，ε = δ/2）抄一遍，**下半就是回答的伏笔**：⚠️ 注意那个推论里出现的 **h^all 是从 𝓗 里挑出来的** —— 这正是"|𝓗| 一小，理想就崩"的推理起点。

⭐ **为什么"理想会崩坏"**（[69:50]–[71:50]）：**h^all 是从大 𝓗 里挑出来的**。𝓗 一小，**可选的 h 就很有限** → **h^all 在 D_all 上算出来的 loss 根本压不下去** → 「**意味着你的理想都坏了，你的理想根本就是坏掉的东西**」→ **现实再接近一个崩坏的理想，拿到手的还是坏的**。

**图示**（[71:52]–[73:04]）：左边 = 大 𝓗（理想好，但理想与现实差距大）／右边 = 小 𝓗（理想与现实接近，但 h^all 本身就烂）。

![[P23_21_Model Complexity_理想崩坏.png]]
> 图注（[69:50]–[71:12]）：⭐ **"理想崩坏"那页** —— 标题仍是 **Model Complexity**，公式上三个箭头（两个向下 = N 大 / |𝓗| 小让机率降，一个向上橙箭头 = |𝓗| 本身在变大/变小这件事），下面把**"好训练集 ⇒ 现实接近理想"** 与 **"|𝓗| 调小 ⇒ 这个理想本身就烂"** 两条摆在一起。

![[P23_22_Tradeoff of Model Complexity_两难.png]]
> 图注（[71:52]–[73:40]）：⭐⭐ **本集的落点页 —— 标题就叫 Tradeoff of Model Complexity**（老师红笔手写，全集的结论压在这一页）：
> ① **Larger N and smaller |𝓗| ⟹ L(h^train, 𝓓_all) − L(h^all, 𝓓_all) ≤ δ**（理想与现实够近）
> ② ⭐ **Smaller |𝓗| ⟹ Larger L(h^all, 𝓓_all)** —— **"理想崩坏"的公式写法**：调小 |𝓗| 的副作用就是理想那个 loss 变大
> ③ 下半两栏对比（竖轴 = loss 大小，两点 = 两个「现实 / 理想」的成绩）：**larger |𝓗|**（左）→ **两点间距 large**，但下面那个 h^all 的点是 **small**（压得低）；**smaller |𝓗|**（右）→ **间距变成 small**（理想现实接近 ✅），但**下面那个点整个被顶上去了（large）**（理想崩坏 ❌）
> ⚠️ **两个红框圈的就是鱼与熊掌**：左边圈的是"**理想很小**"、右边圈的是"**间距很小**" —— 谁也不肯让出另一半。底部一行即收尾问句：**魚與熊掌可以兼得嗎？**

⇒ **两难**：想兼得鱼与熊掌，就要 **h^all 在 D_all 上 loss 小** **且** **h^train 在 D_all 上接近它**。
⇒ **收尾钩子**（[73:45]–[73:56]）：
> 「有没有可能让鱼与熊掌可以兼得呢？**是有的。这个可以让鱼与熊掌兼得的办法就是深度学习。**那至于深度学习怎么做到这件事情，**我们下回分见。**」

- ⚠️ **"下回" = P33「鱼与熊掌可以兼得的机器学习」**（41:35）—— 官方 README 里 P23 = Lecture 2 的 theory video，P33 = Lecture 3 的 validation / whydeep 系列之一。⇒ 这个悬念**挂在 CNN 那几集之后**才回收（**✅ 2026-09-26 已回收 → [[第33集_鱼与熊掌可以兼得的机器学习]]**）。

### 3.1 ⭐ 两个定义：想要什么，以及什么样的 D_train 给得起

> 📄 **本节对应投影片**：`P23_23`（目标框）→ `P23_09`（"好资料"定义）。⚠️ **带三行推导的那一整页 `P23_08` 归 §3.2**（它是推导图示，不是定义页）。

![[P23_23_What do we want_目标式复现.png]]
> 图注（本节讲这页的**上半**；它 [73:10] 在结尾又被调回来当收束 —— 见 §3.2 末）：最上蓝框就是本集的**目标**：**We want L(h^train, 𝓓_all) − L(h^all, 𝓓_all) ≤ δ**。

**① 目标**（[33:04]–[33:43]）：
```
L(h^train, D_all) − L(h^all, D_all)  ≤  δ
```
- **δ 是你自己设的**：「如果你觉得理想跟现实差一点也没有差，那 **δ 设大一点 0.1**；如果你很要求理想跟现实很接近，那 **δ 设小一点 0.0001**。」
- ⚠️ **记号口径（本节一次说清，后面不再重复）**：**投影片上目标式用的是 δ**（⚠️ whisper 把 δ 听写成了"Delta/δ"⇒ 早期笔记曾误记作 Δ，**2026-09-23 按投影片订正为 δ**）；"好训练集"的定义则用 **δ/2**，[41:31] 起把它写成 **ε**「只是为了之后不要再写除二这件事」。⇒ **δ = 目标里的差距，ε = 定义里那一半**，全文统一。
- ⚠️ **`L(h^all, D_all)` 一定是最小的**（[33:47]–[34:20]）：同样在 D_all 上量，h^all「**是无人能敌的**」，因为那是它的 BGM。但**这不代表它的 loss 一定比"别的资料集上找出来的 h"更低**（[34:37]–[35:02]）—— 这正是 2.4 那个反直觉的出处。

**② ⭐ 什么叫一个"好"的 D_train**（[35:24]–[37:21]，本集的第二个地基）：
```
对所有可能的 h ∈ 𝓗：  | L(h, D_train) − L(h, D_all) |  ≤  ε        （ε = δ/2）
```
![[P23_09_好Dtrain的定义_对所有h成立.png]]
> 图注（[41:00]–[41:38]）：**"好训练集"的正式定义页** —— 标题 **We want to sample good 𝓓_train**，右上角标 **ε = δ/2**，正中蓝框 **∀h ∈ 𝓗, |L(h, 𝓓_train) − L(h, 𝓓_all)| ≤ ε**，底部提出本集的主题问题：**What is the probability of sampling bad 𝓓_train?** ⭐ **这一页就是 ⑨ → ⑩ 的转折点**（从"希望"转向"机率"）。

### 3.3 ⭐ union bound：并集算不动 → 改成连加（上界）

![[P23_12_坏资料的机率_并集改成连加.png]]
> 图注（[45:27]–[51:58]）：⭐ **union bound 的原始投影片** —— 第一行 **P(𝓓_train is bad) = ⋃_{h∈𝓗} P(𝓓_train is bad due to h)**（⚠️ **那个大符号就是 ⋃ 并集**，不是连乘 ∏，用户本轮误读过一次）；第二行 **≤ Σ_{h∈𝓗} P(...)**，老师把红框那一项圈出来，说"**接下来只讲这一项怎么算**"。下面两行给出坏的定义 **|L(h,𝓓_train) − L(h,𝓓_all)| > ε** 与大 L 的平均式。

![[P23_11_Probability of Failure_一个点是一组资料.png]]
> 图注（[43:49]–[49:23]）：⭐ **"一个点 = 一组训练资料"那一页**（右上角原文 **Each point is a training set.**）—— 蓝点 = 好资料，橙点 = 坏资料；三个框分别代表 **h₁ / h₂ / h₃ 各自弄坏的范围**，它们互相重叠。⚠️ 底部那行 **h₃** 框到了一大片，正是"每次相加都会重复计算"的可视化来源。

**为什么需要这一步**（[49:23]–[50:14]）：
- 坏资料的总机率 = 「被 h₁ 弄坏的」∪「被 h₂ 弄坏的」∪「被 h₃ 弄坏的」∪ …（**穷举所有 h 的并集**）
- 但 ⚠️ **并集里重叠的部分很难算** → **干脆不取并集，直接相加** → **重复的地方被重复计算** ⇒ **是上界**。

```
P(D_train 是坏的)  ≤  Σ_{h ∈ 𝓗}  P(D_train 被 h 弄坏)
                     └────── union bound：并集 ≤ 各项之和 ──────┘
```

- ⚠️ **学生提问 + 老师的回答**（[50:42]–[51:47]）：「会不会超过 1？」→「**会**，而且**实际上通常你算出来都会超过 1**，所以这个理论没什么用。」
- 🔍 **为什么"改成连加"是必须的（= 用户 Q5 的产物，字幕没明说，见 4.3）**：改成"相加"之后，**每一项就各自独立地需要一个上界** ⇒ 这直接决定了下一步（3.4）的形态：**Hoeffding 必须作用于"固定住的单个 h"**。

### 3.4 Hoeffding 不等式：单个 h 弄坏资料集的机率

**观念**（[52:27]–[55:01]，老师明说只讲观念、不讲证明，"这在机率统计那门课学过"）：
- `L(h, D_all)` = **全世界所有资料的 loss 的平均**；
- `L(h, D_train)` = **从里面 sample 出来的那些的平均**；
- 两个平均会接近，差多少有上界 ⇒ **Hoeffding's inequality**。

```
P(D_train 被某一个（固定的）h 弄坏)  ≤  2 · exp(−2 N ε²)
```
- **N** = D_train 里的资料笔数。
- ⚠️ **前提：loss 的值要介于 0 到 1 之间**（[55:25]–[55:48]）。但对 **loss 长什么样子没有限制** ——「是 identity？还是 cross entropy？还是 regression？**这点是没有限制的**」，只对数值范围有限制。
- ⭐ **关键性质**：右边 **跟 h 无关** ⇒ 求和时每项都一样。

![[P23_13_Hoeffding不等式_单点损失与平均.png]]
> 图注（[52:00]–[55:48]）：⭐ **Hoeffding 那页** —— 上半是把 union bound 与 Σ 再抄一遍，接着 **Hoeffding's Inequality: P(𝓓_train is bad due to h) ≤ 2exp(−2Nε²)**（⚠️ 这一项**必须是固定一个 h**）；下方两条注意事项：**The range of loss L is [0,1]**、**N is the number of examples in 𝓓_train**。底部是**"单点损失 → 平均"的示意**：一排三角 = 每一笔资料的 l(h,xⁿ,ŷⁿ)，**全部平均 → L(h,𝓓_all)**；**只抽其中几个平均 → L(h,𝓓_train)**（右下角红圈）。⇒ 这就是"两个平均为什么接近"的图。

### 3.5 ⭐⭐ 核心公式（本集要带走的那一条）

```
P(抽到坏的训练资料)  ≤  |𝓗| · 2 · exp(−2 N ε²)
```
**怎么来的**（[56:15]–[57:22]）：
1. 3.3 的求和式；
2. 每一项代入 3.4 的上界 → `Σ_h 2e^(−2Nε²)`；
3. ⭐ 发现 **`2e^(−2Nε²)` 跟 h 无关** → **"有多少个 h"直接乘上去** → **`|𝓗| × 2e^(−2Nε²)`**。

![[P23_14_核心公式_H乘2exp.png]]
> 图注（[56:15]–[59:40]）：⭐ **本集的核心公式页** —— 四行一路推下来：`= ⋃ P(...)` **≤ Σ P(...)** **≤ Σ 2exp(−2Nε²)**（因为跟 h 无关）**= |𝓗| · 2exp(−2Nε²)**；底下一行直接给出方向：**How to make P(𝓓_train is bad) smaller? → Larger N and smaller |𝓗|**。⚠️ 两个箭头分别指着 **|𝓗|**（蓝）与 **2exp**（橙）。

**怎么让这个机率变小**（[57:24]–[59:40]）：
- **ε 是你自己定的**（你要求理想与现实多接近）；
- ⭐ **N 变大** → 每个 h 能弄坏的训练集变少 → 机率降；
- ⭐ **|𝓗| 变小** → 能选的 function 变少 → 机率降。

![[P23_15_Larger N_每个h弄坏的范围变小.png]]
> 图注（[58:33]–[59:12]）：**增大 N 的效果** —— 左 = 原本的散点（每组资料一个点），右 = **N 变大后**：点上下的密度变了，**三个框（h₁/h₂/h₃ 弄坏的范围）都明显缩小** ⇒ ⭐ **"每个 h 要把一个训练集弄坏的难度增加了"** 的可视化。

![[P23_16_Smaller H_可选函数变少.png]]
> 图注（[59:12]–[59:40]）：**减小 |𝓗| 的效果** —— ⚠️ 注意与上一张的区别：**散点没变、每个框的大小也没变**（"每一个 h 它们管的范围还是一样"），**变的是框的个数变少了**（h₂ 消失）⇒ ⭐ **两个旋钮从两个不同方向压同一个机率**。

#### 4.3-A ⭐ 为什么证明要"按 h 分组"（用户 Q1c）

**先分清两个 h（混在一起是困惑的根源）**：

| 记号 | 身份 | "谁训谁" |
|---|---|---|
| **h^train** | 从 D_train 里找出来的那个阈值 | **是 D_train 训出来的** ✅ 用户的顺序是对的 |
| **h**（𝓗 里任意一个，含 h^all） | 函数类里**随便挑一个假设**，**跟任何训练集无关** | 不用训，**先固定它** |

**"h 弄坏 D_train"里的 h 是第二行那个。** 证明的先后顺序决定了它必须这样组织：
1. 想算的是**坏资料的总机率**；
2. 坏的定义里有"**存在**某个 h" ⇒ 它是**并集** ∪_h A_h（A_h = 被 h 弄坏的那些训练集）；
3. **并集的重叠算不了** ⇒ 改成**连加**（union bound）；
4. ⭐ **一旦改成"相加"，每一项就必须各自有上界** ⇒ 必须**按"是谁把它加进来的"分组** —— 也就是**按 h 分组**；
5. 而 **Hoeffding 给的上界恰好是"固定一个 h"的上界**（2e^(−2Nε²)）⇒ 与第 4 步严丝合缝；
6. 又因为这个上界**跟 h 无关** ⇒ "对 1 万个 h 求和"退化成"**乘 1 万**" → 得到 |𝓗|·2e^(−2Nε²)。

⇒ **一句话**：**不是"h 训出 D_train"，而是"我按'哪个 h 被这组资料骗了'给坏资料分组，因为只有这样分组才能用上 Hoeffding 那条对单个 h 的上界"。** 逻辑上是**按弄坏者归类**。

**还有一层：这样定义恰好绕开了"你怎么训练"** —— Hoeffding 比较的是两个**期望**（`L(h,D_all)` = 全世界的平均 vs `L(h,D_train)` = 抽样出来的平均），是"**同一个 h 固定住，估计它的平均表现准不准**"，**从头到尾不需要知道 h 是怎么被训出来的**。（老师口语把这叫"在训练资料上量"vs"在所有资料上量"。）

⭐⭐ **2026-09-24 用户自己把这里收口了**（原话：「h 去圈到坏 D_train 这件事本身**跟 h 的训练无关**，我总是会想到**优化（梯度下降）**那一块去，实际上就是**遍历或抽取 h 来试 D_train 的好坏**，这样就没有歧义了」）—— 判定 **✅ 对，而且这正是本集最容易绊人的地方**（用户在同一集的追问 Q5 就绊过一次）。

⭐ **但要分成两句记，别合成一句**：

| | 说法 | 依据 |
|---|---|---|
| **证明里"没有"优化** | union bound + Hoeffding 只比较"**同一个固定的 h**"在两个资料集上的平均表现，**不需要知道 h 是怎么被训出来的** | 本节上一段（＝"绕开了你怎么训练"） |
| **结论里"假设掉"了优化** | 本集的 `h^train` 是**暴力枚举**（1 万个 H 全试，[18:40]）得到的真·argmin ⇒ **optimization 那一格被关掉** ⇒ 结论是"**即使优化满分，理想与现实的差距也抹不掉**"的**悲观下界** | §2.3 末 / §2.7 |

⇒ ⭐ **"优化"不是被这套理论排除掉的，是被它假设掉的**（这也正好接上 P19–P22 那一支"训不起来怎么办"—— 那些集讲的才是这一格）。
⚠️ **用词精确化**：**"遍历"只属于玩具模型**（`|𝓗| = 10000` 数得完）；一般网络里 `|𝓗|` 只是个符号，理论要的是 **∀h（对每一个可能的 h 都成立）** —— ⭐ **被抽的是资料，不是 h**。

⭐ **再补一层（2026-09-24 续，用户「抽取实际就是优化嘛」）—— P23 里"优化"住在第 1 步，不在第 2 步**：

| 步 | 做什么 | 里面的 h 是什么身份 | 与优化的关系 |
|---|---|---|---|
| **第 1 步（训练）** | 找 `h^train = arg min_{h∈𝓗} L(h, 𝓓_train)` | **被挑出来的那一个** | ⭐ **这就是一个优化问题**（玩具模型用**枚举**把它做到满分 ⇒ 所以 P23 是"假设掉"优化） |
| **第 2 步（判断资料好坏）** | 问"这组 D_train 量得准不准" | **任取一个、先固定**（∀h，含 h^all） | **纯统计**，不含 argmin / 不含搜索 |

⇒ ⭐⭐ **同一个 `𝓗` 的两种身份**：**第 1 步里它是"搜索空间"（你要找多大范围）／第 2 步里它是"投保名单"** —— `|𝓗|` 就是**保费**：能为越多 h 各买一份"量得准"的保险，坏资料机率的上界就越贵（`|𝓗|·2exp(−2Nε²)`）。

⚠️ **为什么第 2 步必须 ∀h、而不是"抽几个 h 来试"**：定义"好资料"的时候**你还不知道会挑中哪个 h**（那要等第 1 步做完，而第 1 步依赖这组资料本身，＝**自指**）⇒ 保证必须覆盖**所有可能被挑中的 h**。⇒ **不是"抽几个 h"，是"给每一个 h 各买一份保险"。**

⭐⭐ **2026-09-24 用户第三问（本 thread 最核心的一问）**：

> 「对一个模型（玩具模型 h 自己设成 1–10000；实际模型 h 的范围过大数不清、不可能试遍所有 h，但**可以用梯度下降的方式"抽"出一个个 h**（所以这样选 h 是**有依据的**））都是要用那个 h 去圈 training set。**但实际模型中用 optimizer 选出的 h 是根据 training set 算出来的，这或许就是我不理解的根源** ⇒ 所以似乎 **h 跟 training set 是一一对应的存在**；"h 去试 training set 的好坏"这个想法**是在消除他们之间的联系吗**？」

**答：⭐ 不是"消除"联系，是"绕过"它 —— 而且你的"根源"抓得很准：正因为 `h^train` 是由 `𝓓_train` 算出来的，Hoeffding 才不能直接用在它身上。**

⚠️ **一处措辞**：不是"一一对应"，是**函数依赖** `h^train = A(𝓓_train)`（A = 你的训练算法／optimizer）。⚠️ 而"**h^train 携带 D_train 的信息**"正是 **overfitting** 的语言 —— 它甚至可以"记住"一部分 D_train。

**理论怎么绕过（三行，就是 §3.2 的三件套）**：

1. **定义（刻意不提训练）**：`坏资料 = ∃h ∈ 𝓗, |L(h,D) − L(h,𝓓_all)| > ε`。这里 **𝓗 是你动手之前就定好的**（1–10000／网络结构 + 参数范围），**跟 D 毫无关系**；
2. **计算**：于是可以对**每一个固定的 h** 套 Hoeffding ⇒ union bound ⇒ `P(坏资料) ≤ |𝓗|·2exp(−2Nε²)`；
3. **收束（instantiate）**：若抽到的 D_train **不是**坏资料，则"∀h 都量得准" ⇒ 把 **`h = h^train`** 代进去 ⇒ `|L(h^train, D_train) − L(h^train, D_all)| ≤ ε`。

⭐⭐ **门道在第 3 步**：**我们从头到尾没有对 `h^train` 用过 Hoeffding** —— 我们是对"每一个固定的 h"用了它，最后**把 `h^train` 代进去**。⇒ **`h^train` 与 `D_train` 的联系既没有被否认、也没有被使用，它被"绕过"了。**

⭐ **理论对训练算法 `A` 唯一的假设**：**它的输出属于 `𝓗`**。不管你的 optimizer 多聪明、挑得多"有依据"，只要 `h^train ∈ 𝓗`，结论就成立。⇒ 这也是"优化那一格被假设掉"的另一面。

⭐ **而且这份"联系"恰恰是这个机制起作用的原因**：`h^train` 正因为**跟 `D_train` 有关系**（会记住它），才最可能成为"坏资料"的**证人** —— 把 `h = h^train` 代进坏资料的定义，左边那个差正是"过拟合"。⇒ **"过拟合"与"抽到坏资料"是同一件事的两面。**

⚠️ **真实模型里"`|𝓗|` 数不清"怎么办**（用户点出的那一半）：union bound 的 `|𝓗|` **数不出来**时，这条式子会退化成"干话"（§3.6；老师 [64:46] 自问自答 → **VC dimension，本课不讲**）。⭐ 但要分清：**失效的只是"数个数"这个具体做法；"对整个类买保险 → 再代入你挑中的那个"这个结构，在 VC / Rademacher 那一套里一模一样地保留** ⇒ **绕过自指的手法不会因为 h 数不清而失效。**

#### 4.3-B ⭐ 为什么这里**没有"连乘"**（用户 Q4）

- ⚠️ **纠错**：把 **∪（并集）**看成了 **∏（连乘）** —— 这是本轮唯一的记忆串位，确认后已澄清。
- 本集的逻辑链是：
```
并集（"存在某个 h"） → 算不动 → 改成连加（union bound） → 每项用 Hoeffding → 项数 × 每项 = |𝓗|·2e^(−2Nε²)
```
- ⭐ **唯一的那个"乘"，是"项数 × 每一项"（= 计数），不是概率相乘。**
- **"连乘"属于另一侧**：**独立事件的交集才用乘** —— 本集唯一的独立性假设是 **IID**（[20:55]「每笔资料彼此之间是 Independent 的」），而推导里**没有"而且"结构**（坏资料的定义是"存在某个 h" = **或**）⇒ 不该也不会出现连乘。

## 五、易错点与纠正

1. ❌ **「错误率不能微分，所以这个模型不能用」是错的** —— 大 L 是错误率、确实不可微，但 **𝓗 只有 1 万个 ⇒ 暴力枚举即可**，optimization 不难解。**"不能梯度下降"≠"训不出来"。**
2. ⚠️ **"参数多 → 容易 overfitting"的机制不是"最优解变差了"** —— H 变大，`L(h^all, D_all)` **只会变好或不变**（h^all 是在**更大的**集合里取最小）；变危险的是**你实际拿到手的 h^train**。⭐ 准确说法：**参数越多，"从训练集上最好的那个"落到 D_all 上仍然很好的机会越小。**
3. ❌ **∪ 是并集符号，不是连乘 ∏**（本集 ⑩ 段的核心就是这个并集）。**"并集 → 连加"是上界（union bound）；"独立 → 连乘"是另一回事**，本集推导里不出现。
4. ⚠️ **"上界 > 1"不代表推导错了**，只代表**它松到不含信息量**（重叠被重复计算得太狠）。⭐ **方向信息仍然有效**（|𝓗| 大 → 糟；N 大 → 好），只是**数值不可用** —— 老师自己就是这么定位它的（[61:16]「**它只是试图去解释机器学习的原理**」）。
5. ⚠️ **图中"一个点 = 一组训练资料"，不是一笔资料** —— [43:53] 老师重复了两次。**读成"一笔资料"整段就崩了。**
6. ⚠️ **h^train 在 D_train 上比 h^all 在 D_all 上 loss 更低，是正常的** —— 因为**量的资料不一样**。老师用"BGM"梗解释。别误记成"训练集上效果好 = 模型好"。
7. ⚠️ **这集没有 optimization 那一格** —— 暴力枚举保证了 h^train 是货真价实的 D_train 最优 ⇒ **本集结论是在"优化完美"前提下得出的**，别和 P18 四岔路混着记（那边的"training loss 大"有 model bias **和** optimization 两个来源）。
8. ⚠️ **`|𝓗|` 不是"参数个数"的字面值** —— 它是**你能选多少种 function**。⚠️ 用户复述里出现过"可能的 h 的个数（参数个数）"的括注：**在玩具模型里两者恰好相等（H 就是一个数）**，但在 Deep Network 里 `|𝓗|` **不是**参数个数（参数个数有限，函数组合数大得多）—— 这也是为什么会有"参数连续 → 无穷大"那个问题。
9. ⚠️ **δ 与 ε 是两套记号，别混**：**目标式**用 **δ**（你自己设的大/小）；**"好训练集"的定义**用 **δ/2**；[41:31] 起把 **δ/2 记作 ε**「只是为了不要写除二」，**§3.3 之后就全是 ε 了**（核心公式、反解 N 都用 ε）。**读公式前先确认它用的是哪一套。**
10. ⚠️ **Hoeffding 有前提：loss ∈ [0, 1]** —— 本集能直接用是因为错误率天然在 [0,1]。老师明说 **loss 长什么样没限制、只有数值范围有限制**。
