# 第13集：深度学习简介（第6讲-选修 P13）

> 本集主题：把 ML 三步骤完整套到 neural network 上（把大象放进冰箱）。讲稿：[[raw/第13集_字幕|字幕存档]]；我的自写笔记：[[第13集_深度学习简介（自己写的）]]（已逐条检查，结果见下）。
> 一句话总结：**Step1** 把 logistic regression 前后串联成 neural network（连接方式手动设计，最常见 = 全连接前馈；每层 = x·W + b → 激活函数；结构决定 function set）；**Step2** 多分类：softmax 输出概率 + 交叉熵，全部样本相加得 total loss；**Step3** 还是梯度下降（跟 linear regression 一模一样，只是函数变复杂）；最后抛问题——一个 hidden layer 就能表示任何连续函数，**凭什么要深而不是胖？**（伏笔：以后的课讲）。

## 本集讲了什么

1. **开场 + 历史（沉沉浮浮）**：1958 Perceptron（线性模型）大起大落 → 1980s multi-layer perceptron + 1986 Hinton backprop（但 3 层以上训不出好结果）→ 1989 理论："一个 hidden layer 就能表示任何 function"（叠多层"没必要"）→ 方法臭掉（paper 写 neural network 像写脏话，必被拒）→ **改名"deep learning"全网炒起来** → RBM 初始化（2006，后来发现没用：石头汤里的石头）→ **GPU 加速（2009，关键突破：train 一次从一周 → 几小时）** → 2011 语音、2012 ImageNet（AlexNet）被引爆
2. **DL = 一样的三个 step**（"把大象放进冰箱"：开门、赶大象、关门）：写 function（neural network）→ 定义 loss → 优化
3. **Step 1：neural network 是什么**：把 logistic regression 前后 **concatenate**；每个 LR 有自己的 weight/bias，全部集合起来 = θ；连接方式**手动设计**；最常见 = **Fully Connected Feedforward Network**
4. **手算例**（2-2-2 网络）：输入 [1,−1] → 0.98/0.12 → 0.86/0.11 → **0.62/0.83**；输入 [0,0] → 0.51/0.85。参数定了 = 一个 function；只定了结构 = 定义一个 **function set**
5. **层命名 + "deep" 的定义**：input layer（严格说不是 layer，不是 neuron 组成）/ hidden layers / output layer；deep = 很多 hidden layer（几层算 deep？没有标准答案；"有一层也都说自己是 deep learning"）
6. **层数史**：AlexNet 8 层 16.4%（第二名 30%）→ VGG 19 层 7.3% → GoogleNet 22 层 6.7% → **ResNet 152 层 3.57%（超过人类；但 ResNet 是特殊 structure，普通 FC feed-forward 152 层会 train 不起来——不是 overfitting！）**
7. **矩阵化**：每层 = `x·Wᵢ + bᵢ` → activation function → aᵢ；整个网络 = 一串 **vector × matrix + vector**（线性代数）→ 好处：**GPU 加速**（游戏显卡没对 NN 特化，只是矩阵运算比 CPU 快）
8. **feature extractor 视角**：output layer 之前全部 = 自动 feature extractor（取代手动 feature engineering）；最后 hidden layer 的输出 = 一组新 feature（可能变 separable）；output layer = multi-class classifier → **加 softmax**
9. **手写数字例子**：16×16 图像 = 256 维 vector（涂黑=1/空白=0）；网络 = 一个 function：**256 维 → 10 维**；softmax 输出概率分布，取最大（如 0.7 → 数字 2）
10. **design network structure 是关键难事**：唯一约束 input/output 维度，中间几层、每层几个 neuron 自选；structure 决定 function set；function set 里没好东西 → 大海捞针（**针不在海里**）；怎么定？"我不知道"——凭直觉、经验、多方尝试、domain knowledge
11. **问题转化（不是变简单）**：feature engineering（抽好 feature）→ design network structure；语音/影像（人太下意识、说不出好 feature）design structure 更容易；**NLP**（人容易设计 rule，如正负面词表）传统方法本来就不错 → DL 进步没那么显著（语音/影像错误率相对下降 **20%+**），但长远有优势
12. **CNN 预告**：可以"乱接"（不全连接），下堂课讲
13. **Step 2：loss**：multi-class；label = one-hot 10 维 vector；y 与 ŷ 的 **cross-entropy**；所有样本相加 → total loss L
14. **Step 3：优化**：random 初始化 → 算每个参数对 L 的偏微分（= gradient）→ `θ ← θ − η·g`（η 这里是 μ）→ 反复；**跟 linear regression 没差别，只是函数变复杂**；最潮的 AlphaGo 也是 gradient descent 训的（"gradient descent 就是玩世纪帝国"）
15. **backprop 预告**：参数 millions，手算微分不现实 → backprop 是**算微分更有效的方式**；现在没人自己 implement（有太多 tooling）；段子：某公司面试，75% "自称 DL 专家"的人不会算微分
16. **为什么 deep？**（本集结尾爆点）：2011 Interspeech：1 hidden layer（每层 2k neuron）WER 24.2 → 越 deep 越低；但**不 surprise**（参数多 → function set 大 → bias 小，有足够数据就更好）；理论：**任意连续 function（n 维输入）都能用"一个 hidden layer、够多 neuron"的 network 表示** → 有人说 deep 只是噱头（"deep 听起来潮，fat 听起来虚"）→ **真的吗？往后的 lecture 再讲**

## 核心概念

### 1. Perceptron 与"沉沉浮浮"（历史即考点）
- **1958 Perceptron**：Rosenblatt 海军项目提出；是 linear model（非常像没有 sigmoid 的 logistic regression）[01:40–01:56]；当时 NYT 宣称"人工智慧要产生了"
- **打脸**：Minsky 教科书《Perceptron》指出线性模型局限 → 希望破灭；坦克/卡车故事：模型只抓到**亮度**（坦克照片是雨天拍的、卡车是晴天拍的），方法臭掉 [03:08–04:08]
- **1980s MLP**：多接几个 perceptron；1986 **Hinton backprop**（多人同时提出，credit 归 Hinton paper）[04:54–05:05]；但**超过 3 层就训不出好结果** [05:07–05:18]
- **1989 理论**：一个 hidden layer 就能 model 任何 function → "没必要叠很多层" → MLP 又臭掉（大家转去做 SVM）[05:21–05:52]
- **改名**：neural network 像脏话（paper 必被拒）→ 改名 **deep learning** 炒起来 [05:55–06:33]（笑点：博士改名，大家就想念了）
- **2006 RBM 初始化**：曾被视为 DL 与 80 年代 MLP 的差别；但方法复杂且**后来发现没啥用**（石头汤里的石头：看着厉害、其实不贡献）[06:41–09:33]
- **2009 GPU**：真·关键突破——以前 train 一次一周，失败就不想再来；现在几小时 [09:34–10:37]
- **2011 语音 / 2012 ImageNet**：两个领域被引爆（AlexNet 8 层 16.4%，第二名 30%）[10:38–11:00]

### 2. DL = ML 三步骤（把大象放进冰箱）
- 开门（Step1 写 function = neural network）→ 赶大象（Step2 定义 loss）→ 关门（Step3 优化）[11:01–11:35]
- 所以 DL"非常很简单，你可以瞄懂它"——复杂的是后面怎么设计 structure

### 3. neuron / neural network 的构成
- 把 logistic regression **前后 concatenate** 在一起 = neural network [12:05–12:35]
- 每个 neuron（LR）有自己的 weight + bias；全部集合起来 = 参数 **θ**
- 一个 neuron 的内部：`Σ(weight × input) + bias` → **activation function φ**，输出 = `φ(Σwᵢxᵢ + b)`；⚠️ φ 是**类别名**（σ 只是它的一个实例，现在常用 ReLU）；**φ 可以为 identity**（输出层就是），但 hidden layer 的 φ 必须非线性 [22:41–23:02]
- **连接方式手动设计** [12:53–12:58]；最常见 = **Fully Connected Feedforward Network**：neuron 排成一排排，**层与层两两相连**（fully connected）+ 从前往后传（feedforward）[13:03–17:52]

### 4. 手算例：参数定死后 = function；结构定了 = function set
- 2-2-2 网络（第一层 weights [1,−2]/[−1,1]，bias 1/0）：
  - input [1,−1] → 第一层输出 0.98 / 0.12 → 第二层 0.86 / 0.11 → 输出 **0.62 / 0.83** [13:23–14:35]
  - input [0,0] → 输出 **0.51 / 0.85** [14:38–14:49]
- **参数都知道了 → 它就是 function**（input vector → output vector）；**只定了结构 → define 一个 function set**（每个参数组合 = 一个 function）[14:50–16:21]
- network 的 function set 比 linear/logistic regression 大得多（包含它们没有的 function）[16:16–16:27]

### 5. 层命名与"deep"
| 名称 | 位置 | 备注 |
|---|---|---|
| input layer | 最前面 | ⚠️ **严格说不是一个 layer**（不是由 neuron 组成，只是输入 vector）[18:29–18:42] |
| hidden layer（大 L 排） | 中间 | 每层可以 1000/2000 个 neuron 这个 scale [17:07–17:16] |
| output layer | 最后 | 有 N 个 neuron → 输出 y₁…y𝐍（可多输出）[18:18–18:25] |

- deep = 有很多 hidden layer；几层算 deep？没人说得准（3 层？8 层？）；"自从有 deep learning 这个词，有一层也都说自己是 deep learning" [18:45–19:27]
- 层数史（ImageNet 错误率）：AlexNet 8 层 16.4% → VGG 19 层 7.3% → GoogleNet 22 层 6.7% → **ResNet 152 层 3.57%（超过人的表现）** [19:30–20:56]
- ⚠️ **ResNet 不是一般的 FC Feed-Forward network**：普通 FC FF 堆 152 层会 **train 不起来（不是 overfitting）**，需要特殊结构 → 之后讲 [21:01–21:25]

### 6. 矩阵运算 = 网络前向传播
- 第一层：`x·W₁ + b₁ → activation → a₁`；第二层：`a₁·W₂ + b₂ → activation → a₂`；… 最后：`a_{L−1}·W_L + b_L → y` [23:33–25:08]
- 所以 neural network 本质 = **一连串 vector × matrix + vector**（线性代数矩阵运算）[25:39–25:51]
- **为什么写成矩阵**：可以 **GPU 加速**！游戏显卡并没有对 neural network 特化，只是"算矩阵运算"比 CPU 快 → 需要矩阵运算时 call一下 GPU [25:54–26:42]
- 记忆口诀（延续截图）：**W 的每一行 = 一个 neuron 对全部输入的权重**；x 是列向量（分量 = 各 feature 值）；每层输出 = W·x + b 再逐元素激活

### 7. feature extractor 视角（本集最有"理解深度"的一段）
- **output layer 之前的所有 hidden layer = 一个 feature extractor**：取代手动 feature engineering / feature transformation [26:45–27:08]
- 最后 hidden layer 的输出（x₁…x_K）= **一组新的 feature**；经过复杂转换后，这组 feature 可能变得 **separable**（可分离）→ 一个简单的（单层）multi-class classifier 就能分得很好 [27:09–27:56]
- output layer = multi-class classifier，它用的 feature 不是从原始 x 直接抽的，而是「机器自己找出来的好 feature」
- **output layer 也要加 softmax**（multi-class classifier 的标准做法 → 输出变概率分布）[27:58–28:26]

### 8. 手写数字识别（第二个例子，非宝可梦）
- 16×16 的图像 = 256 个 pixel = **256 维 vector**（涂黑=1，空白=0）[28:38–29:23]
- 网络 = 一个 function：input 256V → output **10V**（每一维对应一个数字）[30:21–30:59]
- softmax 后 output 是概率分布：y₁ = 数字 1 的概率…；概率最大（如 0.7 → 数字 2）则判定为该数字 [29:25–30:14]
- 这个 function set 里的每个 function 都能做手写数字识别，只是有的结构好有的结构差；用 gradient descent 挑一个最好的 [31:03–31:32]

### 9. function set 与 structure 设计（超参数 = 设计决定）
- 之前的 linear/logistic regression：model structure **没什么好设计的**；现在：唯一约束 input 256V / output 10V，**中间几层、每层几个 neuron 全要自己决定** [31:33–32:10]
- 决定 layer 数 + neuron 数 **= 决定 function set 长什么样** [32:10–32:17]
- **function set 差 → 大海捞针（针不在海里）**：怎么找都找不到好 function [32:18–32:31] → 所以决定好的 structure 很关键
- 怎么定？"**我不知道**"——像"怎么成为宝可梦大师"一样，只能凭直觉、经验、多方尝试，有时需要 domain knowledge [32:52–33:25]
- 自动找 structure？可以（基因算法等，问余天丽老师），但未普及——AlphaGo 也不是这些方法做出来的 [37:31–37:55]

### 10. DL 把问题"转化"了（≠ 变简单）
- 传统 ML：要**找一组好 feature**（feature engineering / feature transform）[33:38–33:50]
- DL：往往不需要手动 feature（画像识别直接丢 pixel 硬做），但要 **design network structure** [33:51–34:21]
- 哪个容易？看 case：
  - **语音/影像**：人自己会看会听，但"太下意识"说不出好 feature → design structure 更容易 [34:29–35:15]
  - **NLP**：人容易设计 rule（正负面词表统计）→ 传统方法本来不错 → DL 的进步没那么显著（**但确实有进步**）；文字处理里有很多细腻信息连人自己都不知道 → 长远而言 DL 自己学仍占优势 [35:20–37:30]

### 11. 多分类的 loss（Step 2）
- label ŷ = **one-hot vector**（10 维，只有数字对应位置是 1 其余 0）[38:41–39:05]
- 每笔 data：y 与 ŷ 算 **cross-entropy**（跟之前 multi-class classification 一模一样）[39:15–39:30]
- **Total loss = 所有 data 的 cross-entropy 全部加起来**：`L = Σₙ Cⁿ` [39:40–39:58]
- 然后"在 function set 里找一个 minimize L 的 function / θ*" [40:01–40:15]

### 12. 训练 = 一样的梯度下降（Step 3）
- 随机初始化 θ → 算每个参数的偏微分（= gradient）→ 更新 `θ ← θ − μ·∇L`（学习率这里用 μ）→ 反复 [40:16–41:38]
- **和 linear regression 没有任何差别，只是 function 变复杂**；最潮的 AlphaGo 也是 gradient descent 训练的（"gradient descent 就是玩世纪帝国"）[40:29–41:56]
- 手算微分？因为参数 millions，不现实 → **backprop = 算这个微分更有效率的方式**（之后讲；现在有太多 tooling 帮你算，作业也允许用）[41:57–43:30]

### 13. softmax 深挖：它是激活函数吗？logits 能直接算交叉熵吗？
> 课后追问整理（3 连问）：① softmax 是什么、加在哪 ② 算不算激活函数 ③ 输出层没激活函数时怎么算交叉熵

- **softmax 是什么**：输出端把 logits 变成概率分布的运算 `yᵢ = e^{zᵢ} / Σⱼ e^{zⱼ}`——每个值 0~1、总和=1、指数放大"领先者"的差距（比分越悬殊 → 概率越极端）
- **为什么躲不掉**：交叉熵 `−Σŷᵢ ln yᵢ` 要求 y 是**合法概率分布**（每项>0、和为 1）；裸 logits 有负有正、和≠1，ln 直接无定义。softmax 就是"让 y 成为概率"的那一步——数学上必须，形式则可换
- **softmax 算激活函数吗**？
  - **广义：算**——输出端的非线性变换，框架（PyTorch nn.Softmax）也归为激活函数
  - **狭义：不算"逐元素"激活**——sigmoid/ReLU 每个 neuron 独立变换、互不影响；softmax **整层集体归一化**（分母是全部 e^z 之和，改一个 zᵢ 所有 yⱼ 都变）。所以它管"一层"而不是"一个神经元"
- **输出层不写激活函数 = 不用 softmax？**（关键澄清）
  - 数学上：**必须**，只是位置可换
  - 工程上：`nn.CrossEntropyLoss` **内建 softmax**（内部 = log_softmax + NLL），直接接收 logits——所以"代码里不写 softmax" ≠ "没做 softmax"，它只是搬进了 loss（数学等价；数值更稳：避免 e^z 溢出、小概率 ln → −inf）
  - **只有推断（argmax）时才是真不需要**：softmax 保序，`argmax(z) = argmax(softmax(z))`
- **三种场景总结**：

| 场景        | 输出层             | 怎么得到 loss                      |
| --------- | --------------- | ------------------------------ |
| 手算 / 课件讲解 | 加 softmax       | y 直接代入 `−Σ ŷᵢ ln yᵢ`           |
| 写代码（最常见）  | 不加（线性输出 logits） | `CrossEntropyLoss`（内建 softmax） |
| 回归任务      | 不加              | MSE（y 不需要是概率）                  |

### 14. 为什么 deep？（悬念）
- 直觉答案"越 deep performance 越好"：2011 Interspeech 实验——1 hidden layer（2k neuron）WER 24.2，越深越低 [43:48–44:16]
- 但这**不 surprise**：参数多 → function set 大 → bias 小；有足够 training data 控制 variance → 复杂 model 好是正常的 [44:16–44:43]
- 打击：**理论说任意连续 function（n 维输入）都能用一个 hidden layer（够多 neuron）的 network 表示** → "深度没有意义"？→ 有人说 **deep learning 只是噱头**（"deep 听起来比较潮，fat network 听起来太虚"）[44:44–45:41]
- **真的吗？往后的 lecture 再告诉你们**（伏笔：本课程的"为什么 deep"篇章）[45:41–45:47]

## 公式与推导要点

**一层的前向传播**：`aᵢ = activation(x·Wᵢ + bᵢ)`（i 层；Wᵢ 行数 = 该层 neuron 数，列数 = 上层 neuron 数）

**整个网络**：`y = activation(a_{L−1}·W_L + b_L)`，即 一连串 `vector · matrix + vector → 逐元素激活`

**手算例（截图核对过）**：`σ([[1,−2],[−1,1]]·[1,−1]ᵀ + [1,0]ᵀ) = σ([4,−2]ᵀ) ≈ [0.98, 0.12]ᵀ` ✅（1·1+(−2)(−1)+1=4；(−1)·1+1·(−1)+0=−2；σ(4)≈0.98，σ(−2)≈0.12）

**多分类 loss**：`C(y, ŷ) = −Σᵢ ŷᵢ ln yᵢ`；`L = Σₙ Cⁿ`

**训练**：`θ⁰ 随机 → 算 ∇L(θ)（每个参数的偏微分）→ θ ← θ − μ·∇L → 反复`

**万能逼近（理论）**：任意连续 function（input 为 n 维 vector），都能用**一个 hidden layer** + 足够多 neuron 的 network 表示（1989 理论 reprise）——正是它让"为什么 deep"成为问题

## 易错点与纠正

1. **softmax 不是 sigmoid**：multi-class classifier 的最后一层用 **softmax**（输出归一化为概率分布）；sigmoid 是二分类/神经元的激活函数。转写里 [28:00–28:08] 那句自相矛盾是听写错误，按语义取"softmax 而不要通过 sigmoid"
2. **矩阵行/列语义**：W 的**行 = neuron**（行 i 是第 i 个 neuron 的权重向量），列 = feature；点积后加 bias → 逐元素激活。别用"主要/次要信息"这种自创说法
3. **input layer 严格说不是 layer**：它没有 neuron，只是输入 vector；老师特意区分（hidden/output layer 才是真 layer）
4. **ResNet ≠ 普通 FC FF**：152 层 FC FF 会 **train 不起来**（不是 overfitting）；ResNet 靠特殊 structure（残差连接）才能这么深——"越深越好"的前提是结构要支持
5. **1989 万能逼近 ≠ deep 无意义**：理论说一个 hidden layer（够多 neuron）能表示任意连续函数——但这只是"存在性"，不代表好训练/好泛化；"为什么 deep"是后话（伏笔）
6. **"NLP 不适合 DL"是误读**：DL 在 NLP 有进步，只是相对语音/影像**没那么显著**（人容易设计 rule 所以传统方法本来就不差）；长远看仍占优势
7. **backprop 不是新优化方法**：它就是"算 gradient 的高效方式"（参数 millions 手算不现实）；优化方法还是梯度下降
8. **output layer"空"的说法**：回归任务可以直接输出；分类任务要加 softmax。所谓"拿 hidden layer 输出当结果"是 feature extractor 视角（用它的输出做后续分类），不是 output layer 空着
9. **"CrossEntropyLoss 不用 softmax"是错觉**：loss 内建了 softmax（log_softmax + NLL）；模型里不写 softmax ≠ 没做 softmax，只是搬进了 loss；只有推断 argmax 时才是真不需要
